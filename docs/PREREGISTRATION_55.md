# 사전 등록: 55 단계 (Abdelrahman 2021과 비교: 기억 성능과 누출)

2026-10-14. **결과를 계산하기 전에 작성했다.**

## 배경

Abdelrahman, Vasilaki, Lin 2021(PNAS)은 KC 사이의 변수 불균일(입력 수, 입력 세기, 문턱)이 기억 성능을 떨어뜨리고, 보상(입력 수와 세기의 반비례, 또는 각 KC의 평균 활동을 맞추는 항상성)이 성능을 되살린다고 보고했다. 우리는 같은 불균일이 자발 활동에서 학습된 가치를 새게 한다고 보았다(25~54). 54에서는 누출을 정하는 것이 각 KC의 자발 입력 분포(평균과 흔들림)였다.

질문: 기억 성능을 되살리는 보상이 누출도 없애는가? 아니면 냄새 반응만 맞추는 항상성은 기억은 고치지만 자발 활동 쪽 누출은 남기는가?

## 방법

다섯 반구, 43과 같은 보정 모형, 시드, MBON11 가중치(누출용). 우리 모형에 Abdelrahman의 과제와 보상을 옮긴 근사이며, 그들의 코드를 그대로 재현하지 않는다.

**조건 (4개)**
1. 원래: 공통 문턱(평가 냄새 활성 10%로 보정).
2. 세기 평평 (활동 무관 보상): 29의 alpha 1. KC마다 대응 PN 입력 총량을 같게 한다. Abdelrahman의 "입력 수와 세기의 반비례"를 끝까지 밀어붙인 형태다.
3. 문턱 항상성: 보정용 냄새 37개에서 각 KC의 평균 활동이 원래 회로의 KC 평균 A0와 같아지도록 KC별 문턱을 반복 조정한다(APL 포함, 300회, 문턱 하한 0). 대응 PN 입력이 없는 KC는 조정하지 않는다.
4. 세기 항상성: 같은 목표로 KC별 입력 배율을 반복 조정한다(문턱은 원래 값).

**기억 과제 (Abdelrahman 형식)**
- 평가용 냄새 73개 전부에 무작위 가치(처벌 또는 보상, 반반)를 준다. 10회 반복(시드 550000 + r).
- 접근 MBON과 회피 MBON이 모든 KC를 같은 가중치로 읽는다. 처벌 냄새를 배우면 그 냄새에 켜진 KC에서 접근 MBON으로 가는 연결이 약해진다(w -> w exp(-5 k)). 보상 냄새는 회피 MBON 쪽이 약해진다. 학습은 잡음 없는 냄새 반응으로 한다.
- 시험: 냄새마다 잡음이 있는 전체 농도 시행 20개(시드 550100). 회피 출력이 접근 출력보다 크면 회피를 고른다. 정확도 = 옳은 선택 비율(동점은 0.5).
- 보조: 20개 냄새만 배울 때의 정확도.

**누출:** 43과 같은 H(MBON11 가중치)와 25 정의의 시뮬레이션 누출.

## 판정 (실행 전 고정)

- **P1 (Abdelrahman 방향 재현):** 문턱 항상성과 세기 항상성의 정확도가 원래보다 높은 반구가 각각 4개 이상이면 지지.
- **P2a:** 문턱 항상성의 H가 원래보다 작은 반구가 5개 모두이면 지지.
- **P2b (냄새 기준 항상성으로 충분한가):** 문턱 항상성의 H가 2 이하인 반구가 4개 이상이면 "냄새 반응을 맞추는 항상성으로 누출도 사라진다". 아니면 "냄새 기준 항상성은 자발 활동 쪽 누출을 남긴다".
- **P3 (기억과 누출이 같이 움직이는가):** 반구마다 네 조건에서 정확도와 H의 Spearman 상관을 구하고, 다섯 반구 평균이 -0.6 이하이면 "같이 움직인다(같은 보상이 둘 다 고친다)". 그 밖은 "분리된다".

## 한계
