# 사전 등록: 34 단계 (FlyWire 개체 간 재현)

2026-10-09. **FlyWire 연결 자료를 열기 전에 작성했다.** 주석 파일에서 KC, APL, MBON11, 투사뉴런의 존재만 확인했다.

## 목적

16~33은 BANC 한 개체(좌우 반구)에서 나왔다. FlyWire v783은 다른 초파리 한 마리의 전뇌 커넥톰이다. 핵심 결과가 개체를 넘어 재현되는지 본다. 32의 BANC와 hemibrain 사이 보상 불일치에 대해서도 세 번째 자료를 제공한다.

## 자료와 회로 구성 (사전 고정)

- 연결: Zenodo 10676866의 `proofread_connections_783.feather`. 뉴런 쌍별로 신경망 영역(neuropil)을 합쳐 시냅스 수를 쓴다. 파일에 이미 적용된 시냅스 하한이 있으면 그대로 쓰고 결과 문서에 적는다.
- 주석: `flywire_v783_neuron_annotations.tsv`.
- KC: `cell_class == Kenyon_Cell`, 반구별. APL: `cell_type == APL`, 반구별(양쪽 모두 주석 있음). MBON11: `cell_type == MBON11`, 반구별.
- PN: `cell_class == ALPN`이고 `top_nt == acetylcholine`인 뉴런 중 해당 반구 KC로 연결되는 것. BANC의 "검증된 전달물질" 대신 FlyWire의 예측 전달물질을 쓴다는 차이가 있다.
- 사구체: `cell_type`의 `_` 앞 접두사. `cell_sub_class == multiglomerular`이거나 접두사에 `+`가 있으면 Hallem 대응에서 제외한다.
- 수용체 대응, Olsen 변환, 정규화(KC 입력 중앙값, APL 평균과 합), 보정(보정용 냄새 37개, 10%), 잡음, 시드, 지표는 BANC와 같다.

## 재현 검정 (반구별, 두 반구 일치 필요)

- **F1 (16 보정):** 평가용 냄새 활성 KC가 3~20%이고 APL 제거 시 증가.
- **F2 (17 과수렴 구조):** Z > 3.29 쌍 수가 가상 관측 대조(강도 보존, 1,000개, 시드 340001~)보다 많다(p < 0.05). DM1-DM4 Z도 보고한다.
- **F3 (25 누출):** MBON11 기준 특이 누출(학습 - 무작위 통제)의 냄새 재표집 95% 구간이 0보다 위.
- **F4 (26 허브 인과):** KC 입력 총량을 같게 맞춘 회로에서 누출 비율 <= 0.5.
- **F5 (32 배선 보상):** log(연결당 시냅스) ~ log(PN 연결 수) 기울기가 순열 영분포(1,000회, 시드 345001~)보다 작다(단측 p < 0.05)면 "FlyWire에 배선 보상 있음".

각 검정은 "재현", "재현 안 됨"으로 따로 보고한다. F5는 BANC(보상 없음)와 hemibrain 보고(보상 있음) 중 어느 쪽과 같은지 기술한다.
