# 사전 등록: 23 단계 (신호 검출과 오탐, APL 약화)

2026-10-09. **결과를 보기 전에 작성했다.** 실행 가능성 확인으로 오른쪽 회로, 정상 APL에서 잡음만 있는 시행의 KC 활동만 미리 봤다(0.5 s 창에서 시행의 82%에서 KC가 하나 이상 반응, 평균 활성 0.4%). APL 약화 조건, 냄새 시행, 대조, 왼쪽 반구는 계산하지 않았다.

## 질문

원래 관심사로 돌아간다. 억제(APL)가 약해지면 "냄새가 없는데 있다고 판단하는 오탐"이 늘어나는가? 늘어난다면 그것은 판단 기준이 밀린 것(편향)인가, 아니면 신호와 잡음을 가르는 능력 자체가 떨어진 것(민감도 저하)인가? 그리고 그 취약성이 실제 배선에 특이적인가?

편향과 민감도의 구분은 환각 연구(예: Powers 2017)에서 중요하다. 오탐이 늘어도 민감도가 그대로면, 감각 처리가 망가진 것이 아니라 "있다"고 말하는 쪽으로 기준이 밀린 것에 가깝다.

## 모형과 과제

- 회로: 오른쪽(16)과 왼쪽(22) 보정 모형, 각각의 10% theta. 왼쪽 APL은 22의 추정 뉴런이다.
- **검출기:** KC 활동의 합 D(모든 KC를 같은 가중치로 읽는 출력 뉴런 하나).
- **기준:** 정상 APL(s = 1)에서 잡음만 있는 보정 시행 1,000개(시드 230001)의 D 95백분위로 정한다. 이 기준은 이후 고정한다. "회로의 억제가 바뀌어도 판단 기준은 적응하지 않는다"는 가정이다.
- **잡음 시행:** 냄새 없음. 감각뉴런이 자발 활동에서 Poisson 잡음만 낸다(0.5 s 창). 평가용 1,000개(시드 230002).
- **신호 시행:** 평가용 냄새 73개를 약한 농도로 준다. Hallem 변화량에 농도 배율 c를 곱한다(선형 근사, 가정). c는 0.05, 0.1, 0.2이고 주 조건은 0.1이다. 냄새당 20시행(시드 230003)이다.
- **APL 강도:** s = 1, 0.5, 0. 주 대비는 s = 0.5 대 1이다.

## 측정

- 오탐률 FA: 잡음 시행 중 D > 기준인 비율.
- 적중률 H: 신호 시행 중 D > 기준인 비율.
- **민감도 AUC:** 잡음 시행과 신호 시행의 D 분포를 가르는 정도. 기준과 무관한 지표다.
- 보조: d' = z(H) - z(FA) (비율은 1/(2N)과 1-1/(2N) 사이로 자름), 기준 위치 c_sdt = -(z(H)+z(FA))/2.

## 가설과 판정

**H23a (조작 점검).** s = 0.5에서 FA가 s = 1보다 크다. 두 반구 모두 그러면 "억제 약화가 오탐을 늘림". 판정은 하되 기준이 고정이므로 예상되는 결과로 본다.

**H23b (주 가설: 민감도).** ΔAUC = AUC(s = 0.5) - AUC(s = 1), 주 조건 c = 0.1. 냄새와 잡음 시행을 재표집하는 쌍체 부트스트랩 1,000회(시드 230100)로 95% 구간을 구한다.
- 두 반구 모두 95% 구간이 0보다 아래이고 ΔAUC < -0.02: "억제 약화가 민감도를 떨어뜨림".
- 두 반구 모두 95% 구간이 0보다 위이고 ΔAUC > 0.02: "억제 약화가 민감도를 높임".
- 두 반구 모두 |ΔAUC| < 0.02: "민감도는 거의 그대로이고 오탐 증가는 편향 이동".
- 그 밖: "반구 간 불일치 또는 판단 보류".

**H23c (배선 특이성).** 각 반구에서 실제 배선의 ΔAUC를 N0 대조 100개(오른쪽 시드 180001~, 왼쪽 222001~)와 비교한 z. 두 반구 모두 |z| >= 1.96이고 부호가 같으면 "실제 배선 특이적 취약성(또는 보호)". 그 밖에는 "배선 특이성 없음". 대조에서도 기준은 각 대조 그래프의 s = 1 잡음 보정 시행으로 따로 정한다.

**보조 (판정 없음).** c = 0.05, 0.2, s = 0, 0.25 s 창은 보고만 한다.

## 한계

- 농도 배율은 선형 근사이고, 실제 수용체 용량 반응은 비선형이다.
- 검출기는 KC 합 하나이고 실제 행동 결정 회로가 아니다.
- 오탐은 모형 출력이 기준을 넘은 것이다. 초파리가 냄새를 "느꼈다"는 뜻이 아니며 환각의 증거가 아니다.
