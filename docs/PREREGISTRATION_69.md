# 사전 등록: 69 단계 (실제 배선은 손실 지형의 평평한 곳에 있는가)

2026-10-19. **어떤 결과도 계산하기 전에 작성했다.** 갈래 2의 첫 단계다([연구 계획](RESEARCH_PROGRAM_68.md)). 학습 없이, 이미 있는 배선을 흔들어 성능이 얼마나 떨어지는지 잰다. 같은 확장층을 학습으로 최적화하는 실험은 71에서 한다.

## 질문

딥러닝에서는 "평평한 극소점(flat minima)", 곧 가중치를 조금 흔들어도 손실이 크게 늘지 않는 해가 잘 일반화한다는 주장이 널리 쓰인다. 진화한 배선이 무작위 배선보다 이런 의미에서 평평한지(시냅스 잡음에 강건한지)를 본다. 실제 배선, 입력 세기를 보존한 무작위 배선, 입력을 고르게 한 배선을 같은 섭동에 놓는다.

## 모형과 과제

**회로:** 다섯 반구(BANC 좌우, FlyWire 좌우, hemibrain 오른쪽)의 원래 회로다. `p34.make_g`를 쓰고, 문턱은 `cal.calibrate`로 KC 10%에 맞춘다.

**배선 세 종류:**
- 실제 배선.
- 세기 보존 무작위 배선 10개. 07의 `strength_preserving_null`이고, KC별 입력 세기 분포를 보존한다.
- 입력을 고르게 한 배선. 26의 `equalize_rows`다.

각 배선마다 문턱을 다시 보정한다.

**과제 두 개:** 01~67의 정의를 그대로 쓴다.
- **냄새 식별:** 평가 냄새(make_g의 keep, 약 73종)마다 깨끗한 KC 반응을 원형으로 둔다. 잡음 시험 시행 20회(55의 `SEED_TEST`)를 코사인 최근접 원형으로 분류한다(24의 `identify`). 정답률이 성능이다.
- **가치 기억:** 55의 `memory`로 냄새 20개의 가치를 배우게 한다(배정 10회 평균 정확도).

**섭동:**
- PN→KC 행렬의 0이 아닌 원소마다 독립 로그정규 배수 exp(σz − σ²/2)를 곱한다. 이 배수의 평균은 1이다.
- σ는 0.1, 0.3, 0.5이고, σ마다 10회 뽑는다(시드는 SEED0 = 690000에서 고정).
- 문턱은 섭동 전 값으로 고정한다(주 분석). 다시 보정한 경우는 보고만 한다.

**뾰족함(sharpness):**
- S_σ = P0 − (섭동 성능의 평균)이다. P0는 섭동 전 성능이다.
- 상대 뾰족함 S_σ / P0도 함께 보고한다.

## 판정 (실행 전 고정)

주 지표는 σ = 0.3이다.

- **F1 (식별 과제에서 실제 배선의 평탄도):** 실제 배선의 S_0.3이 무작위 배선 10개의 중앙값보다
  - 작은 반구가 4개 이상이면 "더 평평함"
  - 큰 반구가 4개 이상이면 "더 뾰족함"
  - 그 밖은 "차이 없음"이다.
- **F2 (기억 과제에서 실제 배선의 평탄도):** F1과 같은 규칙을 기억 정확도에 적용한다.
- **F3 (입력을 고르게 한 배선과 실제 배선):** 두 과제 각각, S_flat < S_real인 반구가 4개 이상이면 "고르게 하면 평평해짐", 반대가 4개 이상이면 "고르게 하면 뾰족해짐"이다.
- **F4 (평탄도와 성능의 관계):** 반구마다 무작위 배선 10개와 실제 배선을 합친 11개에서 Spearman(P0, S_0.3)을 잰다. 4개 이상의 반구에서 같은 부호이고 |ρ| > 0.3이면 그 방향을 보고한다. 딥러닝의 주장대로라면 음의 관계(성능이 좋을수록 평평함)다.

## 보고만

- σ = 0.1과 0.5.
- 문턱을 다시 보정한 섭동. 항상성이 섭동을 얼마나 되돌리는지 본다.
- 섭동 전 성능 P0의 실제 대 무작위 비교(18~22의 재확인).
- KC 입력 세기의 변동계수와 Gini(실제, 무작위, 고르게 한 배선).

## 한계

- 섭동은 시냅스 세기에만 준다. 연결의 생성이나 소멸은 넣지 않았다.
- 무작위 배선은 KC별 입력 세기를 보존한다. 그래서 이 비교는 "어느 PN에서 받는가"의 구조가 평탄도에 주는 효과를 본다.
- 성능은 고정 판독(원형, 가치 기억 규칙)에서 잰다. 딥러닝의 손실 지형과 같은 대상이 아니다. 비유가 가능한 범위의 측정이다.
