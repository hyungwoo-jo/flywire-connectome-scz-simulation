# 65 후속 측정 감사: 실행 전 분석 계획

2026-10-18. 65의 실측 결과와 원래 모형 결과는 이미 확인했다. 따라서 이 문서는 새 독립 사전등록이 아니라 **사후 측정 검증의 실행 전 계획**이다. 66 사전등록과 05~65 파이프라인은 보존한다.

## 질문

모형의 작은 KC 활성 여부와 영상에서 검출한 칼슘 사건은 같은 측정이 아니다. 실측의 신호/잡음 범위를 사용해 잠재 KC 활동을 저역통과한 상대 형광으로 바꾸고, 기존 영상 처리와 같은 사건 판독을 적용하면 반응 폭-자발 사건 상관이 어떻게 변하는가?

## 범위와 고정 조건

- BANC 오른쪽만 사용한 측정 민감도 감사다. 전체 7반구의 생물학적 재검증이 아니다.
- 원래 회로, 입력 평평화, 냄새 기준 문턱 항상성, 전체 활동 항상성 네 조건을 기존 정의로 만든다.
- 각 아형/all의 0·1번 개체 8마리는 형광 잡음 SD·lag-1 자기상관·냄새 반응 진폭 보정에만 사용하고, 2·3·4번 12마리는 비교에 사용한다. 모든 개체를 이전에 분석했으므로 독립 외부 검증은 아니다.
- 0.5초 창 ORN Poisson 입력으로 KC 활동 은행(자발 1,024개, 냄새별 3개)을 만들고, 약 5.58Hz 프레임에서 3프레임씩 유지한다. 시간 상관을 생리적으로 추정한 것이 아닌 가정이다.
- 칼슘 관측은 C[t]=alpha*C[t-1]+(1-alpha)*k[t], alpha=exp(-dt/tau)로 근사한다. tau 0.3·0.7초, 진폭 배율 0.5·1·2를 모두 보고한다. 이 값들을 확정된 GCaMP6f 생리 계수라고 주장하지 않는다. 스파이크 모형도 아니다.
- 형광 진폭은 보정 개체의 검출된 냄새 반응 진폭과 original의 활성 KC 진폭의 중앙값 비로 정하고, 네 회로 조건에 같은 값을 사용한다. 상관을 맞추지 않는다.
- 관측 잡음은 보정 자료의 SD와 자기상관을 가진 Gaussian AR(1)로 근사한다. 실제 기저 신호에는 생물학적 활동도 섞이므로 순수 계측 잡음 추정이 아니다. 생물학적 잡음을 이중 계산할 수 있다.
- 같은 시드로 3회 모의 반복한다. 실제 관측 개체별 KC 수와 아형을 맞춘다. 반복 및 표본은 생물학적 개체 수를 늘리지 않는다.
- 모형 상대 형광을 기존 normalize/responds/event_rates_nan에 넣는다. 신경망 배경은 일정한 값으로 두므로 별도 neuropil 생리는 재현하지 않는다. 개체별 반응 폭(B), 용매 반응(S), 양·음 사건률(Rp/Rn), 상관을 보고한다.

## 해석 규칙

1. 잠재 활성 비율과 관측 사건률을 나란히 보고하며 사건 검출로 상관이 약해지는지 확인한다. 직접 지표 결과를 폐기하지 않는다.
2. 상관뿐 아니라 냄새 반응 폭, 양·음 사건률도 비교한다. 실측 개체 재표집의 구간과 비교하되 모형 선택 확률이나 유의성 검정으로 해석하지 않는다.
3. 관측 계수에 따라 결론이 바뀌거나 주변 사건률/반응 폭이 실측과 맞지 않으면, 현재 자료만으로 모형 기각 또는 보상 모형 선택을 확정하지 않는다.
4. 용매는 이번 감사에서 기존 모형처럼 냄새 입력 0이다. 용매 전달은 별도 66의 질문이다. 여기서 용매 상관을 맞추지 않는다.
5. 모든 설정을 보고하고 가장 잘 맞은 설정을 새 확증 결과로 선택하지 않는다. 절대 발화율-형광 변환, 시간 입력, 잔여 움직임/배경 신호가 추가 자료 없이는 식별되지 않음을 명시한다.

## 검증과 산출물

상수/임펄스 저역통과, AR(1) 분산, 동일 사건 검출, 안전 로더를 확인한다. 실측 20개체 B/S/R 재계산이 65 산출물과 일치하는지 점검한다. 산출물은 qc_reports/observation_audit/에 저장한다. 관측 신호의 재보정이 충분하지 않으면 66의 실측 정합 판정을 잠재 활동 기준의 탐색 비교로만 표시한다.
