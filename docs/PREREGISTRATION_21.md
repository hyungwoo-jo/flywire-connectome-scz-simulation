# 사전 등록: 21 단계 (학습의 일반화)

2026-10-09. **결과를 보기 전에 작성했다.** 변경은 결과 문서의 "사전 등록과 다른 점"에 기록한다.

## 배경과 가설

18~20에서 실제 PN->KC 배선은 범용 냄새 구분에서 무작위 대조보다 약간 불리했다. 그 원인은 배선 구조 자체로 좁혀졌다. 이론적으로 구분과 일반화는 서로 맞바꾸는 관계일 수 있다. 비슷한 냄새가 KC를 더 많이 공유하면 구분은 어렵지만, 하나를 배웠을 때 비슷한 냄새로 반응이 넓혀지는 일반화는 쉬워진다.

**H21.** 실제 배선에서는 학습의 일반화가 대조보다 **화학 계열에 더 잘 맞는다**. 한 냄새를 배웠을 때 같은 화학 계열(에스테르, 알코올 등)의 냄새로 더 많이 번지고, 다른 계열로는 덜 번진다.

화학 계열은 DoOR `odor.csv`의 `Class` 열이다. 반응 자료와 독립된 분류다.

## 모형

- 입력, 변환, 보정(10% theta), APL은 16과 같다. 잡음 없는 KC 반응을 쓴다(일반화는 평균 반응의 성질이므로).
- **판독과 학습.** 출력 뉴런 하나가 KC 전체를 같은 가중치로 읽는다(주 조건, PN->KC 구조의 효과만 보기 위함). 보조 조건으로 실제 MBON11의 KC 입력 가중치(08단계 방식, 총합 정규화)를 쓴다. 학습 규칙은 08과 같다. 냄새 A를 배우면 `w' = w * exp(-eta * k_A)` 이다. 주 조건은 eta = 5, 민감도 조건은 eta = 20이다.
- **일반화 지수.** 냄새 B의 반응 감소율은 drop_B = 1 - (w'·k_B)/(w·k_B) 이다. A를 배웠을 때 B로의 일반화는 GI(A,B) = drop_B / drop_A 이다. 학습 전 반응이 0인 냄새는 제외한다.

## 측정

평가용 냄새 73개 중 계열 크기가 4 이상인 7개 계열(O ring 4, acid 12, alcohol 8, aldehyde 5, arom 9, ester 19, terpene 10)의 냄새 67개를 쓴다. 각 냄새를 한 번씩 A로 학습시키고(67회), 나머지 66개에 대한 GI를 계산한다.

- **주 지표 CI (계열 일관성).** 같은 계열 쌍의 GI 평균에서 다른 계열 쌍의 GI 평균을 뺀 값.
- **보조 지표.**
  - 입력 유사도 충실도: 모든 쌍에서 GI와 PN 입력 유사도(무잡음 PN 반응의 Pearson 상관)의 Spearman 상관.
  - 에스테르 안의 CI: 에스테르 쌍의 평균 GI에서 에스테르와 다른 계열 쌍의 평균 GI를 뺀 값.
  - 평균 GI(전반적 일반화 크기).

## 대조와 판정

18과 같은 N0 대조 100개(시드 180001~180100)를 쓴다. 대응 PN 연결만 교환하고 KC->MBON은 바꾸지 않는다.

**판정 규칙 (주 조건: 균일 판독, eta 5, CI).** z = (실제 - 대조 평균) / 대조 SD.
- z >= 1.96: "실제 배선은 계열에 더 일관된 일반화를 만든다" (H21 지지).
- z <= -1.96: "실제 배선은 계열 일관성이 더 낮다" (H21 반대).
- 그 밖: "차이 없음".

보조 조건(MBON11 판독, eta 20)과 보조 지표는 보고만 하고 판정을 바꾸지 않는다.

**해석을 미리 정해 둠.** CI가 높다는 것만으로 "더 좋은 학습"은 아니다. 계열이 행동적으로 의미 있는 범주라는 가정이 필요하다. 이 가정은 검증하지 않는다.
