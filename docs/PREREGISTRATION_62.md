# 사전 등록: 62 단계 (왼쪽의 약한 냄새 신호는 왜 작은가)

2026-10-15. **누출과 기준 결과를 계산하기 전에 작성했다.** 좌우의 사구체 목록, 사구체별 PN 수, APL 배선의 변동계수만 먼저 봤다.

## 배경

61에서 MaleCNS 왼쪽의 큰 누출은 대부분(87%) 기준에서 나왔다. 왼쪽은 학습한 냄새를 세기 10%로 줬을 때의 가치 신호(냄새별 중앙값, 기준은 그 절반)가 오른쪽보다 약 10% 작았다(0.270 대 0.302). 이번에는 그 원인을 회로 성분별로 나눈다.

약한 냄새 시행의 가치 신호는 다음과 같다.

```
L_weak = sum_i w_i d_i k_i / sum_i w_i k_i
```

즉 약한 냄새에서 활성화된 KC(MBON11 가중치로 가중)의 평균 학습 깊이 d다. 약한 활동이 학습된 KC(강한 냄새에 반응한 KC) 위에 덜 놓이거나, 그 KC의 학습 깊이가 얕으면 작아진다.

먼저 본 구조:

- 좌우 모두 매핑된 사구체는 같은 23개다. 사구체 목록 차이는 원인이 아니다.
- 사구체별 PN 수는 다섯 사구체(DM5, DM6, VC3, VM2, VM5v)에서 1개씩 다르다.
- 매핑된 PN이 KC에 주는 입력 평균은 왼쪽이 약 8% 작다(0.415 대 0.451).
- APL→KC 억제의 변동계수는 0.32 대 0.35, KC→APL 구동은 0.23 대 0.26이다.

## 방법

MaleCNS 좌우, 59의 시드 0~4. 각 반사실 회로에서 문턱은 다시 맞춘다(평가 외 냄새에서 KC 10% 활성). 그 뒤 61과 같은 방식으로 냄새별 기준, 냄새 특이 누출을 잰다.

**반사실 조건:**

| 조건 | 바꾸는 것 | 묻는 것 |
|---|---|---|
| base | 없음 | 61 재현 |
| no_apl | APL 억제를 끈다 | 억제 되먹임이 원인인가 |
| uniform_apl | APL→KC 억제와 KC→APL 구동을 모든 KC에 같게 둔다 | APL 배선의 불균일이 원인인가 |
| binary_pn | PN→KC 연결의 시냅스 수를 지우고 연결 유무만 남긴다(KC 입력 총합의 중앙값은 1로 맞춤) | 시냅스 세기 분포가 원인인가 |
| glom_matched | 사구체별 PN→KC 시냅스 총량을 좌우 평균에 맞춘다(사구체 안의 비율은 유지) | 사구체별 입력량 차이가 원인인가 |

**함께 잼 (모든 조건):**

- 무잡음 기준: 약한 냄새를 Poisson 잡음 없이 0.1 × 냄새 반응으로만 줬을 때의 가치 신호. 잡음이 섞인 기준과 비교해 "약한 시행에 섞인 자발 잡음"의 몫을 본다.
- 겹침 분해: L_weak = (약한 활동 중 학습된 KC에 놓인 비율 P) × (그 위의 평균 학습 깊이 D). 냄새별 중앙값을 보고한다.

## 판정 (실행 전 고정)

기준 격차 = 오른쪽 기준 중앙값 - 왼쪽 기준 중앙값(시드 5개 평균). base 격차를 G0라 한다.

- **R1 (반사실별):** 조건 X의 기준 격차가 G0의 절반 미만이면 "X가 격차의 주원인" 지지. 네 조건 각각 판정한다.
- **R2 (잡음 섞임):** base에서 무잡음 기준의 격차가 G0의 절반 미만이면 "약한 시행에 섞인 자발 잡음이 격차를 만든다" 지지.
- **R3 (분해 방향):** base에서 P의 좌우 상대 차이가 D의 좌우 상대 차이보다 크면 "겹침 쪽", 아니면 "학습 깊이 쪽".
- 보조: 각 조건에서 냄새 특이 누출의 좌우 차이도 보고한다. 판정에는 쓰지 않는다.

어떤 조건도 R1을 지지하지 않으면 "단일 성분이 아니라 여러 성분이 함께 만든다"로 보고한다.
