# 사전 등록: 57 단계 (냄새 기준과 자발 기준 항상성의 혼합)

2026-10-14. **결과를 계산하기 전에 작성했다.**

## 배경

- 55: 냄새 반응 평균을 맞추는 문턱 항상성(활성 10%)은 기억을 높였지만(20개 냄새 +4~8%p) BANC에 냄새 특이 누출 0.8~1.0%를 남겼다.
- 56: 자발 입력 분포 기준 문턱(lambda 1)은 다섯 반구 모두에서 누출을 없앴지만 기억을 낮췄다(20개 냄새 -3~-8%p).

두 문턱을 섞었을 때 기억과 누출을 함께 만족하는 지점이 있는지 본다.

## 방법

다섯 반구, 43과 같은 보정 모형, 시드, MBON11 가중치. 55의 기억 과제와 시드를 그대로 쓴다.

**주 조건 (문턱 혼합):**

```
theta_i(beta) = (1 - beta) * theta_odor_i + beta * theta_spont_i + delta(beta)
```

- theta_odor는 55의 문턱 항상성(활성 10%로 맞춘 것), theta_spont는 56의 lambda 1 문턱이다.
- delta(beta)는 모든 KC에 공통인 이동으로, 보정용 냄새의 활성 KC가 10%가 되도록 정한다. 문턱 하한은 0이다.
- beta는 0, 0.2, 0.4, 0.6, 0.8, 1이다. 원래 회로(공통 문턱)를 기준으로 함께 계산한다.

**탐색 조건 (전체 활동 항상성, 판정 없음):** KC가 냄새와 자발 상태를 구분하지 않고 자기 전체 평균 활동을 맞춘다고 가정한다. 냄새 시행 비율 rho, 자발 시행 비율 1 - rho로 섞은 평균 활동을 원래 회로의 집단 평균에 맞추도록 문턱을 반복 조정한다(55와 같은 규칙, 상대 오차 기준). 그 뒤 공통 이동으로 활성 10%에 맞춘다. 자발 시행은 보정용 잡음 시행 1,000개다. rho는 0.1, 0.01이다(rho 1은 55의 문턱 항상성).

**측정:** H(냄새 평균과 중앙값), 시뮬레이션 누출(학습, 무작위 통제, 냄새 특이 = 차이), 기억 정확도(20개, 73개, 원래 대비 짝 차이와 표준오차), 냄새와 잡음 시행의 활성 비율.

## 판정 (실행 전 고정, 주 조건만)

"두 목표 만족"은 냄새 특이 누출 0.3% 이하이고, 20개 냄새 정확도가 원래보다 낮지 않은(차이 > -1 표준오차) 경우다.

- **P1 (공존 지점):** beta 0.2, 0.4, 0.6, 0.8 중 하나의 공통 beta에서 두 목표를 만족하는 반구가 4개 이상이면 지지.
- **P2 (BANC):** beta 0.2~0.8 중 어느 값(반구마다 달라도 됨)에서 BANC 두 반구가 각각 두 목표를 만족하면 지지.
- **P3a (누출의 용량 반응):** 냄새 특이 누출이 beta에 따라 단조 감소(Spearman -0.9 이하)하는 반구가 4개 이상이면 지지.
- **P3b (기억의 용량 반응):** 20개 냄새 정확도가 beta에 따라 단조 감소(Spearman -0.9 이하)하는 반구가 4개 이상이면 지지.

## 한계

- beta 격자가 성기다. 두 목표를 만족하는 구간이 격자 사이에만 있으면 놓친다.
- 기억 정확도 차이의 표준오차는 가치 배정 10회만 반영한다.
- 문턱의 선형 혼합은 생물학적 기제가 아니다. 탐색 조건이 그 대신 기제에 가까운 형태를 본다.
