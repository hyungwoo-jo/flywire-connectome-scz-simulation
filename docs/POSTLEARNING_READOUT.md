# 학습 후 MBON 출력만으로 읽을 수 있는 정보

2026-10-18. [실행 전 계획](POSTLEARNING_READOUT_PLAN.md)에 따라 계산했다. 용매 단위와 칼슘 변환은 미해결이다. 이 분석은 **기존 Hallem 2006 입력의 추상 회로 안에서 접근 가능한 정보만 바꾼 감사**이며 66의 용매 분석이나 실제 행동 검증을 대신하지 않는다.

## 질문

기존 누출 비율은 동일 입력의 학습 전·후 MBON 출력을 모두 사용한다. 분석자가 계산하는 값이 실제 출력 회로에서 읽히는 정보인지 확인하려고, 학습 후 MBON11 출력 하나만 사용하는 판독과 비교했다.

## 한 일

BANC 오른쪽/왼쪽의 original 및 total_homeo 네 조건을 사용했다. 각 조건에서 평가 냄새 73개를 하나씩 A로 학습했다(eta=5). B는 학습 전의 깨끗한 KC 총 활동량이 A와 가장 가까운 다른 냄새로 고정했다. 대부분 세기가 비슷하지만 완전 일치는 아니다. 총 292개 A/B 선택 중 4개는 활동량 비율 0.8~1.25 밖이었고 전체 비율은 0.49~1.68이었다. 일치가 나쁜 쌍을 사후로 빼지 않았다.

학습 A / 학습 없음 / 학습량 일치 순열 통제를 비교했다. 순열은 KC 아형과 MBON11의 같은 입력 가중치 집단 안에서 학습 활동을 교환했다. MBON 가중치의 총 감소량을 1e-12 이내로 보존했다. 교환 가능 집단은 입력 가중치의 약 97.8~99.0%를 포함했다. 제한 순열이며 균등 무작위 표본이나 실제 배선 대조는 아니다.

판독 보정은 냄새별 원래 세기 10시행+세기 10%의 10시행, 평가에는 독립 잡음의 각 20시행을 사용했다. 유무 기준은 별도 잡음 1,000시행의 95백분위에서 정했고 독립 잡음 1,000시행에 적용했다. 모든 계수·규칙을 고정한 뒤 감각·판독 보정 잡음 seed를 +10000 한 두 번째 표본에서도 반복했다. 같은 냄새·배선의 추가 모의 잡음 검증이지 새 생물학적 개체 재현이 아니다.

각 학습 조건에서 A/B 경험으로 판독 문턱을 다시 보정한다. 실제 동물이 즉시 그런 적응을 한다는 근거는 없다. A/B 판독 기준의 변화와 신경 출력 변화가 함께 포함되므로 작은 잡음 오판 차이를 신경 출력 변화만의 인과 효과로 읽지 않는다.

## 정보 조건

| 점수 | 접근 정보 |
|---|---|
| raw_after | 학습 후 MBON11 출력 하나 |
| pn_normalized_after | 학습 후 MBON11 출력과 추가 PN 총 입력 채널 |
| privileged_fraction | 동일 입력의 학습 전·후 출력. 분석자용 진단 기준 |

각 점수에서 유무 판단 없음, MBON 자체의 잡음 기준 초과, PN 총 입력의 잡음 기준 초과를 비교했다. PN을 읽는 경우는 추가 정보가 있는 판독이다. 두 유무 기준 모두 미리 고정한 보정 자료만 사용했다. 자극이 있는데 유무 기준에 미달한 시행은 전체 A/B 정확도에서 오답으로 셌다. 무자극에는 냄새 식별 정답을 부여하지 않았다.

## 결과 1: 학습 후 MBON 출력 하나에도 강한 냄새의 정보가 남았다

아래는 raw_after와 MBON 자체 유무 기준만 사용하는 결과다. PN 총 입력이나 학습 전 출력에 접근하지 않는다. 정확도는 A/B 동일 비중이며 검출 누락을 포함한다.

| 표본 | 반구 | 학습 A | 학습량 일치 순열 | 학습 없음 |
|---|---|---:|---:|---:|
| 주 분석 | 오른쪽 | 83.12% | 57.67% | 56.95% |
| 주 분석 | 왼쪽 | 88.80% | 55.92% | 55.79% |
| 새 잡음 | 오른쪽 | 82.64% | 57.77% | 56.82% |
| 새 잡음 | 왼쪽 | 85.75% | 56.20% | 55.21% |

주 분석에서 냄새별 학습 A−순열 통제의 정확도 차이는 오른쪽 평균 +25.45%p(57/73쌍 양수), 왼쪽 +32.88%p(68/73쌍 양수)였다. 여기서 73쌍은 동일 개체의 여러 냄새이며 독립 동물 73마리가 아니다. 생물학적 유의성 검정을 하지 않았다.

따라서 이 단순 모형 안에서 학습 효과가 분석자용 비율에만 존재하는 것은 아니다. 그러나 이 A/B 비교를 73종 전체 식별로 확대할 수 없다. 새 잡음의 원래 세기에서 나머지 냄새들이 A로 판독된 비율은 오른쪽 21.70%, 왼쪽 18.89%였다. 세기가 비슷한 B 한 개와 구분하는 것과 다양한 냄새를 모두 구분하는 것은 다른 과제다.

## 결과 2: 무자극을 강제로 A/B 판독하면 거의 A가 됐다

raw_after는 출력이 작을수록 A 점수가 크다. 따라서 무자극의 작은 출력도 A로 읽힐 수 있다. 실제로 유무 판단을 생략하면 무자극의 A 판독률은 다음과 같았다.

| 표본 | 오른쪽 | 왼쪽 |
|---|---:|---:|
| 주 분석 | 98.97% | 99.56% |
| 새 잡음 | 98.33% | 99.70% |

이 비율은 학습된 냄새의 지각이나 환각을 증명하지 않는다. 판독 정의와 작은 출력의 관계에서 예상되는 문제다. MBON 자체 유무 기준을 추가하면 무자극 A 판독률은 주 분석 오른쪽 3.48%·왼쪽 4.24%, 새 잡음 오른쪽 4.58%·왼쪽 4.84%로 줄었다. 이는 잡음 보정의 95백분위라는 판독 기준을 사용한 결과이며 생물의 성능 향상을 실험한 것이 아니다.

## 결과 3: 작은 학습 조건 차이는 남았으나 해석 범위가 제한된다

같은 MBON 자체 유무 기준 절차에서 학습량 일치 순열 통제의 무자극 A 판독률은 주 분석 오른쪽 2.59%·왼쪽 3.12%, 새 잡음 오른쪽 4.05%·왼쪽 4.11%였다. 학습 A가 통제보다 평균 약 0.53~1.12%p 높았다.

두 모의 표본과 양쪽 반구에서 같은 방향이지만 각 학습 조건마다 판독 문턱/유무 기준을 재보정했다. 따라서 이 차이는 현재 모형의 학습+판독 절차 전체의 효과다. 특정 MBON 신호의 순수 인과 효과, 실제 냄새 오인율 또는 행동적 누출로 해석하지 않는다. 이를 [동일 기준의 추가 비교](FIXED_READOUT_CRITERION.md)로 분리했다. 원래 회로의 작은 양의 잡음 차이는 같은 기준에서 반대 방향으로 바뀌었고, 항상성 회로에서는 0 근처였다. 따라서 작은 양의 차이를 출력 자체의 누출로 해석하지 않는다. 고정 기준을 통제에 옮기는 것이 통제의 최적 판독은 아니라는 제한도 함께 보고했다.

## 결과 4: 약한 신호는 누락과 혼동이 많았다

raw_after+MBON 자체 유무 기준의 약한(10%) 신호 정확도는 주 분석 오른쪽 33.18%·왼쪽 24.62%, 새 잡음 오른쪽 34.86%·왼쪽 27.95%였다. 거부를 오답으로 포함하므로 50%보다 낮은 수치를 무조건 '분류 방향이 반대'로 해석하면 안 된다. 잡음 억제 기준에서 신호를 놓치는 비용이 포함돼 있다.

주 분석에서 약한 A를 검출한 비율은 오른쪽 54.38%·왼쪽 42.74%였다. 검출된 출력도 B와 겹쳤다. 문턱과 무관한 raw 점수 A/B AUC는 약한 입력에서 오른쪽 0.682·왼쪽 0.638, 원래 세기에서는 0.918·0.959였다. 정보가 전혀 없다는 결과는 아니지만 제한된 고정 판독에서는 약한 입력을 잘 읽지 못했다. 두 세기를 섞어 보정한 하나의 스칼라 문턱이라는 가정도 원인일 수 있다.

## 결과 5: 학습 전 출력 정보와 추가 PN 정보가 결과를 바꿨다

아래는 공통 PN 유무 기준을 사용한 주 분석이다. 모두 PN의 추가 정보가 있고, privileged_fraction만 같은 입력의 학습 전 출력도 안다.

| 입력 | 반구 | raw_after | MBON/PN 정규화 | 특권 비율 |
|---|---|---:|---:|---:|
| 원래 세기 | 오른쪽 | 83.12% | 87.23% | 94.32% |
| 원래 세기 | 왼쪽 | 89.08% | 89.59% | 96.03% |
| 10% 세기 | 오른쪽 | 40.68% | 43.97% | 55.89% |
| 10% 세기 | 왼쪽 | 37.16% | 41.27% | 51.23% |

새 잡음에서도 같은 큰 경향이었다. PN 정규화는 추가 입력 규모 정보를 사용한다. 특권 비율의 우세를 실제 후속 회로의 능력이라고 간주할 수 없다. 또한 이는 25의 '약한 A 기준 절반' 누출 판정과 다른 A/B 과제이므로 기존 누출률과 숫자를 직접 대조하지 않는다.

전체 활동 항상성 조건에서도 학습 후 출력의 강한 A/B 정보는 남았다. MBON 단독 기준의 주 분석 정확도는 오른쪽 76.10%·왼쪽 81.23%였다. 보상이 판독법에 따라 기억/잡음 결과를 다르게 바꿀 수 있지만 이번 실험만으로 실제 보상 기제를 선택하지 않는다.

## 수치 검증과 재현

학습 없음의 특권 비율이 부동소수점 행렬 연산의 반올림 오차 때문에 미세한 비율 신호를 만들던 부분을 확인했다. 학습 전후 출력이 계산 오차 범위에서 같으면 변화량을 0으로 처리했고 재계산했다. 학습 없음의 비율은 이제 정확히 0, AUC 0.5다. 실제 출력 판독의 입력에는 학습 전 출력이 전달되지 않는다.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python pipelines/67_postlearning_readout.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python pipelines/67_postlearning_readout.py --validation
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python -m unittest discover -s tests -q
```

산출물은 qc_reports/postlearning_readout/와 postlearning_readout_validation/의 metrics.csv, summary.csv, controls.csv, report.json, postlearning_readout.png다. 각 표본 15,768행은 독립 실험 15,768개가 아니다. 동일 잡음의 판독값은 두 입력 세기 행에 반복된다. 원자료 체크섬과 총 학습 가중치 감소량 보존을 확인했고 전체 unittest 104개를 통과했다.

추가 산출물: 두 결과 폴더의 fixed_criterion_contrasts.csv와 fixed_criterion.png, metrics/summary의 fixed_* 열은 [고정 판독 기준 계획](FIXED_READOUT_CRITERION_PLAN.md)에 따른 기전 분리 결과다. 기존 수치는 조건별 재보정 결과로 보존했다.
