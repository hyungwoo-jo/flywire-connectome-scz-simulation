# 버섯체 연결 대조 실험

2026-10-08. Pipeline 04의 큰 활성 증가가 실제 연결 구조에 특이적인지 검증했다. 환각·기억 오류라는 명칭을 결과 변수로 사용하지 않았다.

## 추가 데이터 감사

새 입력 구분 실험에서 연결 버전의 ID는 root_888이며, 기존 04/05가 사용한 최신 root_id와 일치하지 않는 주석이 있음을 확인했다. 최신 root_id에는 중복도 있고 APL 주석의 최신 ID에는 해당 연결이 없다. 따라서 이 문서의 ‘실제 회로’는 **기존 스크립트가 추출한 실제 데이터 부분 그래프**를 뜻하며, 완전하고 정확하게 주석된 KC–APL 회로로 보증할 수 없다. 05는 기존 주장과 처리 방식을 재현해 반박하는 검증으로 보존한다. 올바른 버전 ID와 verified 전달물질을 사용한 별도 탐구는 [입력 구분 실험](INPUT_DISCRIMINATION.md)이다.

## 판단

**기존의 큰 효과는 실제 버섯체 배선에 특이적이지 않으며, 조건별 재정규화에 크게 의존한다.** 기준 gain 2.05에서 실제 회로의 활성 증가보다 큰 증가가 대조군 20개 중 14개에서 나타났다. 6개 대조군은 평균 활성 기준 0.05에서도 기존과 같은 ‘정상 0% → GABA 약화 100%’ 판정을 보였다.

정규화를 정상 조건의 값으로 고정하면 실제 회로의 활성 증가는 약 98.7% 줄었다. 따라서 기존의 ‘환각 또는 가짜 기억 0% → 100%’ 주장은 이 검증을 통과하지 못했다. 이것은 환각이 실제 초파리에 존재하지 않는다는 주장이 아니라, 해당 계산 결과로 그 해석을 뒷받침할 수 없다는 판단이다.

다만 정규화 고정 조건에서 실제 회로의 작은 GABA 반응은 이번 대조군 모두보다 컸다. 연결 구조의 역할을 전부 부정할 수는 없다. 남은 질문은 ‘이 모형에서 실제 연결 구조가 억제 변화에 대한 작은 반응을 어떻게 만드는가?’다. 환각이나 질환의 증거로 해석할 단계는 아니다.

## 설계

- 기존 스크립트와 같은 796개 뉴런, 10,767개 연결을 사용했다. ‘상위 KC’ 선택에 비-KC 10개가 포함된 문제도 재현을 위해 그대로 유지했다.
- 방향을 가진 이중 연결 교환으로 대조군 20개를 생성했다. 뉴런별 입력·출력 연결 수, 출력 가중치의 집합과 합, 전달물질 부호, 기존 자기 연결을 보존했다. 새로운 자기 연결과 중복 연결을 금지했다.
- 자기 연결을 제외한 연결 수의 10배만큼 성공적인 교환을 시행했다. 연결 상대가 바뀐 비율은 약 93.0–93.3%였다. 이것만으로 완전한 무작위 혼합을 보장하지는 않는다.
- 대조군은 입력 가중치 합과 세포 유형 사이의 연결 비율을 보존하지 않는다. 실제 회로와의 차이가 남더라도 그 원인을 상세 배선 하나로 특정할 수 없다.
- 각 회로에 같은 초기 상태 16개를 적용했다. 초기화 시드 2000–2015, 대조군 시드 7001–7020이다. 초기 상태와 대조군은 생물학적 개체 표본이 아니다.
- GABA 가중치 100%와 40%, gain 0.8/1.2/1.6/2.05/2.5, 판정 기준 0.02/0.04/0.05/0.06/0.08을 비교했다. 판정 기준은 동일한 최종 활성 값에 적용했으며 별도 동역학 조건이 아니다.
- 원래 방식인 대칭화·조건별 정규화, 대칭화·정규화 고정, 방향 보존·정규화 고정을 비교했다. 고정 정규화는 회로별 정상 GABA 행렬의 스펙트럴 반지름에 작은 epsilon을 더한 값을 기준으로 했다. 방향 보존에서는 원래 pre→post 행렬을 전치하여 입력을 합산했다.
- Euler dt=0.1, 초기 최대 2,000단계, 최대 정상 상태 잔차 기준 10^-8로 실행했다. 미수렴 조건만 최대 20,000단계로 재실행했다. 수렴은 고정점 잔차가 작다는 뜻이며 안정성이나 유일성의 증명이 아니다.

## 기준 gain 2.05 결과

아래 활성은 모형 내부의 무차원 값이며 실제 발화율 또는 행동 반응률이 아니다. 대조군 범위는 20개 회로의 최소–최대다.

| 처리 방식 | 실제 회로 정상 활성 | 실제 회로 GABA 40% 활성 | 실제 회로 활성 증가 | 대조군 활성 증가 범위 |
|---|---:|---:|---:|---:|
| 원래 방식: 대칭화·조건별 정규화 | 0.0376335 | 0.0537499 | 0.0161164 | 0.0087594–0.0219676 |
| 대칭화·정규화 고정 | 0.0376335 | 0.0378483 | 0.0002148 | 0.0000029–0.0001194 |
| 방향 보존·정규화 고정 | 0.0247369 | 0.0257011 | 0.0009642 | 0.0000564–0.0004615 |

방향 보존 조건의 실제 GABA 40% 결과는 긴 실행에서 수렴한 값이다. 16개 초기 상태 중 15개와 1개가 서로 다른 두 최종 상태에 도달했다. 학습된 기억 표상이나 행동 검증이 없으므로 이를 기억 분지나 가짜 기억으로 부르지 않는다. 원래의 대칭화 모델에서는 이런 관찰이 나오지 않았다.

원래 방식의 판정 기준 민감도도 크다. 기준을 0.02로 두면 실제 회로 두 조건 모두 100%, 0.05로 두면 0%/100%, 0.06으로 두면 모두 0%다. 판정 기준을 넘는다는 사실이 독립적인 환각 지표를 제공하지 않는다. gain 2.5에서는 정규화 고정·대칭화 조건도 두 조건 모두 평균 활성 0.05를 넘는다.

이 검증은 기존 그림을 확인한 뒤 설계한 탐색 실험이다. 대조군 수가 20개이고 여러 gain을 탐색했으므로, 실제 회로가 대조군 모두보다 크다는 관찰에 확정적인 통계적 유의성이나 생물학적 타당성을 부여하지 않는다.

## 수렴 및 재현

630개 조건 중 처음에는 154개가 잔차 기준을 통과하지 못했다. 긴 실행 후 600개가 통과했고, 남은 30개는 모두 대칭화 모델의 대조군 gain 1.2 조건이었다. 해당 30개는 정상 상태로 해석하지 않고 최종 비교 그림에서 제외했다. **핵심 gain 2.05 비교와 실제 회로의 모든 조건은 기준을 통과했다.**

입력 파일 체크섬과 Python·패키지 버전은 `qc_reports/connectome_null_control/environment.json`에 기록했다. 원본 결과와 긴 실행 결과를 별도 파일로 보존했다. 원래 네 가지 분석 스크립트와 기존 그림은 수정하지 않았다.

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
  .venv/bin/python pipelines/05_connectome_null_control.py \
  --nulls 20 --initializations 16
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
  .venv/bin/python pipelines/05_connectome_null_control.py \
  --refine --max-steps 20000
.venv/bin/python -m unittest discover -s tests -v
```

결과 디렉터리는 `qc_reports/connectome_null_control/`이다. `results.json`과 `summary.csv`는 초기 실행, `refined_results.json`과 `refined_summary.csv`는 미수렴 조건을 재검증한 결과다. `refined_paired_effects.csv`는 조건 간 활성 차이, `refined_null_control.png`는 비교 그림이다.

데이터는 별도 확보해야 한다. 이 실험은 BANC v888의 `banc_888_meta.feather`와 `banc_888_edgelist_simple_v2.feather`를 사용한다. FlyWire v783 분석으로 해석하지 않는다. 데이터 출처는 [BANC 공식 프로젝트](https://github.com/htem/BANC-project/)를 참고한다.

## 다음 판단 기준

기존 환각 해석은 보류하는 것이 맞다. 연구를 이어간다면 전달물질·세포 유형별 연결 비율까지 보존한 대조군과 입력 가중치 합을 통제한 비교로 남은 작은 효과가 유지되는지 확인해야 한다. 그 효과가 유지될 때 학습된 표상의 재생 오류를 별도로 정의하고 시험할 근거가 생긴다. 현 단계에서 모델과 그림을 더 복잡하게 만드는 것만으로 환각 해석의 문제가 해결되지는 않는다.
