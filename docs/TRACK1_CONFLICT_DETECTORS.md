# 갈래 1: 갈등 감시 뉴런은 실제로 작동할 수 있는가 (47)

2026-10-10. 개인 프로젝트의 탐색 분석이다(`pipelines/47_conflict_detectors.py`). 46에서 "두 기억이 같은 방향으로 입력을 바꾸는" 뉴런 15개를 갈등 감시 후보로 찾았다. 이번에는 이 뉴런들이 고정된 문턱 하나로 "두 기억이 함께 왔을 때"와 "하나만 왔을 때"를 실제로 구분할 수 있는지 봤다.

## 방법

- 46과 같은 설정: 냄새 A는 처벌, B는 보상과 짝지어 학습. 대상은 비교기 84개와 통합 뉴런 12개.
- 무작위 냄새 60쌍 중 30쌍으로 뉴런마다 문턱 하나를 정하고(섞인 자극 대 단일 기억의 균형 정확도 최대), 나머지 30쌍에서 평가했다.
- 지표(실행 전 고정): 평가 쌍에서의 AUC와 균형 정확도. AUC 0.8 이상이고 균형 정확도 0.75 이상이면 "감시기".
- 대조: 출력 뉴런 53개의 도파민 구역 배정(처벌/보상)을 개수를 유지한 채 무작위로 섞기 100회.

## 결과

| | 실제 배선 | 구역 무작위 대조 |
|---|---:|---:|
| 감시기 기준 충족 뉴런 수 | 0 | 평균 0 |
| 가장 높은 AUC | 0.726 (CRE042) | 평균 0.731 (95백분위 0.753), p 0.69 |
| 상위 5개 AUC 평균 | 0.709 | 평균 0.718 (95백분위 0.737), p 0.82 |

상위 뉴런: CRE042 0.73, CB1079 0.72, MBON06 0.70, CB4159 0.70, CB1079(다른 개체들) 0.69~0.70. 대부분 "섞이면 입력이 더 줄어드는(억제형)" 방향이고, MBON06과 통합 뉴런 일부는 "섞이면 입력이 더 느는(활성형)" 방향이었다.

## 판단

- **고정 문턱 하나로 갈등을 안정적으로 감지하는 뉴런은 없다.** 최고 AUC가 0.73 정도로, 섞인 자극을 어느 정도 구분하지만 신뢰할 수준은 아니다. 냄새 쌍마다 변화의 크기가 크게 달라서 문턱 하나로 나누기 어렵다.
- **그 정도의 구분 능력도 실제 배선에 특별하지 않다.** 도파민 구역을 무작위로 배정해도 같은 수준이 나왔다.
- 46의 "AND 가능" 구조는 전용 회로라기보다, (1) 냄새를 섞으면 두 냄새의 KC 반응이 함께 들어가고 (2) 학습은 연결을 약하게만 만든다는 두 성질에서 나오는 일반적인 결과다.
- 따라서 **초파리 회로에서 ACC식 "전용 갈등 감시기"의 근거는 이 분석에서 나오지 않았다.** 45의 결론(초파리는 처벌과 보상을 더해 순 가치로 정리한다)이 유지된다.

## 한계

- 출력 뉴런 이후는 한 단계 선형 전달이다. 시간 차이(한 기억이 먼저 오고 다른 기억이 나중에 오는 경우), 여러 단계의 비선형성, 되먹임은 없다.
- 실제 갈등 상황(두 냄새가 같은 위치에서 섞여 오는 경우)만 봤다. 두 냄새가 다른 방향에서 오는 공간적 갈등은 다루지 않았다.
