# 사전 등록: 72 단계 (식별과 간섭을 함께 최적화한 확장층)

2026-10-19. **어떤 결과도 계산하기 전에 작성했다.** 갈래 2의 셋째 단계다.

71의 결과는 두 가지였다.

- 식별만으로 학습하면 KC 입력 세기의 불균일성(CV)이 실제 배선(0.63~0.84)보다 커진다.
- 불균일성을 줄이면 간섭이 준다.

여기서 사후 가설이 나왔다. "실제 배선의 불균일성은 식별과 간섭의 절충점이다." 72는 이 가설을 검정한다. 손실에 간섭 벌점 λ·D를 더해 학습하고, 다음 두 가지를 본다.

1. 실제 CV 근처에서 멈추게 하는 λ가 다섯 반구에 공통으로 있는가.
2. 71에서 본 늦은 CV 증가가 과제 효과인가, 최적화기 표류인가(표지 섞기 대조).

## 공통

학습 설정은 71 B와 같다.

- **회로:** 다섯 반구다.
- **학습 대상:** 대응 PN→KC 로그 가중치(연결 유무 고정)와 냄새 73종 softmax 판독이다.
- **기울기:** APL 억제량을 상수로 둔다.
- **최적화:** Adam 학습률 0.01, 1,500단계, 냄새당 4시행이다.
- **제약:** 전체 가중치 합을 고정하고, 50단계마다 문턱을 10%로 재보정한다.

λ = 0이고 표지를 섞지 않은 조건은 71 B와 같은 시드를 쓴다. 따라서 71 B를 그대로 재현해야 한다(재현 확인).

## 간섭 벌점 D

25의 간섭(specific)은 두 누출의 차이다.

- **학습된 누출:** 냄새 하나에 KC→MBON 학습을 했을 때, 학습된 가치가 자발 활동 시행(냄새 없음)에 나타나는 비율이다.
- **대조 누출:** 같은 수의 KC를 무작위로 골라 학습했을 때의 같은 비율이다.

specific이 크다는 것은 자발 활동에서 켜지는 KC가 냄새에 반응하는 KC와 겹친다는 뜻이다. 25의 지표는 문턱을 써서 미분할 수 없다. 그래서 겹침을 직접 재는 미분 가능한 대리 지표를 쓴다.

- t_i: 냄새 73종의 깨끗한 반응에서 KC i의 평균 활동
- n_i: 자발 활동 시행에서 KC i의 평균 활동
- D = (Σ t_i n_i / Σ t_i) / mean(n) − 1

D는 냄새 반응 KC에서 평균한 자발 활동이 전체 평균보다 몇 배 높은지를 뜻하며, 단위가 없다. 학습 중 자발 활동 시행은 단계마다 64개를 새로 뽑는다. 평가에 쓰는 25의 고정 표본(500시행)과 겹치지 않게 시드를 따로 쓴다.

손실은 교차 엔트로피 + λ·D이고, λ ∈ {0, 0.1, 0.3, 1, 3, 10}이다. 이 격자는 크기만 보고 정했다. D는 단위가 없고 O(0.1~1)으로 예상되며, 71의 최종 교차 엔트로피는 0.03~0.07이었다. 결과를 보고 고르지 않았다.

## 지표

끝(1,500단계)에서 잰다.

- KC 입력 세기 CV
- 69의 식별(원형 분류)
- 25의 간섭 specific(`p25.evaluate`, 평가용 고정 표본)
- 대리 지표 D(평가용 고정 표본)

CV는 250, 500, 1000, 1500단계에서도 기록한다.

## 판정

**C0 (대리 지표의 타당성, 선결 조건):**
- 71 A의 조절기 여섯 점(α)에서 D를 잰다. 시드와 배선은 71 A와 같다.
- 71 A의 specific과의 Spearman ρ가 0.9 이상인 반구가 4개 이상이어야 한다.
- 실패하면 C2~C4는 "D를 줄였을 때"로만 해석한다. 이때 간섭에 관한 결론은 내지 않는다.

**C1 (벌점이 작동한다):**
- 실제 시작점에서 λ(6점)와 최종 specific의 Spearman ρ가 -0.9 이하인 반구가 4개 이상이면 지지한다.

**C2 (벌점이 불균일성을 줄인다):**
- 실제 시작점에서 λ와 최종 CV의 ρ가 -0.9 이하인 반구가 4개 이상이면 지지한다.

**C3 (주 가설: 공통 λ):**
- 반구마다 실제 시작점의 최종 CV를 log λ에 대해 선형 보간한다(λ > 0인 다섯 점).
- 최종 CV가 그 반구의 실제 CV와 같아지는 λ*를 찾는다. 실제 CV가 다섯 점의 최종 CV 범위 밖이면 λ*는 정의되지 않는다.
- 지지 조건(둘 다 충족):
  - λ*가 정의된 반구가 4개 이상이다.
  - 정의된 λ*의 최댓값/최솟값이 3 이하다.

**C4 (시작점과 무관한 수렴):**
- 각 반구에서 λ*에 가장 가까운 격자 λ를 쓴다(λ*가 없으면 해당 반구 실패).
- 실제와 고르게 한 시작점의 최종 CV 차이가 처음 차이의 절반 미만인 반구가 4개 이상이면 지지한다.

**D1 (표류 대조):**
- 표지를 섞은 학습의 CV 변화를 정상 학습(λ = 0, 실제 시작점)의 CV 변화와 비교한다. CV 변화는 끝 − 시작이다.
- 섞은 학습의 CV 변화가 정상 학습의 절반 이상인 반구가 3개 이상이면, 다음 결론을 표류에 오염된 것으로 표시한다.
  - 71의 B1과 B3
  - 72의 C2~C4
- 오염으로 표시되면 250단계 값으로 같은 판정을 다시 계산해 함께 보고한다.

## 보고만

- 각 λ에서 시작점별 최종 식별, specific, D와 학습 곡선
- C3가 지지될 때, λ*에서의 식별이 실제 배선의 식별(0.945~0.970)보다 높은가
- λ = 0 조건이 71 B를 재현하는지(최종 CV가 같은지)

## 해석의 한계 (미리 적음)

- C3가 지지되더라도 이는 매개변수 하나를 다섯 반구에 맞춘 결과다. 다섯 반구는 독립적이지 않다. 반구 다섯 개는 세 데이터셋에서 왔고, 그중 둘은 좌우 쌍이다.
- 대리 지표 D, 전체 가중치 합 고정, 문턱 재보정은 모두 설계 선택이다. 결과는 이 선택에 조건부다.
- 학습 규칙은 경사하강법이다. 실제 발달 과정을 주장하지 않는다. 주장할 수 있는 것은 "이 목적함수의 최적점이 실제 배선의 불균일성과 맞는가"뿐이다.
