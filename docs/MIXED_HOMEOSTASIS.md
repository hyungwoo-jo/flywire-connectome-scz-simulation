# 냄새 기준과 자발 기준 항상성의 혼합 (57)

## 질문

55의 냄새 반응 기준 문턱 항상성은 기억을 높였지만 BANC에 누출을 남겼다. 56의 자발 입력 기준 문턱은 누출을 없앴지만 기억을 낮췄다. 둘을 섞으면 두 목표를 함께 만족하는 지점이 있는지 봤다.

- **주 조건:** theta(beta) = (1 - beta) theta_odor + beta theta_spont에 공통 이동을 더해 활성 10%로 맞췄다.
- **탐색 조건:** KC가 냄새와 자발 상태를 구분하지 않고 자기 전체 평균 활동을 맞춘다. 냄새 시행 비율을 rho로 두었다. rho 1이 55의 문턱 항상성이다.

## 판정을 읽을 때 주의할 점 (사후)

사전 등록한 누출 기준은 "0.3% 이하"라는 한쪽 기준이었다. 실제로는 beta 0.2~0.6에서 FlyWire와 hemibrain의 냄새 특이 누출이 -0.3~-1.3%로 **음수**가 됐다. 학습한 냄새보다 무작위 KC 집합이 잡음 시행에서 더 많이 나타난다는 뜻이다. 27, 53, 55의 세기 평평과 같은 과보상이다. P3a가 기각된 것도 누출이 0을 지나 음수로 갔다가 다시 0으로 돌아오는 U자 모양 때문이다.

양쪽 기준(절대값 0.3% 이하)으로 다시 보면 다음과 같다. 판정에는 쓰지 않는다.

| 조건 | 두 목표를 만족한 반구 |
|---|---|
| beta 0 (55) | FlyWire 두 반구, hemibrain (3/5) |
| beta 0.2 | BANC 두 반구 (2/5) |
| beta 0.4~1 | 0~1/5 |
| 전체 활동 rho 0.1 | BANC 두 반구, hemibrain (3/5, FlyWire는 -0.39%, -0.49%) |
| 전체 활동 rho 0.01 | **5/5** (-0.11~0.25%, 기억 +0.7~+3.2%p) |

- 선형 혼합에서는 회로마다 맞는 beta가 다르다. BANC는 0.2 근처, FlyWire와 hemibrain은 0이다. 하나의 공통 beta로는 다섯 반구를 함께 맞추지 못한다.
- 전체 활동을 보는 항상성은 회로마다 따로 조율하지 않아도 다섯 반구를 함께 맞췄다(rho 0.01). 자발 시행이 대부분인 조건에서는 자발 입력이 큰 KC가 스스로 문턱을 높이므로, 입력 불균일이 큰 BANC에서는 자동으로 더 강하게 보정된다.
- rho를 낮출수록 누출은 0에 가까워지고 기억 이득은 줄었다(rho 1: +4~8%p, rho 0.1: +3~8%p, rho 0.01: +1~3%p).

## 해석

1. **두 목표의 공존 지점이 있다.** 냄새 기준 항상성에 자발 기준을 조금만 섞으면(beta 0.2) BANC의 남은 누출이 사라지고 기억 이득은 거의 그대로였다. 자발 기준을 더 섞을수록 기억은 단조로 떨어졌다.
2. **선형 혼합은 과보상을 만든다.** BANC에 맞는 혼합 비율은 FlyWire와 hemibrain에서 누출을 반대 방향으로 뒤집는다. 이때 무작위 통제 누출(학습 일반의 흔적)은 오히려 커졌다(beta 0.2에서 0.8~2.0%).
3. **전체 활동 항상성이 가장 자연스러운 답이다.** 세포가 자발 상태가 대부분인 환경에서 자기 평균 활동을 맞추기만 하면(rho 0.01), 회로마다 따로 맞추지 않아도 다섯 반구 모두 냄새 특이 누출이 ±0.3% 안에 들고 기억은 원래보다 낮지 않았다. 생물학적으로도 KC는 냄새와 자발 활동을 구분하지 않는다.
4. **남는 상충.** 전체 활동 항상성에서도 냄새 시행 비율이 낮을수록 누출은 줄고 기억 이득은 작아진다. 실제 파리의 냄새 노출 비율과 항상성 시간 척도가 이 자리를 정할 것이다. 이 모형은 그 값을 알려 주지 않는다.
