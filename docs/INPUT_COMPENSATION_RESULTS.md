# 부분 보상 최적 가설의 독립 검정 (29)

2026-10-09. [사전 등록](PREREGISTRATION_29.md)에 따라 실행했다.

## 질문

27에서 문턱 보상의 강도를 바꾸자 "중간 보상이 최적(U자형)"이라는 사후 관찰이 나왔다. 이번에는 KC별 추정이 필요 없는 입력 강도 보상(KC 입력 가중치 x (평균 / S_i)^α)으로 같은 관찰이 재현되는지 봤다.

## 결과

| α | 오른쪽 누출 (학습 / 통제) | 오른쪽 d' | 왼쪽 누출 (학습 / 통제) | 왼쪽 d' |
|---|---|---:|---|---:|
| 0 | 3.49% / 0.06% | 18.3 | 3.71% / 0.01% | 18.2 |
| 0.25 | 2.08% / 0.12% | 19.6 | 2.86% / 0.06% | 18.8 |
| 0.5 | 1.47% / 0.43% | 21.0 | 1.88% / 0.29% | 20.1 |
| 0.75 | 0.98% / 0.53% | **21.4** | 1.07% / 0.76% | **21.1** |
| 1 | **0.83%** / 0.90% | 19.8 | **0.75%** / 1.35% | 19.9 |

α = 0은 25와, α = 1은 26과 정확히 같았다(재현 점검).

## 사전 등록 판정

규칙상 판정은 **"불일치"**다. 사전에 정한 범주(둘 다 중간 최적 / 누출만 중간 최적 / 둘 다 완전 보상 최적)에 해당하지 않았기 때문이다. 그러나 두 반구는 서로 일치했다.

- **누출: 중간 최적이 아니다.** 두 반구 모두 학습 누출은 α에 따라 단조롭게 줄었고 α = 1에서 최소였다.
- **구분: 중간 최적이다.** 두 반구 모두 d'은 α = 0.75에서 최대였고, α = 1보다 1.6(오른쪽), 1.2(왼쪽) 높았다(기준 0.3).

미리 정한 범주에 "구분에서만 중간 최적"을 넣지 않은 것은 사전 등록 설계의 누락이다.

## 27과 합친 해석

| | 문턱 보상 (27) | 입력 보상 (29) |
|---|---|---|
| 학습 누출 최소 | 중간 (α 0.5~0.75) | 완전 보상 (α 1) |
| 구분 최대 | 중간 (α 0.75) | 중간 (α 0.75) |
| 무작위 통제 누출 | α와 함께 증가 | α와 함께 증가 |

1. **구분의 중간 최적은 두 방식, 두 반구에서 모두 나타났다.** 허브를 어느 정도 누르는 것은 구분을 높이지만, KC 입력을 완전히 같게 만들면 오히려 떨어진다. 이 결론은 비교적 견고하다.
2. **누출의 U자형은 문턱 방식에서만 나타났다.** 문턱 방식에서 완전 보상의 누출이 다시 늘어난 것은, 보정용 냄새 37개로 KC별 문턱을 추정하며 생긴 잡음이나 문턱 방식 고유의 특성 때문일 가능성이 크다. 입력 방식에서는 보상이 강할수록 누출이 줄었다.
3. **두 방식 모두, 보상이 강할수록 무작위 통제의 누출(비특이 누출)이 늘었다.** α = 1에서는 통제 누출이 학습 누출과 비슷하거나 더 커서, "배운 냄새가 특별히 새어 나오는" 현상은 사라지고 대신 어떤 학습이든 조금씩 섞여 나오는 상태가 된다.

## 결론

- **확립:** 허브 KC를 누르는 보상은 학습된 냄새 특이적 누출을 줄인다(26, 27, 29). 구분은 부분 보상에서 가장 좋다(27, 29).
- **확립 안 됨:** 누출 자체가 부분 보상에서 최소라는 것(27에서만).
