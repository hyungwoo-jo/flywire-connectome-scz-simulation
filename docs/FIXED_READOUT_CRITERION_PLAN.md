# 67 후속: 판독 기준 고정으로 신호 변화와 기준 이동 분리

2026-10-18. 조건별 판독을 재보정한 67 결과를 본 뒤, 아래 추가 비교를 계산하기 전에 작성했다. 사후 기전 감사이며 새 확증 실험이 아니다.

주 분석과 추가 잡음 표본 각각에서 learned_A 조건의 판독 문턱과 MBON 잡음 유무 문턱을 보정 자료로 정한다. 그 문턱을 matched_shuffle 및 none 조건에도 그대로 적용한다. 평가 시행의 학습 전 출력이나 정답을 사용하지 않는다. PN 유무 문턱은 원래 학습 조건에 무관하므로 그대로 쓴다.

각 조건을 자기 자료로 다시 보정한 adaptive 결과와 fixed_A 결과를 나란히 보고한다. 기본 확인은 raw_after + mbon_gate이며 잡음 A 판독률, 잡음 검출률, 강한/약한 A/B 정확도를 본다. 동일 판독 기준으로 남는 차이는 이 모형의 학습 가중치 배치에 따른 출력 변화의 결과이고, 재보정할 때만 남는 차이는 판독 기준 적응이 포함된 효과다.

learned_A 기준을 다른 조건에 옮기는 것은 기전 분리용 개입이다. 모든 조건의 최적 판독 능력을 공정하게 비교하는 실험은 아니며 실제 동물의 판독 기준 적응을 측정한 것도 아니다. 생리·행동·질환 결론을 내리지 않는다.
