# 사전 등록: 22 단계 (왼쪽 반구 재현)

2026-10-09. **왼쪽 반구 결과를 보기 전에 작성했다.** 왼쪽 회로의 연결 수와 APL 후보 확인 외에는 왼쪽 자료로 아무 계산도 하지 않았다.

## 목적

16~21의 결과는 모두 BANC **오른쪽** 버섯체 하나에서 나왔다. 같은 개체의 왼쪽 버섯체는 PN->KC 배선이 독립적으로 만들어진다(KC의 PN 선택은 개체 사이, 좌우 사이에 고정되어 있지 않다고 보고됨). 그래서 왼쪽은 독립된 재현 표본이 된다. 특히 21의 에스테르 일반화 결과는 보조 지표에서 나온 것이므로 확증이 필요하다.

## 왼쪽 회로 구성 (사전 고정)

- KC: `cell_class == kenyon_cell`, `side == left` (2,260개).
- PN: 오른쪽과 같은 규칙(verified acetylcholine 투사뉴런 중 왼쪽 KC로 연결되는 것).
- **APL:** 왼쪽에는 APL 주석이 없다. 왼쪽 KC로부터 입력 시냅스를 가장 많이 받는 뉴런 `720575941734526507`을 왼쪽 APL로 쓴다. 근거는 다음과 같다. 왼쪽 KC 2,140개에서 9,261개 시냅스를 받고, 왼쪽 KC 2,107개로 10,653개를 되돌려 보낸다. 오른쪽 APL은 2,126개에서 10,678개를 받고 2,097개로 12,160개를 보낸다. 교정 완료(proofread) 표시가 있다. 주석이 아닌 연결로 추정한 것이므로 결과 문서에 명시한다.
- 정규화, 수용체->사구체 대응, PN 감사 규칙(다중 사구체, 주석 접두사 충돌 제외), Olsen 변환은 오른쪽과 같다.
- **보정:** 같은 보정용 냄새 37개로 왼쪽 회로의 theta를 활성 KC 10%(민감도 5%)에 맞춰 따로 정한다.
- 냄새 분할, 잡음 시드, 시행 구성, 지표 계산은 18, 21과 같다.

## 재현 검정과 판정

각 검정은 왼쪽 회로에서 오른쪽과 같은 절차로 계산한다.

**R1 (17 재현, 과수렴 구조).** PN 유형 쌍 공동 수렴을 강도 보존 대조 1,000개와 비교한다(시드 220001~221000). Z > 3.29 쌍의 수가 가상 관측 대조 분포보다 많으면(p < 0.05) "재현". 추가로 DM1-DM4 쌍의 Z를 보고한다(Z > 3.29면 "최강 쌍 재현").

**R2 (18 재현, 범용 구분의 불리함).** 실제 왼쪽 배선 대 N0 대조 100개(시드 222001~222100), 주 조건(0.5 s, 10%) d'. z <= -1.96이면 "재현", -1.96 < z < 0이면 "같은 방향, 유의하지 않음", z >= 0이면 "재현 실패".

**R3 (21 재현, 에스테르 일반화).** 21과 같은 균일 판독, eta 5의 CI_ester. 같은 N0 대조 100개를 쓴다. z >= 1.96이면 "재현", 0 < z < 1.96이면 "같은 방향, 유의하지 않음", z <= 0이면 "재현 실패". 21의 주 지표 CI도 함께 보고한다.

세 검정은 서로 독립된 판정이다. 다중 비교 보정은 하지 않고, 각각을 개별 재현 시도로 보고한다.
