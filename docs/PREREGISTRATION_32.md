# 사전 등록: 32 단계 (실제 배선 안의 보상)

2026-10-09. **결과를 보기 전에 작성했다.** 배선 자료만 쓴다.

## 배경

27, 29에서 KC 사이의 보상을 모형에 넣었다. 실제 초파리에서는 KC마다 받는 PN 입력의 수(클로 수)가 다르고, 이를 보상하는 특성 변이가 있다는 보고가 있다(Abdelrahman, Vasilaki, Lin 2021). 보상의 일부가 배선 자체에 들어 있다면, PN 연결이 많은 KC일수록 연결당 시냅스 수가 적어야 한다. BANC에서 이를 직접 확인하고, 실제 배선이 보상 축의 어디쯤에 있는지 추정한다.

## 방법

- 각 반구의 모든 PN->KC 연결(verified acetylcholine PN 전부)을 쓴다.
- KC마다 n = 연결된 PN 수, S = PN에게서 받는 시냅스 총수, s = S / n(연결당 평균 시냅스)를 구한다. n >= 1인 KC만 쓴다.
- **회귀:** log s = a + b log n (최소제곱). b < 0이면 연결이 많은 KC일수록 연결당 시냅스가 적다(배선 수준의 보상). b = 0이면 보상 없음, b = -1이면 총입력 S가 n과 무관(완전 보상)이다.
- **유효 보상 강도:** α_eff = -b. 29의 입력 보상 α와 같은 축은 아니지만(29는 대응 PN 입력 총량 기준), 같은 방향의 지표다.
- KC 하위 유형별로도 계산한다(보조).
- 비교 대조: 강도 보존 대조는 KC별 n과 S를 보존하므로 쓸 수 없다. 대신 PN별 연결 시냅스 수를 KC 사이에서 섞는 순열(KC의 n은 그대로, 각 연결의 시냅스 수를 전체 연결에서 무작위 재배정, 1,000회, 시드 320001~)로 b의 영분포를 만든다.

## 판정

- **H32.** 두 반구 모두 b < 0이고, 순열 영분포 대비 단측 p < 0.05면 "실제 배선에 보상이 들어 있다".
- α_eff를 보고하고, 0~0.25, 0.25~0.75, 0.75 이상 중 어디에 있는지 기술한다.

## 한계

- 시냅스 수는 연결 강도의 근사다. 실제 보상은 시냅스 강도, 수상돌기 성질, 흥분성 등에서도 일어난다.
- 클로 수는 PN 연결 수로 근사했다. 한 PN이 한 KC에 여러 클로를 만들 수도 있다.
