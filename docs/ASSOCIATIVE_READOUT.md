# KC→MBON 학습 출력 탐구

2026-10-08. 입력 표상이 구별되는지 보는 단계에서, **경험에 따라 연결 가중치가 변하고 새 입력에 반응하는지** 보는 단계로 진행했다. 실제 행동·기억 회로나 조현병을 검증한 실험은 아니다.

## 회로와 학습 규칙

앞 단계의 BANC v888 우측 PN/KC/APL 회로를 유지하고 root_888로 KC→MBON 연결을 추가했다. KC가 10개 이상 연결된 우측 MBON 39개, 연결 7,362개, 예측 시냅스 13,307개를 포함한다. KC 1,827개가 이 출력 회로에 연결된다.

주 분석 대상은 결과를 보기 전에 KC 입력 시냅스 수가 가장 많은 MBON11(root_888=720575941586084230)로 정했다. 이 세포는 KC 1,027개에서 총 2,775개 시냅스를 받는다. 다른 MBON도 전부 평가해 결과를 저장했다. MBON의 출력 전달물질을 흥분/억제 행동으로 바꾸지 않았고, 미확인 전달물질을 임의 지정하지 않았다. 모사한 것은 verified acetylcholine KC의 MBON 입력까지다.

[Hige 등, 2015](https://pubmed.ncbi.nlm.nih.gov/26637800/)의 KC→MBON 가소성 실험과 [Aso·Rubin, 2016](https://elifesciences.org/articles/16135v1)의 구획별 학습 규칙을 출발점으로 삼았다. 이번에는 다음 하나의 단순 규칙만 구현했다.

```text
W_after = W_before × exp(−eta × gate × mean_training_KC)
```

학습 신호가 있는 동안 활성화된 KC의 연결이 약해진다. gate=0이면 연결은 그대로다. eta=5/20을 비교했고, 단위와 시간 경과는 임의의 모형 계수다. 평균 KC 활동을 사용하므로 노출 시간과 학습률은 분리되지 않는다. 실제 DAN 연결, 도파민 농도, 수용체 반응이나 장기 유지 동역학을 구현하지 않았다. 여러 MBON을 동일한 추상 신호로 가소성 평가하는 가정이며 실제로 모두 같은 DAN의 신호를 받는다는 주장이 아니다.

MBON마다 원래 입력 시냅스 수의 합으로 한 번만 나눴고 **학습 후에는 다시 정규화하지 않았다.** 원래 없는 연결은 새로 만들지 않는다.

## 학습과 평가의 분리

- 입력 8쌍 × 겹침 25/60/90% × 잡음 0.1/0.4를 사용했다.
- A/B 각각 80회 중 40회는 학습·판독 기준 결정, 나머지 40회는 별도 평가에 사용했다.
- 학습 신호 없음, A에만 학습 신호, B에만 학습 신호를 비교했다. B 학습은 변화의 방향이 자극에 따라 반대로 움직이는지 확인하는 대조다.
- 학습 때 APL 정상/제거, 평가 때 APL 정상/제거를 분리한 네 조합을 비교했다.
- KC→MBON 출력 대조군 5개는 같은 가중치의 연결 대상을 교환했다. KC별 출력 연결 수·가중치 집합과 MBON별 입력 연결 수·가중치 합을 보존했다. PN/KC/APL은 바꾸지 않았다.
- MBON 활동이 낮을수록 A라고 판정하는 단순 판독을 사용했다. 문턱은 학습 때의 A/B 출력으로 정확도가 가장 높아지도록 정했고 평가 때 바꾸지 않았다. 이 문턱 적합 자체도 A/B 라벨을 사용하는 외부 판독 절차다. 실제 생물학적 결정 회로가 아니다.

총 269,568개 출력 단위·조건 조합을 기록했다. 이 수는 269,568개의 독립 표본 또는 서로 다른 생물학적 개체가 아니다.

## 결과: 학습의 기본 동작

정상 APL로 학습·평가, eta=20, 큰 잡음 조건에서 주 MBON의 입력 8쌍 평균이다.

| 입력 겹침 | 학습 없음 정확도 | A 학습 정확도 | 학습 없음 AUC_A | A 학습 AUC_A | B 학습 AUC_A |
|---|---:|---:|---:|---:|---:|
| 25% | 54.38% | 96.56% | 0.467 | 0.991 | 0.001 |
| 약 60.7% | 55.16% | 83.44% | 0.494 | 0.931 | 0.069 |
| 약 89.3% | 51.72% | 61.72% | 0.507 | 0.682 | 0.331 |

AUC_A는 낮은 MBON 출력이 A와 B 중 어느 쪽에 더 자주 나타나는지 순위를 비교한다. 0.5는 방향성 없는 구분, 1은 A 쪽으로 완전한 구분, 0은 B 쪽으로 완전한 반대 방향이다. **B 학습의 작은 AUC_A는 B 학습 실패가 아니라 방향이 반대로 바뀐 결과**다. B를 알아보는 방향으로 읽으면 해당 AUC는 1−AUC_A다.

높은 겹침에서 A 학습 후 새 A의 평균 MBON 활동은 약 0.00380, B는 0.00502였다. 학습 전에는 약 0.04082/0.04078이었다. 실제 연결의 활동을 통해 변화가 입력 특이적으로 생기는 기본 동작은 확인했다. 그러나 활동에 따라 연결을 약화시키는 규칙을 가정했으므로 가소성의 존재 자체를 발견한 실험은 아니다.

## 실제 배선이 특별한가

높은 겹침·큰 잡음에서 A 학습의 실제 회로 정확도 61.72%는 대조군별 평균 60.78~64.84% 범위 안이었다. AUC_A=0.682도 대조군 0.658~0.698 범위 안이었다. 이번 판독과 학습 규칙에서 실제 상세 배선의 특별한 우수성을 확인하지 못했다. 대조군 수가 5개인 탐색이며 이 범위는 신뢰구간이 아니다.

억제가 학습·평가 내내 제거됐을 때 같은 어려운 조건의 정확도는 60.94%였다. 정상 억제로 학습한 뒤 평가에서만 억제를 제거하면 50.47%, 제거 상태로 학습한 뒤 정상 억제로 평가하면 52.03%였다. 학습과 평가 사이의 출력 크기 변화 및 고정된 판독 문턱의 영향일 수 있다. 이 변화를 즉시 기억 손상이나 질환으로 특정하지 않는다. AUC_A는 각각 다른 값으로 움직이므로 문턱 문제와 표상의 순위 변화도 구분해야 한다.

## 무자극에서 드러난 판독 문제

정확한 0 입력에서 KC와 MBON 출력은 0이다. 판독은 ‘MBON 출력이 작으면 A’이므로 무자극이 전부 A로 판정됐다. **학습 신호가 없는 대조군도 같았다.** 따라서 학습으로 생긴 가짜 기억의 증거가 아니다. A/B 강제 분류기를 입력이 없을 때도 적용한 구조적 오류다.

다음 검증은 입력 존재를 먼저 확인하는 외부 기준을 넣어 이 오류가 줄어드는지, 대신 약한 실제 신호를 얼마나 놓치는지 비교하는 것이다. 실제 감각 판정 회로를 모델링한 것은 아니며, 이 기준 자체의 가정을 명시해야 한다.
