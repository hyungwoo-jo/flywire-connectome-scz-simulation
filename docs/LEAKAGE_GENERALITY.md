# 누출은 확장층 회로의 일반 성질인가 (53)

2026-10-12. 개인 프로젝트의 탐색 분석이다(`pipelines/53_leakage_generality.py`). 지표는 실행 전에 스크립트 머리말에 고정했다. 43의 누출 식(허브 인자 H)이 초파리 배선 없이, 일반적인 확장층 회로에서도 같은 법칙을 따르는지 봤다.

## 모형

- 입력 채널 50개 -> 세포 2,000개. 세포 i는 K_i개 채널을 무작위로 고르고(평균 K, 변동계수 CV_K), 연결 세기는 로그정규분포(변동계수 CV_w)를 따른다. 초파리 배선은 쓰지 않았다.
- 모든 채널은 자발 활동 1을 가진다. 잡음 시행에서는 이 값이 무작위로 흔들리고, 자극은 채널 30%에 추가 활동을 준다.
- 문턱 하나로 자극 때 세포 10%가 켜지게 했고, 잡음 시행에서 0.3%가 켜지도록 잡음 크기를 맞췄다(FlyWire 오른쪽 실측값).
- 조건: K 3, 7, 15 x CV_K 0, 0.5 x CV_w 0, 0.35, 0.7. 각 조건에 (a) 보상 없음, (b) 세포별 입력 총량을 같게 맞춤, (c) 세포별 문턱 조절(각 세포가 자극의 10%에서 켜지게). 회로 10개 x 자극 40개.

## 결과

보상 없는 회로(회로 10개 중앙값):

|---|---|---|---:|---:|
| 3, 7, 15 | 0 | 0 | 0 | 0.97~0.99 |
| 3, 7, 15 | 0 | 0.35 | 0.09~0.20 | 3.3~3.9 |
| 3, 7, 15 | 0 | 0.7 | 0.18~0.40 | 8.0~12.7 |
| 3, 7, 15 | 0.5 | 0~0.7 | 0.57~0.80 | 14.3~20.7 |

| 지표 | 결과 | 사전 예측 | 판정 |
|---|---|---|---|
| 입력 총량 변동계수와 H의 순위 상관 (18개 조건) | 0.74 (p 0.0005) | 0.8 초과 | 근소 미달. 변동계수 0.4 이상에서 H가 포화(15~20)하고 K에 따른 차이가 있어서 |
| 입력 총량을 같게 맞춘 회로의 H | 중앙값 1.32 (최대 3.6) | 1에 가깝고 2 미만 | 중앙값은 충족, 최대는 미충족 |

| 초파리와 비슷한 조건 (K 3, CV_K 0.5, CV_w 0.7) | H 14.3 | 실측 5~12 (43) | 같은 크기 범위, 약간 큼 |

## 해석

1. **세포 사이 입력 차이가 0이면 누출이 없고(H 약 1), 차이가 조금만 있어도 누출이 생긴다.** 입력 총량 변동계수 0.1~0.2만으로도 H가 3~4가 됐다. 초파리 배선과 무관하게, "자발 활동이 있는 입력 + 공통 문턱 + 세포 간 입력 차이 + 출력 학습"만 있으면 생기는 일반 성질이다.
2. **차이의 원천은 상관없다.** 연결 개수의 차이(CV_K)든 연결 세기의 차이(CV_w)든 입력 총량의 차이로 모이면 같은 효과를 낸다. 31의 "허브는 특정 유형이 아니라 입력의 양으로 정의된다"와 같은 결론이다.
3. **보상하면 대부분 사라진다.** 입력 총량을 맞추거나 세포별 문턱을 조절하면 H가 1~2로 내려갔다. 남는 부분(최대 3.6)은 입력 구성의 차이 때문이다. 43에서 완전 보상 뒤에도 H가 남은 것과 같다.
4. **세포별 문턱 조절이 지나치면 H가 1 아래로 내려간다**(초파리와 비슷한 조건 0.51). 약한 세포가 잡음에 더 잘 켜지는 쪽으로 뒤집힌 것이다. 27의 "과한 보상은 비특이 누출을 늘린다"와 같은 방향이다.

## 다른 회로에 대한 의미

포유류 소뇌의 과립세포(이끼섬유 입력 약 4개)와 후각 피질처럼 확장층에 학습하는 출력이 붙은 회로라면, 세포 간 입력 차이가 보상되지 않는 만큼 같은 누출이 예상된다. 이 모형에서는 차이가 작아도 효과가 커서(변동계수 0.2에서 H 약 3~4), **실제 회로가 거짓 지각을 피하려면 세포 간 흥분성 보상이 거의 필수**라는 예측이 나온다. 다른 회로의 실제 값은 이번에 넣지 않았다.

## 한계

- CV_K 0.5인 보상 없는 조건에서는 잡음 시행 활성 비율이 목표(0.3%)보다 높았다(0.6~1.2%). 입력이 아주 많은 세포는 잡음이 없어도 문턱을 넘었기 때문이다. 이 조건의 H는 "항상 켜진 허브"가 있는 극단을 포함한다.
- 입력 채널은 서로 독립이고, 자극 구조(냄새 사이 상관)는 단순화했다. 억제 되먹임(APL)은 넣지 않았다(23, 33에서 누출에 영향이 작았다).
- H는 43에서 시뮬레이션 누출과의 일치를 확인한 지표다. 이번에는 시뮬레이션 누출을 따로 계산하지 않았다.
