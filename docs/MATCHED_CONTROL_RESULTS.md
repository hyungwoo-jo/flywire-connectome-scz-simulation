# 누출은 냄새 특이적인가, 허브 학습의 산물인가 (38)

2026-10-10. [사전 등록](PREREGISTRATION_38.md)에 따라 실행했다.

## 질문

25의 통제는 냄새 A의 학습량을 무작위 KC에 옮겼다. A에 반응하는 KC는 원래 입력이 많은 KC에 치우쳐 있으므로, 25의 결과가 "A의 표상이 특별해서"인지 "입력 많은 KC에서 학습이 일어났기 때문"인지 구분되지 않았다. 이번에는 A의 KC마다 같은 입력 강도 10분위에서 A에 반응하지 않는 KC를 골라 학습량을 옮긴 통제를 추가했다.

## 결과

| 반구 | 누출: 학습 / 무작위 통제 / 강도 맞춘 통제 | 냄새 특이 성분 비율 (S_match / S_rand) | S_match 95% 구간 | KC 입력 강도: A의 KC / 맞춘 통제 / 무작위 |
|---|---|---:|---|---|
| BANC 오른쪽 | 3.49 / 0.06 / 0.36% | 0.91 | 2.8~3.4%p | 1.25 / 1.04 / 0.41 |
| BANC 왼쪽 | 3.71 / 0.01 / 0.41% | 0.89 | 2.8~3.8%p | 1.42 / 1.18 / 0.49 |
| FlyWire 오른쪽 | 1.62 / 0.01 / 0.85% | 0.48 | 0.3~1.2%p | 0.89 / 0.81 / 0.39 |
| FlyWire 왼쪽 | 1.88 / 0.00 / 0.99% | 0.47 | 0.3~1.5%p | 0.83 / 0.77 / 0.37 |
| hemibrain 오른쪽 | 2.77 / 0.04 / 0.14% | 0.97 | 2.2~3.0%p | 1.08 / 0.93 / 0.44 |

## 판정

**둘 다 기여한다.** 다섯 반구 모두 강도 맞춘 통제보다 학습 조건의 누출이 컸다(95% 구간이 모두 0보다 위). 그러나 비율은 BANC와 hemibrain에서 0.9 안팎, FlyWire에서 0.5 안팎으로 기준(모두 0.5 이상)을 충족하지 못했다.

## 해석

1. **입력 강도를 맞추는 것만으로 누출의 상당 부분이 재현된다.** 무작위 통제(0.0~0.06%)와 달리, 강도 맞춘 통제는 0.14~0.99%의 누출을 만들었다. 즉 누출의 일부는 "A의 표상이 특별해서"가 아니라 "입력 많은 KC에서 학습이 일어났기 때문"이다.
2. **냄새 특이 성분의 크기는 상한으로 읽어야 한다.** 사전 등록에서 경고한 대로, A에 반응하지 않는 KC 중에서 고르면 최상위 허브는 통제에 들어가기 어렵다. 실제로 통제 KC의 입력 강도는 A의 KC보다 낮았다(BANC 1.04 대 1.25). 강도가 더 잘 맞은 FlyWire에서 냄새 특이 성분 비율이 더 작았다(0.47~0.48). 강도를 완벽히 맞추면 비율은 더 내려갈 가능성이 크다.
3. **"거짓 지각의 내용이 최근 학습을 따른다"는 해석은 유지된다.** 다만 그 이유는 주로 "무엇을 배우든 그 학습이 허브 KC를 거치기 때문"이다. 냄새마다 표상이 특별히 잡음과 겹치기 때문이라는 해석은 약하다.

## 이 결과가 바꾸는 것

25~37의 핵심 결과를 다음처럼 정확하게 고쳐 말해야 한다.

- 전: "배운 냄새의 의미가 잡음으로 새어 나온다."
- 후: "**입력이 많은 KC가 냄새 표상과 잡음 활동 양쪽에 참여하므로, 그 KC들에서 일어난 학습은 잡음 상황의 출력에 나타난다.** 냄새 특이 성분은 있지만, 상당 부분은 입력 강도에서 온다."

이 정리는 기제를 더 단순하게 만든다. 동시에 이 현상이 수학적으로 예상 가능한, 회로의 일반 성질에 가깝다는 뜻이기도 하다.
