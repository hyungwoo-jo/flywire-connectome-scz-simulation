# 학습 후 출력 판독: 실행 전 탐색 계획

2026-10-18. 기존 25~65의 결과는 알려져 있다. 새로운 판독 결과를 계산하기 전 작성했다. 생리 관측 모형과 용매 단위가 미해결이므로 **기존 Hallem 2006 단위의 추상 회로 내부에서 판독의 정보 접근만 검증**한다. 66의 용매 분석이나 실제 동물의 지각 검증이 아니다. READOUT_VALIDATION_PLAN의 생리 검증 단계와 독립적인 정보 접근 감사로 범위를 제한한다.

## 회로와 학습

- BANC 오른쪽/왼쪽, original 및 total_homeo 네 조건. 기존 보정·항상성 정의, MBON11의 실제 입력 가중치, 학습 eta=5를 사용한다.
- 원래 분할의 평가 냄새 전체(73개 예상)를 학습 A로 각각 사용한다. B는 사전의 깨끗한 KC 총 활동량이 A와 가장 가까운 다른 냄새로 고른다. 이는 세기를 대략 맞추는 비교이며 표상·학습량을 완전히 일치시키지 않는다. 선택 규칙을 성능에 맞춰 바꾸지 않는다.
- 학습 A / 학습 없음 / 가중치 감소량 일치 순열 통제. 순열은 KC 아형과 MBON11의 동일 입력 가중치 집단 안에서 학습 활동을 섞어 총 가중치 감소량을 정확히 보존한다. 교환 가능한 입력 비율을 보고한다. 제한 순열이며 균등 무작위 배선 표본이 아니다.

## 보정과 평가

- 문턱/항상성 보정은 기존 37개 냄새와 기존 잡음 자료로 한다.
- 판독 보정: 냄새별 full 10시행 및 weak(0.1배) 10시행. 신호 판독과 별도로 잡음 1,000시행으로 유무 기준을 정한다.
- 평가: 독립 seed의 full 및 weak 냄새별 20시행, 잡음 1,000시행. 모든 회로·학습 통제는 같은 감각 표본을 공유한다. 모의 시행은 독립 동물 수를 늘리지 않는다.
- A/B 보정 점수의 균형 정확도를 최대화하는 스칼라 문턱을 정한 뒤 고정한다. 평가 정답/강도를 이용해 문턱을 다시 정하지 않는다.

## 판독에 접근 가능한 정보

1. raw_after: 학습 후 MBON11 출력의 음수. 평가 입력의 학습 전 출력은 접근하지 않는다.
2. pn_normalized_after: 학습 후 MBON11 출력 / PN 총 입력의 음수. PN 총 입력을 읽는 추가 채널을 가정하므로 단일 MBON과 같은 정보 조건이 아니다.
3. privileged_fraction: 동일 입력의 학습 전후 출력 비율. 기전 진단용 기준이며 실제 판독 가능성을 주장하지 않는다.

각 점수에 다음 유무 판단을 비교한다.
- none: 유무 판단 없이 A/B 강제 판독.
- mbon_gate: 학습 후 MBON11 출력이 별도 잡음 보정의 95백분위를 초과할 때만 자극 있다고 판단. 학습 전 출력/전체 KC 입력을 쓰지 않는다.
- pn_gate: PN 총 입력이 잡음 보정의 95백분위를 초과할 때만 자극 있다고 판단. 추가 PN 정보 채널이라는 가정을 명시한다.

신호가 있어도 유무 문턱을 못 넘으면 누락으로 세며, 검출 시행만의 정확도를 전체 정확도로 표시하지 않는다. 무자극에서는 A라고 판독한 비율과 자극 있다고 판독한 비율을 보고하고 냄새 식별 정답을 부여하지 않는다.

## 결과와 범위

A hit, B→A 오류, 전체 A/B 정확도, 검출률, 잡음→A 비율, 잡음 검출률, 점수 AUC를 보고한다. 전체 다른 냄새가 A로 읽힌 비율도 보조 지표로 남긴다. 억지 판독, 유무 판단, 추가 감각 채널, 학습 전 출력 정보의 기여를 분리한다.

각 회로 조건에서 냄새 A 간 변동을 보고하며, 두 반구를 두 독립 동물로 취급하지 않는다. 회로 상세 배선 특이성·행동·지각·질환의 결론은 내리지 않는다. 판독기가 조건별로 A/B 경험을 받아 다시 보정된다는 가정도 명시한다.

## 추가 잡음 검증 (첫 계산 확인 후, 추가 계산 전 고정)

첫 표본을 확인한 뒤 감각·판독 보정 잡음 seed 네 개에 각각 +10000을 적용한 새 표본에서 반복한다. 학습용 깨끗한 패턴, 통제 순열, 회로 보정, 점수 정의, 선택 규칙은 고정한다. 같은 실제 회로와 냄새를 재사용하므로 외부 자료 재현이 아닌 추가 모의 잡음 검증이다. 결과는 별도 postlearning_readout_validation/에 저장하고 두 표본 모두 보고한다.
