# 사전 등록: 54 단계 (허브 인자의 그래프 분해)

2026-10-13. **결과를 계산하기 전에 작성했다.**

## 배경

43의 허브 인자는 판독 가중치 w(MBON11)로 가중한 평균을 E_w라 쓰면 다음과 같이 다시 쓸 수 있다.

```
H = E_w[m d] / (E_w[m] E_w[d]) = 1 + Cov_w(m, d) / (E_w[m] E_w[d])
```

m은 잡음 시행의 평균 KC 활동, d는 냄새 A 학습에 의한 감소분이다. 그래프 관점의 가설은 이렇다: m과 d가 모두 KC의 입력 세기(노드의 들어오는 세기, 1차 그래프 성질)의 증가 함수이므로 공분산이 양수가 된다. 어떤 PN에게서 받는지(입력의 구성, 고차 성질)는 작은 몫이다.

입력 세기는 두 가지로 정의한다.

- s_raw: 대응 PN에서 KC로 오는 시냅스 세기 합 (부분 회로 행렬의 행 합).
- s_spont: 잡음 시행 평균 PN 입력에 대한 KC 입력 (= 자발 상태에서 그래프가 내는 응답). PN마다 자발 발화가 다르므로 s_raw와 다르다. 여전히 노드 단위의 양이다.

## 방법

다섯 반구(BANC 양쪽, FlyWire 양쪽, hemibrain 오른쪽), 43과 같은 보정, 시드, MBON11 가중치, 평가용 냄새 73개.

### 1. 입력 세기로 설명되는 몫

- 판독 가중치가 있는 KC를 입력 세기 10분위로 나눈다(w 가중 아님, KC 수 기준).
- 각 KC의 m과 d를 그 분위 안의 w 가중 평균으로 바꿔 H_s를 계산한다. 몫 = (H_s - 1) / (H - 1).
- 우연 기준: 입력 세기를 KC 사이에서 섞은 뒤 같은 계산(100회, 시드 540100). 분위 평균만으로 생기는 몫을 보정하기 위해 함께 보고한다.
- 냄새 73개의 중앙값을 반구별로 보고한다. s_raw, s_spont 각각.

### 2. 2 x 2 재배선

| | 입력 세기 그대로 | 입력 세기 평평하게 (29의 보상 alpha 1) |
|---|---|---|
| 실제 구성 | 원래 회로 | 평평 |
| 구성 섞음 | 재배선 | 재배선 + 평평 |

- 재배선: 07의 세기 보존 교환(같은 시냅스 수의 연결끼리 받는 KC를 맞바꿈)을 대응 PN의 연결에만 적용한다. 각 KC의 들어오는 세기, 연결 수, 각 PN의 나가는 세기는 그대로이고 어떤 PN이 어떤 KC로 가는지만 바뀐다. 반구당 20개(시드 540000 + 반구 번호 x 100 + i).
- 조건마다 문턱을 다시 보정(활성 10%)하고 43의 H(냄새 평균)와 시뮬레이션 누출(25 정의)을 계산한다.

## 판정 (실행 전 고정)

- **P1 (1차 성질로 충분):** 다섯 반구 모두 s_spont 몫의 중앙값이 0.5 이상이고 우연 기준의 95번째 백분위보다 크면 지지.
- **P2 (구성은 작은 몫):** 다섯 반구 모두 H(재배선) 중앙값 / H(원래)가 0.7 이상이면 지지. 0.4 이하가 하나라도 있으면 "그 반구에서는 구성이 주요 요인".
- **P3 (세기를 지우면 구성만 남음):** 다섯 반구 모두 H(재배선 + 평평)의 중앙값이 2 이하이면 지지.
- s_raw의 몫, 반구 간 입력 세기 변동계수와 H의 순서 비교(n = 5)는 기술만 하고 판정하지 않는다.
