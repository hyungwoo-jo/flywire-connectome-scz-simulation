# 사전 등록: 25 단계 (학습만으로 생기는 가치 신호의 누출)

2026-10-09. **결과를 보기 전에 작성했다.**

## 배경과 예측

24에서 기대를 "A에 반응하는 KC의 흥분성 증가"로 근사하자, 전체 오탐이 같은 수의 무작위 KC를 바꾼 통제보다 훨씬 컸다(19% 대 8%). 해석은 이렇다. 냄새에 반응하는 KC는 PN 입력을 많이 받는 KC이고, 그래서 잡음에도 더 잘 켜진다.

이 해석이 맞다면 흥분성을 바꾸지 않고 **학습만 해도** 비슷한 일이 생겨야 한다. A를 학습하면 A에 반응한 KC의 MBON 출력 연결이 약해진다(08, 21의 규칙). 잡음이 그 KC들을 우선적으로 켠다면, 냄새가 없는데도 MBON 출력에 "A를 배웠을 때의 변화", 즉 가치 신호가 나타날 것이다.

**H25.** 냄새 A를 학습하면, 잡음 시행에서 A의 가치 신호가 나타나는 비율이, 같은 수의 무작위 KC에서 학습이 일어난 통제보다 크다.

**보조 예측 P25.** KC가 받는 PN 입력 총량(대응 PN에서 오는 가중치 합)과, 잡음 시행에서 그 KC가 켜지는 확률은 양의 순위 상관을 가진다.

## 모형

- 23, 24와 같은 두 반구 보정 모형, 10% theta, 정상 APL, 0.5 s 창, 검출기(KC 합)와 기준(시드 230001)이다.
- 잡음 시행 500개(시드 250002), 약한 신호(농도 0.1) 냄새당 20시행(시드 250003), 무잡음 원농도 템플릿을 쓴다.
- **출력:** 각 반구의 MBON11(오른쪽 `720575941586084230`, 왼쪽 `720575941575561885`, 둘 다 cell_type MBON11)이 받는 KC 입력 시냅스 수를 총합으로 나눈 가중치 w다. 학습은 `w' = w * exp(-5 * k_A)`이고, k_A는 A의 무잡음 원농도 KC 반응이다.
- **가치 신호:** 시행 k의 상대 감소 L(k) = 1 - (w'·k)/(w·k). w·k = 0이면 L = 0으로 둔다.
- **가치 판정 기준:** L_crit(A) = 약한 A 시행 L 중앙값의 절반.
- **누출률:** 잡음 시행 중 검출기가 "있음"으로 판단하고 L > L_crit(A)인 비율이다.
- **통제:** A의 템플릿에서 활성인 KC 수와 같은 수의 KC를 무작위로 골라(시드 250200 + A 번호), 그 KC들이 1로 반응했다고 보고 같은 학습을 적용한다. L_crit도 같은 규칙(그 통제 학습 후 약한 A 시행 L 중앙값의 절반)으로 정한다.

## 판정

**주 판정.** Δ_A = 누출률(A 학습) - 누출률(무작위 통제)의 평가용 냄새 73개 평균. 냄새 재표집 부트스트랩 1,000회(시드 250300)의 95% 구간이 두 반구 모두 0보다 위면 "학습만으로 가치 신호가 잡음에 누출되며, 무작위 학습보다 크다"(H25 지지).

**P25.** 각 반구에서 KC 입력 총량과 잡음 활성 확률의 Spearman 상관. 두 반구 모두 rho > 0이고 p < 0.05면 지지.

**배선 특이성.** 주 지표 평균 Δ_A를 N0 대조 100개(반구별 기존 시드)와 비교한 z. 두 반구 모두 |z| >= 1.96이고 부호가 같으면 "배선 특이적". 대조에서는 템플릿, 기준, L_crit를 각 대조 그래프에서 다시 만든다. MBON11 가중치는 바꾸지 않는다.

## 한계

- 학습 규칙, 도파민 신호, MBON 하나의 판독은 단순화했다.
- "가치 신호가 잡음에 나타난다"는 출력 수준의 계산 결과다. 초파리가 학습한 냄새를 느꼈다는 뜻이 아니다.
