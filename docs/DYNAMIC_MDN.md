# 동역학 모형: 거짓 신호가 MDN 활동을 바꿀 만큼 큰가 (51)

2026-10-12. 개인 프로젝트의 탐색 분석이다(`pipelines/51_dynamic_mdn.py`). 지표는 실행 전에 스크립트 머리말에 고정했다. 46~50은 출력 뉴런 이후를 선형으로 두 단계 전달했다. 이번에는 문턱, 되먹임, 시간 변화가 있는 발화율 모형에서 냄새 없는 잡음 시행의 학습 신호가 뒷걸음질 하행 뉴런(MDN)의 활동을 얼마나 바꾸는지 봤다.

## 모형

- 단위: 출력 뉴런 입력을 받는 중추 뉴런 8,327개와 하행 뉴런 1,303개. 이 단위들 사이의 모든 연결(약 100만 개)과 출력 뉴런 53개에서 오는 연결을 넣었다. 가중치는 받는 뉴런의 전체 입력 대비 시냅스 비율에 예측 전달물질 부호를 곱했다. MDN 4개가 받는 입력의 59~64%가 이 단위들에서 온다.
- 동역학: `tau dr/dt = -r + relu(g * W r + 출력 뉴런 입력 - theta)`. tau 20 ms, 400 ms 모의. 출력 뉴런 발화율은 냄새(또는 잡음) 동안 일정하다.
- 되먹임 강도 g: 0.5, 0.9. 문턱 theta: 학습 전 잡음 시행에서 각 뉴런이 50%(q 0.5) 또는 5%(q 0.95)만 켜지도록, 이 비선형 망 안에서 세 번 다시 맞췄다.
- 학습은 49, 50과 같다(처벌 PPL1, 보상 PAM 구역). 대조는 같은 학습량을 무작위 KC 또는 입력 강도가 같은 KC에 준 경우다. 평가 냄새 30개, 검출기가 "냄새 있음"으로 판단한 잡음 시행 23개.
- float32와 float64 계산 결과가 같았다(최대 차이 0.0005).

## 지표

- z: 잡음 시행에서 학습 후와 학습 전의 MDN 발화율 차이를, 학습 전 잡음 시행 MDN 발화율의 표준편차로 나눈 값. 1 이상이면 이 모형 안의 자연 변동만큼 크다.
- 비율: 같은 차이를 실제 약한 냄새 A에서의 학습 효과로 나눈 값.
- 전환: MDN 중 하나라도 꺼짐과 켜짐이 바뀐 잡음 시행 비율.
- 냄새 30개의 중앙값.

## 해석

1. **비선형 되먹임 망에서도 거짓 신호는 사라지지 않는다.** "냄새 있음"으로 판단된 잡음 시행에서 학습으로 생긴 MDN 변화는 이 모형의 자연 변동의 0.9~1.9배이고, 실제 약한 냄새에 대한 학습 효과의 0.6~1.9배다. 문턱과 되먹임을 바꿔도 같았다.
2. **배운 냄새 특이성이 남는다.** 무작위 KC 학습 대조보다 6~12배, 입력 강도 맞춘 대조보다 약 2배 크다. 38의 결론(약 절반은 입력 강도)과 같은 구도다.
3. **문턱이 높을수록(뉴런이 드물게 켜질수록) 효과가 커진다.** 잡음 시행의 4~24%에서 MDN이 꺼짐에서 켜짐, 또는 그 반대로 바뀌었다. 보상 학습 쪽이 더 크다.
4. **효과는 빠르다.** 출력 뉴런 신호가 바뀐 뒤 50 ms 안에 대부분 나타난다.

## 한계 (중요)

- **z의 기준 변동은 냄새 경로에서 온 변동뿐이다.** MDN은 이 모형 밖의 뉴런에서도 입력의 약 40%를 받고, 실제로는 다리 감각, 시각 등의 변동이 더해진다. 실제 MDN의 변동은 훨씬 클 것이므로, z는 상한으로 읽어야 한다. "실제 뒷걸음질을 일으킬 만큼"인지는 이 모형으로 결론 낼 수 없다.
- 50에서 처벌 -> MDN 증가는 구역 표지를 무작위로 섞어도 비슷하게 나왔다. 이번 대조(무작위 KC, 강도 맞춘 KC)는 "어떤 냄새를 배웠는가"의 특이성을 보며, "처벌이기 때문인가"는 보지 않는다.
- 단위들은 출력 뉴런에서 한 단계 떨어진 뉴런과 하행 뉴런으로 한정했다. 시냅스 세기는 시냅스 수 비율로 근사했고, 모든 뉴런의 시간 상수를 같게 뒀다.
- 출력 뉴런 발화율은 KC 모형에서 바로 계산했고 시간 변화가 없다. 실제 학습의 시간 척도(분~시간)와 잡음의 시간 구조도 없다.
