# 사전 등록: 71 단계 (불균일성 조절기와 학습한 확장층)

2026-10-19. **어떤 결과도 계산하기 전에 작성했다.** 갈래 2의 둘째 단계다. 68~69에서는 실제 배선과 입력 세기를 모두 같게 맞춘 배선, 두 점만 비교했다. 그 비교에서 맞교환 후보가 나왔다. KC 입력 세기의 불균일성은 단일 시행 식별에는 이득이고, 해석 가능성과 간섭에는 비용이었다. A는 이 맞교환이 불균일성을 연속으로 바꿀 때도 단조롭게 성립하는지 본다. B는 경사하강법 학습이 불균일성을 만드는지 없애는지 본다.

## 공통

- **회로:** 다섯 반구(BANC 좌우, FlyWire 좌우, hemibrain 오른쪽)의 원래 회로(`p34.make_g`)를 쓴다.
- **문턱:** 조건마다 KC 10%로 다시 보정한다.
- **입력 세기:** s_i는 KC i가 Hallem에 대응된 PN에서 받는 시냅스 가중치의 합이다.

## A. 불균일성 조절기

**배선:** m_α = diag((s̄ / s_i)^α) m이다(s_i > 0인 KC만, s̄는 그 평균).

- α = 0이면 실제 배선, α = 1이면 26의 `equalize_rows`다.
- α ∈ {-0.5, 0, 0.25, 0.5, 0.75, 1}이다. α = -0.5는 불균일성을 키운 배선이다.

**지표:** α마다 잰다.

1. **식별:** 69와 같다. 깨끗한 반응을 원형으로 두고 코사인 최근접 분류를 한다.
2. **26 지표:** 26의 `discrimination`과 같다. 잡음 학습 시행의 중심점에 대어 d'를 잰다. 같은 함수의 정확도도 보고한다.
3. **기억:** 55의 `memory`, 냄새 20개다.
4. **간섭:** 25의 냄새 특이 누출 specific = learned − control이다(`p25.evaluate`).
5. **해석 가능성:** 68의 혼합 체제 NMF 복원도 R_NMF다. 시행은 3,300개로 줄인다(68의 6,600 중 앞 절반과 같은 생성 방식, 같은 시드). SAE는 비용 때문에 넣지 않는다.
6. **불균일성:** s의 변동계수(CV)다.

**판정:** 반구마다 여섯 α에 걸친 Spearman ρ(α, 지표)를 잰다. 4개 이상 반구에서 정해진 부호로 |ρ| ≥ 0.9이면 지지한다.

- **A1:** 식별은 α가 커질수록 떨어진다(ρ ≤ -0.9).
- **A2:** 간섭(specific)은 α가 커질수록 준다(ρ ≤ -0.9).
- **A3:** NMF 복원도는 α가 커질수록 오른다(ρ ≥ 0.9).
- **A4 (26과 69의 충돌):** 26 지표 d'는 α가 커질수록 오른다(ρ ≥ 0.9). A1과 A4가 함께 지지되면, 충돌은 지표의 차이다. 같은 배선 변화가 평균 분리도는 올리고 단일 시행 식별은 낮춘다는 뜻이다.
- **A5 (보고만):** 식별이 α = 0의 99% 이상이면서 간섭이 α = 0의 절반 이하인 α가 있는가. 반구별로 보고한다.

## B. 경사하강법으로 학습한 확장층

**학습 대상:**
- 대응 PN→KC 시냅스의 로그 가중치 u_e다. 연결 유무는 실제 배선에 고정한다.
- 판독은 KC → 냄새 73종 softmax(가중치와 편향)다.

**전방 계산:**
- 01~67의 반응식 k = clip(E − θ − g·inh·a, 0, 1)이다(APL 포함).
- 기울기에서는 APL 억제량 a를 상수로 취급한다(stop-gradient). dk/dE = 1[0 < k < 1]이다.

**과제와 학습:**
- 평가 냄새 73종의 잡음 시행(0.5초 Poisson)이다. 단계마다 냄새당 4시행을 새로 뽑는다(배치 292).
- 손실은 교차 엔트로피다.
- Adam(학습률 0.01, 두 매개변수 모두), 1,500단계다.

**제약:**
- 단계마다 전체 시냅스 가중치의 합을 시작 값으로 되돌린다. 전체 배율만 고정하고 KC 사이 분배는 자유다.
- 50단계마다 문턱을 10%로 다시 보정한다.

**시작점 세 가지:** 실제 배선(α = 0), 고르게 한 배선(α = 1), 키운 배선(α = -0.5)이다.

**기록:**
- 단계 0, 250, 500, 1000, 1500에서 KC 입력 세기 CV를 남긴다.
- 끝에서 69의 식별 정답률을 잰다. 판독은 학습한 softmax가 아니라 원형 분류다.
- 끝에서 시작 세기와 최종 세기의 Spearman을 잰다.

**판정:**

- **B0 (학습 작동, 선결 조건):** 세 시작점 모두에서 최종 식별이 시작점의 식별보다 높은 반구가 4개 이상이어야 한다. 실패하면 B1~B3를 해석하지 않는다.
- **B1 (균일에서 불균일이 생긴다):** 고르게 한 시작점의 최종 CV가 0.2 이상인 반구가 4개 이상이면 지지한다.
- **B2 (시작점에 상관없이 수렴):** 실제와 고르게 한 시작점의 최종 CV 차이가 처음 차이의 절반 미만인 반구가 4개 이상이면 지지한다.
- **B3 (실제 배선에서 학습은 어느 쪽으로 가나):** 실제 시작점의 CV 변화 부호가 4개 이상 반구에서 같으면 그 방향을 보고한다. 방향은 미리 정하지 않는다.

## 보고만

- A: 26 지표의 정확도, 기억, α별 활성 KC 수.
- B: 학습 곡선, 최종 softmax 정확도, KC별 입력 세기와 학습 전후 변화의 관계, 학습 후 간섭(specific).
