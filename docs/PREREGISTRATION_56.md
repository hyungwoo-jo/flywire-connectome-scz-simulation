# 사전 등록: 56 단계 (자발 활동 기준 항상성)

2026-10-14. **결과를 계산하기 전에 작성했다.**

## 배경

55에서 냄새 반응 평균을 맞추는 항상성은 FlyWire와 hemibrain의 냄새 특이 누출을 거의 없앴지만, BANC에는 0.8~1.0%가 남았다. 54에서는 누출을 정하는 것이 각 KC의 자발 입력 분포(평균과 흔들림)였다. 그렇다면 KC마다 자기 자발 입력 분포를 기준으로 문턱을 정하는 항상성이 남은 누출까지 없애야 한다.

## 방법

다섯 반구, 43과 같은 보정 모형, 시드, MBON11 가중치. 55의 기억 과제와 시드를 그대로 쓴다.

**자발 기준 문턱:** 보정용 잡음 시행 1,000개(평가용 잡음 시행과 다른 시드)에서 KC마다 입력의 평균 mu_i와 표준편차 sigma_i를 구한다.

```
theta_i(lambda) = (1 - lambda) * theta_0 + lambda * (mu_i + z * sigma_i)
```

- theta_0은 원래 공통 문턱이다. z는 공통값이며, 보정용 냄새의 활성 KC가 10%가 되도록 정한다.
- lambda = 1이면 모든 KC가 자발 상태에서 같은 확률로 문턱을 넘는다(입력이 정규분포라면).
- lambda는 0.25, 0.5, 0.75, 1이다.

**비교 조건:** 원래 회로, 55의 문턱 항상성(활성 10%로 맞춘 것).

**측정:** H(냄새 평균과 중앙값), 시뮬레이션 누출(학습, 무작위 통제, 냄새 특이 = 차이), 기억 정확도(20개, 73개, 원래 대비 짝 차이), 냄새와 잡음 시행의 활성 비율, KC별 잡음 시행 활성 확률의 변동계수.

## 판정 (실행 전 고정)

- **P1 (남은 누출 제거):** lambda = 1에서 냄새 특이 누출이 다섯 반구 모두 0.3% 이하이면 지지.
- **P2:** lambda = 1에서 H(냄새 평균)가 2 이하인 반구가 4개 이상이면 지지.
- **P3 (기억 비용 없음):** lambda = 1에서 20개 냄새 정확도가 원래보다 낮지 않은(차이 > -1 표준오차) 반구가 4개 이상이면 지지.
- **P4 (용량 반응):** 냄새 특이 누출이 lambda 0, 0.25, 0.5, 0.75, 1 순서로 단조 감소(Spearman -0.9 이하)하는 반구가 4개 이상이면 지지.

## 한계

- KC 입력이 정규분포가 아니면 lambda = 1에서도 잡음 활성 확률이 완전히 같지 않다. 실제 값의 변동계수를 함께 보고한다.
- 대응 PN 입력이 없는 KC는 sigma가 0이라 조정되지 않는다.
- 생물학적으로 KC가 자기 자발 입력의 흔들림을 어떻게 감지하는지는 이 모형이 다루지 않는다.
