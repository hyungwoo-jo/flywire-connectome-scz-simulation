# 사전 등록: 26 단계 (허브 KC 기제의 인과 검정)

2026-10-09. **결과를 보기 전에 작성했다.**

## 배경과 예측

25에서 학습만으로 학습한 냄새의 가치 신호가 잡음 시행에 누출됐다(잡음 "있다" 판단의 약 3분의 2). 해석은 "입력을 많이 받는 허브 KC가 냄새 표상과 잡음 활동 양쪽에 참여한다"였다. 근거는 상관(입력 총량과 잡음 활성의 rho 0.6)이었다.

인과 검정을 위해 허브를 없앤다. **각 KC가 대응 PN에게서 받는 입력 가중치의 총합을 모두 같게 맞춘다**(입력이 하나라도 있는 KC의 평균값으로 행 단위 재조정, 입력 0인 KC는 그대로 0). 어떤 PN에게서 받는지와 상대 비율은 유지한다.

**H26.** 허브를 없앤 회로에서는 누출이 크게 줄어든다.

## 방법

- 두 반구, 25와 같은 입력, 잡음, 시드(잡음 250002, 신호 250003, 통제 250200 + A, 부트스트랩 250300), MBON11 가중치, 학습 규칙, 누출 정의, 통제를 쓴다.
- 조작 회로는 위의 행 정규화 행렬이다. **theta는 조작 회로에서 같은 보정용 냄새 37개, 활성 KC 10% 규칙으로 다시 정한다.** 검출 기준도 조작 회로의 잡음 보정 시행(시드 230001)으로 다시 정한다.
- 비교 대상은 같은 실행에서 다시 계산한 원래 회로(25와 같은 값이 나와야 함, 재현 점검)다.

## 판정

- **주 판정.** 반구마다 비 R = 누출률(조작) / 누출률(원래), 학습 조건의 냄새 73개 평균이다. 두 반구 모두 R <= 0.5이고, 냄새 재표집 부트스트랩 1,000회로 구한 (원래 - 조작) 차이의 95% 구간이 0보다 위면 "허브 기제가 인과적으로 지지됨".
- 두 반구 모두 R > 0.8이면 "허브 기제로 설명되지 않음". 그 밖은 "부분적".

**보조 (판정 없음).**
- KC "참여도": 각 KC가 반응하는 평가용 냄새의 수. 분포의 지니 계수를 원래와 조작 회로에서 비교한다(허브가 줄었는지 조작 점검).
- 조작 회로의 무작위 통제 누출률, 잡음 "있다" 판단률, 입력 총량과 잡음 활성의 상관.
- 조작 회로의 범용 냄새 구분 d'(18의 방식, 주 조건): 허브 제거가 구분에 이득인지 손해인지.
