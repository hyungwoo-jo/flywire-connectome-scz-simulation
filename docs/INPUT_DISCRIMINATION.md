# 입력 구분으로 시작하는 초파리 탐구

2026-10-08. 이번 단계는 ‘연결망이 입력을 어떤 표상으로 바꾸는가’를 시험한다. 학습·기억·환각 또는 조현병을 구현하거나 검증한 결과는 아니다.

## 무엇을 만들었나

PN은 감각 입력을 버섯체로 보내는 뉴런, KC는 입력을 비교적 적은 세포의 활동으로 표현하는 뉴런, APL은 KC의 활동을 받아 KC에 억제 신호를 돌려주는 뉴런이다. 이 역할에서 출발해 PN→KC→APL→KC의 방향을 보존한 작은 회로를 만들었다. 이러한 피드백 억제와 입력 구분의 관계는 [Lin 등, 2014](https://pubmed.ncbi.nlm.nih.gov/24561998/)의 생물학적 실험을 출발점으로 삼았다. 그 논문의 행동 결과를 재현했다고 주장하지 않는다.

입력은 실제 냄새 측정치가 아닌, PN 일부를 켜는 인공 패턴 A와 B다. 공통으로 켜지는 PN이 많으면 비슷한 입력이다. 반복마다 잡음을 더하고, KC의 출력 패턴을 보고 A/B를 얼마나 구분할 수 있는지 평가했다.

## 먼저 고친 데이터 문제

연결 파일의 pre/post ID는 문자열이며 **BANC 버전 888의 root_888**에 대응한다. 최신 root_id로 주석을 붙이면 전체 연결의 약 16%에서 presynaptic 주석을 놓친다. root_id에는 중복 주석 168개도 있다. APL과 다른 KC가 같은 최신 root_id를 공유하는 사례가 있지만 각각의 root_888는 다르다. 이 자료에서 root_888는 중복이 없다.

새 실험은 root_888로 연결과 주석을 맞췄다. 우측 KC 2,245개와 APL 1개를 사용했고, KC에 연결된 PN 중 acetylcholine이 verified로 주석된 138개만 포함했다. GABA성 PN 3개와 전달물질 미확인 PN 11개는 흥분성으로 취급하지 않고 제외했다. KC는 모두 verified acetylcholine, APL은 verified GABA다.

| 경로 | 뉴런 간 연결 수 | 용도 |
|---|---:|---|
| PN→KC | 10,620 | 감각 입력 전달 |
| KC→APL | 2,126 | KC 활동을 억제 회로에 전달 |
| APL→KC | 2,097 | KC 활동 억제 |

PN→KC에는 총 83,989개의 예측 시냅스가 포함된다. 시냅스 수를 상대 가중치로 썼으며, 이것이 실제 전도도·발화율을 제공하지는 않는다. 원자료의 출처는 [BANC 공식 프로젝트](https://github.com/htem/BANC-project)다.

## 모형의 가정

각 KC의 활동은 ‘들어온 PN 신호 − 문턱 − APL 억제’를 0~1로 제한한 값이다. APL 활동은 KC의 가중 평균이다. 하나의 APL 전체가 같은 활동 변수를 갖는다고 단순화했다. 실제 세포 내부의 위치별 전기 신호나 수용체 반응은 모사하지 않는다.

```text
k = clip(W_PN_KC x − theta − 4 s w_APL_KC a, 0, 1)
a = w_KC_APL · k
```

s가 APL 억제 강도다. 1, 0.75, 0.5, 0.25, 0을 비교했다. 이는 억제 효과의 모형 계수이며 GABA 농도나 약물 용량이 아니다. PN 가중치는 실제 회로의 KC별 입력 시냅스 수 중앙값 34로 나눴다. APL→KC 가중치는 평균 1, KC→APL 가중치는 합 1로 정했다. **조건마다 다시 정규화하지 않았다.**

문턱 theta=0.5888234576은 별도의 기준 입력 100개에서 정상 APL 조건의 활성 KC 비율을 10%로 맞추도록 한 번만 정했다. 분류 정확도나 기대한 결과를 맞추지 않았다. 10%와 APL gain 4는 탐색적 가정이며 생리학적으로 추정한 값이 아니다. 다른 값에서도 결과가 유지되는지 아직 확인하지 않았다.

음성 피드백의 정상 상태를 이분법 35회로 풀었다. 최종 최대 잔차는 약 5.1×10^-12이다. 이 수치는 방정식을 잘 풀었다는 뜻이며, 실제 뇌의 시간 변화나 생물학적 정확성을 입증하지 않는다.

## 비교 설계

- 입력 겹침 목표 25%, 60%, 90%. PN 수가 정수라 실제 겹침은 25%, 약 60.7%, 약 89.3%다. PN의 약 20%를 패턴마다 활성화했다.
- PN 입력에 표준편차 0.1 또는 0.4의 Gaussian 잡음을 더하고 음수는 0으로 제한했다. 비활성 PN에도 양의 잡음이 남는 인공 입력 가정이다.
- 패턴별 반복 40개 중 20개로 KC 출력의 평균 패턴을 계산하고, 나머지 20개를 두 평균 중 가까운 쪽으로 분류했다. 전체 평가 표본은 조건마다 40개다.
- 실제 회로와 무작위 PN→KC 회로 10개를 비교했다. PN별 출력 연결 수, KC별 입력 연결 수, 각 PN의 출력 가중치 집합과 합을 보존했다. 세포 유형과 전달물질 구성도 같다. KC–APL 연결은 그대로 유지했다.
- 무작위 대조군은 KC별 입력 가중치 합을 보존하지 않는다. 실제 회로와 차이가 있더라도 원인을 상세 배선 하나로 특정할 수 없다. 대조군마다 연결 수의 5배인 53,100회의 이중 연결 교환을 성공시켰고, 연결 상대의 약 99.9%가 달라졌다.
- 같은 입력과 같은 문턱을 모든 회로와 억제 조건에 사용했다. 총 330개 조건이다. 입력 패턴 쌍은 겹침별 하나뿐이며 반복과 대조군은 독립적인 생물학적 개체 표본이 아니다.

## 첫 결과

비슷한 입력과 큰 잡음인 조건에서 다음 결과가 나왔다. 아래 수치는 모형의 출력이다.

| 지표 | APL 정상 | APL 억제 제거 |
|---|---:|---:|
| 활성 KC 비율 | 13.8% | 22.5% |
| A/B 평균 KC 패턴의 cosine 유사도 | 0.899 | 0.920 |
| 별도 평가 입력 분류 정확도 | 90.0% | 92.5% |
| PN 입력 자체의 분류 정확도 | 97.5% | 97.5% |

억제를 없애면 더 많은 KC가 활성화되고, 두 출력 패턴은 더 비슷해졌다. 그러나 **이번 조건에서는 분류 정확도가 나빠지지 않았다.** 90%와 92.5% 차이는 평가 표본 한 개에 해당한다. 이를 억제 제거의 개선 효과로 주장하지도 않는다. cosine 유사도가 높아졌다는 관찰만으로 기능이 망가졌다고 부를 수 없다는 점이 핵심이다.

실제 회로의 높은 겹침·큰 잡음 조건에서 ‘패턴 간 거리 / 반복 내 변동’ 지표도 0.384→0.410으로 증가했다. 출력 패턴이 더 비슷해져도 변동과 비교한 분리 정도는 별도로 평가해야 한다.

낮은 잡음에서는 두 APL 조건의 분류 정확도가 모든 입력 겹침에서 100%였다. 큰 잡음의 덜 비슷한 입력도 두 조건 모두 100%였다. 쉬운 문제에서는 정확도만으로 차이를 평가하기 어렵다.

높은 겹침·큰 잡음의 무작위 대조군에서 정상 APL 정확도는 82.5~92.5%, APL 제거 정확도는 85.0~92.5%였다. 실제 회로는 이 범위 안에 있었다. 활성 KC 비율도 대부분 겹쳤다. 따라서 이번 결과는 실제 배선이 특별히 좋은 분류 기능을 만든다는 증거가 아니다. 피드백 억제라는 일반 구조와 모델의 문턱만으로 설명되는 부분이 클 수 있다.

## 다음 단계

1. **입력 구분의 재현성부터 확인한다.** 여러 패턴 쌍과 잡음 반복 시드, PN 활성 비율, 문턱과 APL gain을 바꾸고 정확도·유사도·반복 내 변동을 함께 본다. 실제 배선과 대조군의 차이가 입력 가중치 합을 통제해도 남는지 확인한다. 지금의 한 패턴 쌍을 반복하는 실험은 출발점이다.
2. **그다음 학습을 별도로 추가한다.** KC→MBON 연결에 명시적인 학습 규칙을 넣고, 입력 A에 보상/처벌을 연결한 뒤 새로운 A/B 입력을 구별하는지 평가한다. 학습 전후가 있어야 기억이라는 이름을 붙일 근거가 생긴다. 도파민은 전체 활성에 일정 값을 더하는 신호보다 어떤 연결의 학습을 언제 바꾸는지를 지정하는 변수로 다룬다.
3. **기억 오류는 마지막에 정의한다.** 학습한 뒤 비슷한 B 또는 무자극을 넣었을 때 A에 대한 반응이 잘못 나오는지, 정상 대조군과 비교해 시험한다. 무자극에서 평균 활동이 커졌다는 사실만으로 가짜 기억이나 환각이라고 부르지 않는다.

현재는 1단계의 첫 탐색을 완료했다. 2·3단계는 구현하지 않았다. 조현병을 해석하는 단계는 아직 아니다.

## 실행과 산출물

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
  .venv/bin/python pipelines/06_input_discrimination.py --nulls 10 --trials 40
.venv/bin/python -m unittest discover -s tests -v
```

원자료 2개는 data/에 별도 확보해야 한다. 결과는 qc_reports/input_discrimination/에 저장된다.

- metrics.csv: 실제 회로와 대조군 330개 조건의 지표와 수치 잔차.
- pn_input_baseline.csv: 회로에 넣기 전 입력 자체의 구분 난이도.
- manifest.json: 정확한 ID 열, 세포 수, 전달물질 주석, 가중치·문턱, 시드, 원자료 SHA-256.
- discrimination.png: 억제 강도에 따른 활성 비율·표상 유사도·정확도. 색은 입력 겹침, 음영은 대조군의 최소~최대이며 신뢰구간이 아니다.

실행 환경은 Python 3.12.3, NumPy 2.5.3, pandas 3.0.6이며 기존 가상환경의 SciPy·Matplotlib도 필요하다. 원래 01~04 스크립트와 이전 결과는 보존했다. 05는 기존 추출 회로를 재현하는 대조 분석이고, 이번 06은 버전별 ID를 바로잡은 별도 회로이므로 수치를 직접 이어 붙이지 않는다.
