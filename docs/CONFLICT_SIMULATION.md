# 갈등 시뮬레이션: 처벌 기억과 보상 기억이 동시에 올 때 (45)

2026-10-10. 개인 프로젝트의 탐색 분석이다. 사람 ACC의 대표 기능인 "갈등 처리"를 초파리 회로에서 디지털로 시험했다.

## 설정

- FlyWire 오른쪽 버섯체 보정 모형(34). KC 입력을 충분히 받는(KC 50개 이상) 출력 뉴런 53개를 썼다.
- 출력 뉴런마다 도파민 뉴런 입력을 보고 구역을 나눴다. PPL1 도파민 뉴런 입력이 많으면 처벌 학습 구역(27개), PAM이 많으면 보상 학습 구역(26개)이다. 출력 뉴런의 부호는 예측 전달물질로 정했다(아세틸콜린 +, GABA와 글루탐산 -).
- 냄새 A는 처벌과 짝지어 배운다(처벌 구역 출력 뉴런에서 A의 KC 연결이 약해짐). 냄새 B는 보상과 짝지어 배운다(보상 구역에서 B의 KC 연결이 약해짐). 평가용 냄새에서 무작위 60쌍.
- A만, B만, A+B(수용체 반응의 합)를 주고, 학습 전후의 출력 뉴런 변화를 실제 배선과 부호로 아래 뉴런까지 전달했다.
- 지표(실행 전에 코드에 고정): 반대 부호로 읽기(opposed), 상쇄(섞으면 큰 쪽의 절반 미만), 갈등 증폭(섞으면 큰 쪽의 1.2배 초과).

## 결과 1: 44의 "가치 + 몸 상태" 통합 뉴런 12개

| 지표 | 평균 |
|---|---:|
| 출력 뉴런 입력 수 | 0~4개 (대부분 1개) |
| 두 기억을 반대 부호로 읽는 비율 | 0~12% |
| 상쇄 | 0~2% |
| 갈등 증폭 | 0~2% |

이 뉴런들은 대부분 출력 뉴런 하나에서만 가치를 받는다. 하나의 기억 채널을 읽을 뿐 두 기억을 비교하지 않는다. 섞은 자극의 효과는 거의 한쪽 기억의 효과와 같았다.

## 결과 2: "비교기" 뉴런 (탐색, `pipelines/45x_comparators.py`)

처벌 구역과 보상 구역의 출력 뉴런을 각각 2개 이상, 50시냅스 이상 받는 중추 뉴런을 찾았다.

- **84개.** 주요 유형: CB2357, CB1079, LAL171/172, LHPV10d1, CRE050, LHPV4m1, SMP177, SMP030/031, SIP019, LAL159, 그리고 다른 출력 뉴런(MBON24, MBON26), APL.
- **26개는 두 기억을 대부분의 쌍에서 반대 부호로 읽는다**(반대 부호 비율 50% 이상). 예: LHPV10d1(98%), LAL159(95%), MBON24(92%), CRE050(67~78%).
- 섞은 자극에서는 **상쇄가 평균 15%**, 강하게 상쇄하는 뉴런 2개(LAL171/172, LAL173/174 계열). **갈등 증폭은 2.5%로 드물었다.**
- 비교기의 출력은 도파민 뉴런 3.0%, 다른 출력 뉴런 5.1%, 중심복합체 1.5%, 하행 뉴런 1.0%로 퍼진다.

## 해석

1. **초파리 회로는 처벌과 보상 기억을 "따로 감지"하기보다 "더해서 순 가치로" 정리하는 쪽에 가깝다.** 비교기 뉴런들은 반대 부호로 두 기억을 받아 합산한다. 서로 반대인 기억이 함께 오면 부분적으로 상쇄된다.
2. **비교는 LAL, CRE, SMP, SIP, 외측각과 출력 뉴런끼리의 연결에서 일어난다.** 44에서 찾은 "가치 + 몸 상태" 통합 뉴런은 비교 이후의 단계(한 채널을 받아 행동으로 넘기는 곳)로 보인다.
3. **ACC의 "갈등 감시"(두 반응이 경쟁할 때 따로 켜지는 신호)에 해당하는 반응은 이 모형에서 거의 나오지 않았다.** 다만 이 모형은 출력 뉴런 이후를 선형으로 전달하므로, 갈등 감시에 필요한 비선형성(두 입력이 모두 있을 때만 켜짐)은 원래 만들기 어렵다. 이 결과는 "배선의 부호 구조만으로는 갈등 신호가 나오지 않는다"까지를 말한다.

## 한계

- 출력 뉴런 이후는 한 단계 선형 전달이다. 실제 뉴런의 문턱, 시간 동역학, 여러 단계의 연결은 없다.
- 도파민 구역 배정은 도파민 뉴런 -> 출력 뉴런 시냅스 수의 다수결이다.
- 글루탐산을 억제로 두었다(초파리에서 흔한 해석이지만 항상 그렇지는 않다).

## 다음

- 비교기 뉴런에 문턱(비선형성)을 넣어, "두 기억이 함께 올 때만 켜지는" 갈등 감시 뉴런이 생길 수 있는 배선 조건이 있는지 본다.
- 학습 누출(25)이 비교기와 행동 선택 갈래까지 전달되는지 본다(냄새 없이 생기는 거짓 가치 신호가 행동 출력까지 가는가).
