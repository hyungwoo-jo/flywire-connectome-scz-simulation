# 65 后속: 실제 기저 영상에 사건 주입·회수

2026-10-18. 관측 감사에서 Gaussian AR(1)이 실제 음 사건률을 재현하지 못한 뒤 작성한 추가 탐색 계획이다. 아래 회수 결과를 계산하기 전에 고정한다. 원래 회로의 생리학적 기각을 직접 판정하는 실험은 아니다.

## 설계

- 기존 감사의 비교 개체 12마리에서 실제 냄새 전 정규화 형광을 사용한다. 실제 시간 구조·비Gaussian 잡음·기존 생물학적 활동을 보존한다.
- 세포별 반응 폭 B가 큰 세포에 알려진 양의 사건 발생 성향을 부여한다. 성향은 exp(zscore(B))를 평균 1로 정규화한 뒤 시행당 평균 0.02 또는 0.1의 Bernoulli 확률로 바꾸고 1에서 자른다. 실제 모형 사건률을 추정한 것이 아닌 통제된 효과 주입이다.
- 주입 형광은 세포별 기저 MAD×1.4826의 2·4·8배다. 8프레임의 exp(-frame/2) 펄스를 냄새 전 구간 안에 무작위로 넣는다. 크기는 실제 칼슘 진폭의 확정값이 아닌 검출 민감도 축이다.
- 개체·조건별 10개 seed를 사용한다. 동일 seed의 사건 위치와 유무를 진폭 비교에서 공유한다. 사건 없음 대조도 기록한다.
- 65와 동일한 MAD 3배·2연속 프레임 규칙을 다시 적용해 양·음 사건률을 센다. 이전 영상에서 이미 검출된 사건을 빼서 추가 검출량도 보고한다. 사건 창 안에서 원래 검출되지 않았으나 주입 후 검출된 경우를 회수로 센다. 같은 사건을 두 번 세지 않는다.
- 결과: 실제 주입 비율, 회수율, B와 알려진 성향/주입 횟수/최종 검출 사건률의 상관. 모의 seed를 독립 동물로 취급하지 않는다.

## 해석

큰 주입은 회수되고 작은 주입은 누락된다면 칼슘 사건의 검출이 잠재 활동 크기에 의존함을 보여준다. 이것만으로 원래 허브 예측이 맞거나 틀렸다고 결론내리지 않는다. 원래 모형의 활동-형광 진폭과 시간 대응이 식별돼야 그 예측의 검출력을 판단할 수 있다. 실제 기저 영상에 이미 존재하는 사건과 회수의 혼동을 별도로 기록한다.
