# 사전 등록: 30 단계 (누출의 일반성: 모든 MBON)

2026-10-09. **결과를 보기 전에 작성했다.** MBON 수만 미리 셌다(KC 입력 100개 이상인 MBON: 오른쪽 22개, 왼쪽 17개).

## 질문

25~29의 누출은 MBON11 하나로만 측정했다. 학습된 가치가 허브 KC를 통해 잡음에 누출되는 현상이 KC 입력을 충분히 받는 다른 MBON에서도 나타나는가?

## 방법

- 두 반구, 원래 부분 회로(16, 22의 보정), 25와 같은 입력, 시드, 학습 규칙, 누출 정의, 통제를 쓴다.
- 대상: 각 반구에서 서로 다른 KC 100개 이상에게서 입력을 받는 MBON 전부(cell_type이 MBON으로 시작, 결과를 보기 전에 정한 기준).
- MBON마다 KC 입력 시냅스 수를 총합으로 나눈 가중치로 25의 누출을 계산한다.
- MBON마다 특이 누출 = 누출(학습) - 누출(통제)의 냄새 평균과, 냄새 재표집 부트스트랩 1,000회(시드 300300 + MBON 순번) 95% 구간을 구한다.

## 판정

- 반구마다 특이 누출의 95% 구간이 0보다 위인 MBON의 비율 P를 구한다.
- 두 반구 모두 P >= 0.75: "누출은 MBON 일반적 현상".
- 두 반구 모두 P <= 0.25: "누출은 MBON11 등 일부에 국한".
- 그 밖: "부분적".

**보조 (판정 없음).** MBON의 KC 입력 수, 입력을 주는 KC 하위 유형 비율(g, ab, a'b')과 특이 누출의 관계를 기술한다.

## 한계

- 학습 규칙과 학습 신호를 모든 MBON에 똑같이 적용한다. 실제로는 구획마다 다른 DAN이 다른 규칙으로 학습을 조절한다.
- MBON의 출력 부호(흥분, 억제)와 행동적 의미는 다루지 않는다.
