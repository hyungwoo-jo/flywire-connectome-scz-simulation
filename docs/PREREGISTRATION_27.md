# 사전 등록: 27 단계 (흥분성 보상의 강도와 누출)

2026-10-09. **결과를 보기 전에 작성했다.**

## 배경

26에서 KC 입력 총량을 같게 맞추면 학습된 가치의 누출이 사라지고 구분이 좋아졌다. 하지만 입력 가중치를 직접 고치는 것은 생물학적 조작이 아니다. 실제 초파리에서는 KC마다 다른 특성이 서로 보상해 KC들이 평균적으로 비슷하게 활동하게 된다는 연구가 있다(Abdelrahman, Vasilaki, Lin 2021). 이 원리를 KC별 문턱으로 구현하고, 보상의 강도를 바꿔 본다.

## 보상의 구현

- 배선(입력 가중치)은 원래 그대로 둔다.
- **완전 보상 문턱:** KC i의 흥분 입력 E_i(o) = (W x_o)_i를 보정용 냄새 37개(무잡음)에서 계산한다. 그 90백분위를 θ_i^h로 둔다. 즉 각 KC가 보정용 냄새의 약 10%에만 반응하도록 하는 문턱이다(APL 이전 기준). 대응 PN 입력이 없는 KC는 θ_i^h를 다른 KC들의 평균으로 둔다(어차피 켜지지 않는다).
- **보상 강도 α:** θ_i(α) = s_α [(1 - α) θ̄ + α θ_i^h]. θ̄는 θ^h의 평균이다. s_α는 보정용 냄새에서 전체 활성 KC 평균이 10%가 되도록 이분법으로 정한다. α = 0이면 모든 KC가 같은 문턱이므로 원래 모형과 같다(재현 점검).
- α = 0, 0.25, 0.5, 0.75, 1.

## 측정

각 α, 두 반구에서 다음을 측정한다.
- 학습된 가치의 누출과 무작위 학습 통제의 누출. 25와 같은 정의, 시드, MBON11 가중치를 쓴다. 검출 기준도 각 α 회로에서 다시 정한다.
- 범용 냄새 구분 d'. 18의 주 조건, 같은 잡음 시드를 쓴다.
- 보조: 참여도(KC가 반응하는 평가용 냄새 수)의 최대와 지니 계수, 잡음 "있다" 판단률.

## 판정

- **H27a (누출).** 두 반구 모두 (i) 누출이 α에 따라 단조 감소하고(5개 수준의 Spearman rho = -1), (ii) 누출(α = 1) / 누출(α = 0) <= 0.5이면 "보상이 강할수록 누출이 줄어든다".
  - (ii)만 충족하면 "보상은 누출을 줄이지만 단조롭지는 않다".
  - 둘 다 충족하지 않으면 "지지되지 않음".
- **H27b (구분).** 두 반구 모두 d'(α = 1) > d'(α = 0)이면 "보상이 구분을 높인다".

## 한계

- 90백분위 문턱은 "평균 활동을 고르게"라는 원리의 한 구현일 뿐이다. 실제 보상은 문턱 외에도 입력 강도, 크기 등 여러 특성에 걸쳐 일어난다.
- 21개 사구체 부분 회로, BANC 한 개체다.
