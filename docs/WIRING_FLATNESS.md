# 실제 배선은 손실 지형의 평평한 곳에 있는가 (69)

2026-10-19. [사전 등록](PREREGISTRATION_69.md)에 따라 실행했다. 갈래 2의 첫 단계다.

## 질문

PN→KC 시냅스마다 평균 1인 로그정규 배수를 곱해 흔들었다(σ 0.1, 0.3, 0.5, 각 10회). 그때 냄새 식별 정답률과 가치 기억 정확도가 얼마나 떨어지는지(뾰족함 S)를 봤다. 비교 대상은 실제 배선, 세기 보존 무작위 배선 10개, 입력을 고르게 한 배선이다.

### 판정

| 예측 | 기계적 판정 | 효과 크기 |
|---|---|---|
| F1 식별: 실제 대 무작위 | "더 평평함" (5/5에서 실제 S < 무작위 중앙값) | 차이 0.1~0.2%p. 실제 값이 무작위 10개 범위 안이다 |
| F2 기억: 실제 대 무작위 | "더 평평함" (4/5) | 차이 1%p 미만. 무작위 범위 안이다 |
| F3 고르게 한 배선 | 두 과제 모두 "고르게 하면 평평해짐" | 실제 뜻은 다르다. 아래 해석 2를 본다 |
| F4 성능과 뾰족함의 관계 | 두 과제 모두 "양의 관계" (ρ 0.48~0.86, 식별은 4/5) | 뾰족함의 범위 자체가 1%p 미만이다 |

## 해석

1. **실제 배선과 무작위 배선 모두 시냅스 잡음에 아주 강건하다.**
   - 시냅스마다 σ = 0.5(대략 ±50%)로 흔들어도 식별과 기억은 1%p 넘게 변하지 않았다.
   - 사전 규칙으로는 실제 배선이 "더 평평함"이지만, 차이가 무작위 배선 사이의 변동 안에 있다. 따라서 "진화한 배선이 특별히 평평한 곳에 있다"는 근거로 쓰지 않는다.
   - 이 회로에서 평탄도는 배선 패턴이 아니라 확장층 구조 자체(희소 문턱, 평균화)의 성질로 보인다.
2. **입력을 고르게 한 배선은 평평한 극소점이 아니라 나쁜 점이다.**
   - KC 입력 세기를 같게 맞추면 식별 정답률이 14~18%p 떨어졌다(0.95 → 0.77~0.83).
   - 무작위로 흔들기만 해도 성능이 다시 올랐다(σ 0.5에서 0.92~0.94).
   - F3의 기계적 판정("고르게 하면 평평해짐")은 S가 음수여서 나온 것이다. 실제 뜻은 "고르게 한 배선은 손실 지형의 오르막에 있고, 불균일성을 다시 넣으면 내려간다"다.
   - 단위 수준에서 "평평한(균일한)" 확장층은 이 과제들에서 불리했다.
3. **F4는 딥러닝의 통념과 방향이 반대다.** 성능이 좋은 배선일수록 섭동에 약간 더 민감했다. 그러나 뾰족함 차이가 1%p 미만이므로 의미를 두지 않는다.
4. **26과의 충돌.**
   - 26에서는 입력을 고르게 하자 범용 냄새 구분 d'가 올랐다(+1.5).
   - 여기서는 단일 시행 식별 정답률이 크게 떨어졌다.
   - 지표가 다르다. d'는 평균 반응의 분리도이고, 여기서는 Poisson 잡음 시행을 원형에 대어 분류했다. 문턱 보정도 다를 수 있다.
   - 고르게 하면 입력이 적은 KC의 배율이 커진다. 그러면 그 KC가 받는 소수 PN의 잡음도 함께 커질 수 있다. 확인은 하지 않았다.
   - 이 충돌은 71 이후에 다룬다.
5. **68과 함께 읽으면** KC 입력 세기의 불균일성에 서로 다른 값이 걸려 있다.
   - 해석 가능성에는 비용이다(68: 고르게 하면 분해 복원 +0.1~0.2).
   - 단일 시행 식별에는 이득이다(69: 고르게 하면 -14~18%p).
   - 간섭에는 비용이다(70: 고르게 하면 누출 감소).
   - 배선의 세부 패턴은 세 측면 모두에서 무작위와 구분되지 않았다.

## 한계

- 섭동은 시냅스 세기에만 준다. 연결의 생성과 소멸은 없다.
- 무작위 배선은 KC별 입력 세기를 보존한다. 그래서 "어느 PN에서 받는가"의 효과만 본다.
- 성능은 고정 판독(원형 분류, 가치 기억 규칙)으로 잰다. 딥러닝의 손실 지형과는 비유적으로만 대응한다.
- 문턱을 다시 보정한 섭동(보고만)은 고정 문턱과 거의 같았다(차이 0.5%p 미만).
