# 입력 구분 재현성: 두 번째 탐구

2026-10-08. [첫 입력 구분 실험](INPUT_DISCRIMINATION.md)의 한 패턴 쌍 의존성과 대조군의 입력 가중치 합 차이를 보완했다. 결과를 원하는 방향으로 맞추지 않고 설정 변화와 예외를 함께 기록했다.

## 이번에 추가한 것

- 겹침 25/60/90%와 잡음 0.1/0.4의 각 조합에서 인공 입력 쌍을 8개로 늘렸다. 각 패턴의 반복 40개 중 20개로 평균 출력을 만들고 나머지 20개로 분류한다.
- 기준 문턱의 0.8/1.0/1.2배, APL 모델 gain 2/4/8을 실제 회로에서 비교했다. 문턱을 조건별로 다시 적합하지 않았다. 각 설정에서 APL 정상과 제거를 비교했다.
- PN→KC 대조군 10개는 같은 가중치의 연결끼리만 대상을 교환했다. 뉴런별 연결 수, PN의 출력 가중치 집합·합과 **KC별 입력 가중치 합도 보존**한다. KC–APL은 그대로다.
- 실제 회로의 설정 민감도 864개 조건과 기준 설정의 대조군 960개 조건, 총 1,824개 조건을 계산했다. 무작위 대조군의 설정은 문턱 1배·gain 4뿐이며, 모든 설정에서 실제 회로와 대조군을 비교한 것은 아니다.

같은 가중치끼리의 교환은 53,100회 성공했다. 연결 상대가 달라진 비율은 약 99.4~99.6%, 전체 가중치 중 대상이 달라진 몫은 약 98.0~98.9%였다. 입력 강도 차이를 통제했지만 가중치가 같은 연결 사이로 혼합을 제한하므로 모든 가능한 배선을 균등하게 추출했다고 할 수 없다.

입력과 시드는 모든 회로와 설정에서 공유했다. 잡음 수준마다 별도의 시드로 입력 패턴을 만들었으므로 잡음 수준의 차이를 동일한 패턴에 대한 순수 잡음 효과로 해석하지 않는다. 하나의 패턴에 여러 독립적인 잡음 묶음을 넣는 추가 검증은 남아 있다.

## 결과

기준 설정(문턱 1배, gain 4)의 높은 겹침·큰 잡음 조건에서:

| 지표: 입력 8쌍 평균 | APL 정상 | APL 제거 |
|---|---:|---:|
| 활성 KC 비율 | 14.77% | 24.79% |
| 평균 출력 패턴 cosine 유사도 | 0.9191 | 0.9333 |
| 별도 평가 입력 분류 정확도 | 87.19% | 88.13% |

분류 정확도는 APL 제거 후 8쌍 중 2쌍에서 감소, 1쌍에서 동일, 5쌍에서 증가했다. 변화의 범위는 −5~+5%포인트이며, 평균은 +0.94%포인트다. 조건별 평가 입력은 40개라 한 개의 정답 차이가 2.5%포인트다. 작은 평균 차이에 생물학적 유의성을 부여하지 않는다.

입력별 정확도 변화는 순서대로 +5, +5, +2.5, +2.5, −5, 0, −5, +2.5%포인트였다. APL 제거 시 활성 KC 비율은 8쌍 모두 증가했다. 출력 패턴의 유사도는 7쌍에서 증가했고 1쌍에서 아주 작게 감소했다. ‘유사도 증가’와 ‘구분 성능 저하’를 동일시할 수 없다는 첫 판단이 유지됐다.

이 어려운 조건에서 대조군별로 8쌍을 평균한 정확도 변화는 −2.81~+1.88%포인트였다. 실제 회로의 +0.94%포인트는 그 범위 안이었다. 연결 수뿐 아니라 KC의 입력 가중치 합도 통제했지만 이번 지표에서 실제 배선만의 특별한 반응을 확인하지 못했다. 이 범위는 신뢰구간이 아니며, 대조군과 패턴들을 독립적인 생물학적 표본으로 합치지 않았다.

문턱과 APL gain의 9개 조합에서도 높은 겹침·큰 잡음의 평균 정확도 변화는 모두 양수였으며 약 +0.63~+3.44%포인트였다. 이는 검사한 범위에서 APL 약화가 평균적인 구분 장애를 만들지 않았다는 탐색 결과다. 모든 입력·수용체·동역학 모형에서 그렇다는 결론은 아니다. 쉬운 조건에서는 기준 설정의 분류 정확도 변화가 모두 0이어서 차이를 평가하기 어려웠다.

정상 상태 수치 잔차의 최댓값은 약 7.1×10^-12다. 수치 정확성과 생물학적 타당성은 별개다.

## 이 결과가 다음 단계에 주는 방향

현재 모델은 억제가 출력을 희소하게 만든다는 현상은 보인다. 그러나 희소성이 곧 분류 정확도 향상을 보장하지는 않는다. 분류기는 모든 KC를 이용해 두 평균 패턴에 대한 거리를 계산하며, 생물학적인 학습 회로나 행동 출력은 없다. 이런 읽기 방식이 실제 회로의 제약을 생략할 수 있다.

다음 단계는 **학습된 읽기 회로를 명시적으로 추가하는 것**이다. KC→MBON의 실제 연결을 버전 ID로 확인하고, 출력과 보상 신호·학습 규칙을 구분한다. 먼저 정상 입력을 배운 뒤 별도 평가 입력에서 학습 전후 성능을 검증한다. 그 단계가 작동한 다음, 억제 약화가 학습·일반화에 어떤 영향을 주는지를 물을 수 있다.

도파민은 활동 전체에 상수를 더하는 대신 어떤 연결의 변화가 언제 일어나는지를 조절하는 변수로 정의할 예정이다. 어떤 생물학적 기억 규칙을 단순화하는지 자료를 확인하고 명시해야 한다. **이번 07에는 학습·도파민·기억 오류를 추가하지 않았다.** 현재 결과를 조현병이나 환각의 증거로 해석하지 않는다.

## 한계와 재현

원자료 한 개체, 인공 감각 입력, 단일 활동 변수의 APL, 임의 모델 계수, 제한된 문턱 범위, 두 패턴 평균 거리 분류기의 한계가 유지된다. 8개 입력 쌍은 서로 다른 생물학적 개체가 아니다. 입력 활성 비율이나 잡음 분포를 바꾼 검증은 아직 없으며, PN/KC 막전위·시냅스 전도도·행동의 실측을 적합한 모형도 아니다.

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
  .venv/bin/python pipelines/07_discrimination_robustness.py \
  --pairs 8 --nulls 10 --trials 40
.venv/bin/python -m unittest discover -s tests -v
```

06의 결과 manifest에 저장한 문턱을 이어 사용하므로 06을 먼저 실행해야 한다. 이전 manifest의 체크섬과 원자료 SHA-256을 대조하고, 달라졌으면 실행을 중단한다. 결과는 qc_reports/discrimination_robustness/ 아래에 저장했다.

- metrics.csv: 1,824개 조건의 원래 지표와 잔차.
- paired_effects.csv: 같은 입력·회로·설정에서 APL 제거 − 정상의 차이.
- summary.csv: 입력 쌍 평균과 범위.
- pn_input_baseline.csv: 입력 자체의 분류 난이도.
- manifest.json: 설계, 원자료 체크섬, 시드, 모델 설정과 대조군 혼합 정도.
- robustness.png: 어려운 입력의 쌍별 효과와 모델 계수 민감도.
