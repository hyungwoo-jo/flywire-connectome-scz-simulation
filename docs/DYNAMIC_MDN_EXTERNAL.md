# 모형 밖 입력의 변동을 넣어도 MDN 효과가 남는가 (52)

2026-10-12. 개인 프로젝트의 탐색 분석이다(`pipelines/52_dynamic_mdn_external_noise.py`). 지표는 실행 전에 스크립트 머리말에 고정했다. 51의 큰 한계는 비교 기준(자연 변동)이 냄새 경로에서 온 변동뿐이라는 점이었다. 이번에는 각 뉴런이 모형 밖에서 받는 입력의 변동을 더했다.

## 방법

- 51의 망(되먹임 g 0.9)을 그대로 쓴다.
- 각 뉴런에 시행마다 바깥 입력 변동을 더한다. 크기 = kappa x (그 뉴런의 모형 안 입력 표준편차) x (바깥 입력 비율 / 안쪽 입력 비율). MDN은 바깥/안쪽 비가 약 0.95다.
- kappa 1은 바깥 시냅스가 안쪽 시냅스만큼 변하고 서로 완전히 같이 움직인다는 가정이다. 독립적으로 움직이면 실제로는 이보다 작다. 그래서 kappa 1은 큰 쪽 가정이다. 0.5, 1, 2, 4를 봤다.
- 같은 시행에서 학습 전과 후에 같은 변동을 쓴다. 문턱은 변동을 넣은 상태에서 다시 맞췄다.

MDN 전환(꺼짐/켜짐이 바뀐 잡음 시행)은 0~33%였다.

## 해석

1. **바깥 입력이 안쪽만큼 변하는 가정(kappa 1)까지는 효과가 51과 거의 같다**(z 1.0~1.9).
2. **바깥 변동이 두 배(kappa 2)여도 z 0.7~1.3으로 남는다.**
3. **네 배(kappa 4)면 대부분 z 0.5 아래로 내려간다.** 이 모형에서 거짓 신호가 MDN 수준에서 드러나는 한계는 "바깥 입력이 냄새 경로보다 2~4배 더 크게 변하는가"에 달려 있다.
4. 배운 냄새 특이성(무작위 대조 대비 약 7~10배, 강도 대조 대비 약 2배)은 모든 kappa에서 유지됐다.

## 한계

- 바깥 입력의 실제 변동 크기는 커넥톰으로 알 수 없다. 걷는 중인 초파리에서는 다리 감각 신호 때문에 MDN 입력이 크게 변할 수 있다(그러면 kappa가 크다). 가만히 있을 때는 작을 수 있다.
- 바깥 변동을 뉴런마다 독립된 정규 잡음으로 넣었다. 실제로는 뉴런끼리 상관된 변동이 있다.
- 51의 다른 한계(구역 특이성 없음, 시냅스 수 비율 근사, 같은 시간 상수)는 그대로다.
