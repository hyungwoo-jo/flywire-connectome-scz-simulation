# 학습 누출의 이론: 닫힌 식 지표 (43)

2026-10-10. 25~38의 "학습 누출"을 시뮬레이션 없이 계산할 수 있는 식으로 정리하고, 다섯 반구와 보상 단계에서 시뮬레이션 결과와 비교했다. 사전 등록 없이 진행한 이론 점검이다(`pipelines/43_leakage_theory.py`).

## 식

출력 뉴런(MBON)이 KC i를 가중치 w_i로 읽고, 냄새 A를 배우면 연결이 `w_i -> w_i exp(-eta k_A,i)`로 약해진다고 하자. 학습에 의한 감소분을 `d_i = 1 - exp(-eta k_A,i)`라 쓴다. 어떤 시행에서 KC 활동이 k일 때, 출력의 상대 감소(가치 신호)는 다음과 같다.

```
L(k) = sum_i w_i k_i d_i / sum_i w_i k_i
```

잡음 시행에서 KC i의 평균 활동을 m_i라 하면, 잡음 시행에서 기대되는 가치 신호를 근사할 수 있다.

```
L_hat = sum_i w_i m_i d_i / sum_i w_i m_i
```

즉 **잡음 활동으로 가중한 학습 패턴의 평균**이다. 학습 패턴과 잡음 활동이 무관하다면 L_hat은 `L_base = sum_i w_i d_i / sum_i w_i`(학습 패턴의 단순 가중 평균)가 된다. 둘의 비가 허브 인자다.

```
H = L_hat / L_base
```

H > 1이면 잡음이 학습된 KC들을 우연보다 더 많이 켠다는 뜻이다. 입력이 많은 KC(허브)는 냄새에도 잡음에도 잘 켜지므로 학습 패턴(d)과 잡음 활동(m)이 함께 커지고, 그래서 H가 커진다.

## 시뮬레이션과의 비교

다섯 반구 각각에서 원래 회로와 입력 강도 보상 2단계(29의 α = 0.5, 1), 모두 15개 조건을 계산했다.

| 비교 | Spearman 상관 |
|---|---:|
| 조건 간: L_hat 평균 대 시뮬레이션 누출 평균 (15개 조건) | **0.94** |
| 조건 간: H 평균 대 냄새 특이 누출 평균 | 0.80 |
| 조건 안, 냄새 간: L_hat 대 누출 (15개 조건의 중앙값) | 약 0.78 |

| 반구 | 원래 회로 H | 보상 0.5 H | 완전 보상 H |
|---|---:|---:|---:|
| BANC 오른쪽 | 10.9 | 6.6 | 5.0 |
| BANC 왼쪽 | 12.3 | 6.8 | 2.6 |
| FlyWire 오른쪽 | 6.4 | 3.6 | 3.1 |
| FlyWire 왼쪽 | 5.4 | 2.9 | 3.4 |
| hemibrain 오른쪽 | 6.6 | 3.1 | 4.2 |

## 해석

1. **학습 누출은 한 줄의 식으로 대부분 설명된다.** 시뮬레이션의 복잡한 과정(잡음 표본, 검출 기준, 판정 문턱)을 거치지 않고, "잡음 활동과 학습 패턴의 겹침"만으로 조건 사이의 누출 차이가 거의 그대로 예측된다(상관 0.94).
2. **허브 인자 H가 핵심 양이다.** 원래 회로에서 학습된 KC 패턴은 무작위보다 5~12배 더 잡음 활동과 겹친다. BANC가 가장 크고(11~12), FlyWire와 hemibrain은 5~7이다. 이 차이가 자료 간 누출 크기 차이(BANC 3.4~3.7%p, FlyWire 1.6~1.9%p)와 맞는다.
3. **보상은 H를 줄인다.** 입력을 고르게 할수록 H가 대체로 줄었다. 완전 보상에서도 H가 1보다 크게 남는 것은 입력 총량 말고도 입력의 구성(어떤 PN에게서 받는가)이 잡음 활동과 학습 패턴을 함께 정하기 때문이다.
4. **일반화.** 이 식은 초파리에만 해당하지 않는다. "입력이 많은 세포가 신호와 잡음 양쪽에 참여하고, 학습이 그 세포들의 출력을 바꾸는" 구조라면 같은 식이 적용된다. 소뇌의 과립세포처럼 확장층과 학습 가능한 출력을 가진 회로에서도 H를 계산할 수 있다.

## 한계

- 잡음 시행의 활동을 평균 m으로 바꾼 근사다. 시행마다 켜지는 KC 수가 매우 적어 변동이 크므로, 개별 시행 수준의 예측은 덜 정확하다.
- 검출 기준과 판정 문턱은 식에 들어 있지 않다. 그래서 절대 누출률이 아니라 순위와 상대 크기를 예측한다.
