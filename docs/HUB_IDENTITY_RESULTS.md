# 허브 KC는 어떤 KC인가 (31)

2026-10-09. [사전 등록](PREREGISTRATION_31.md)에 따라 실행했다.

## 질문

30에서 αβ KC를 많이 읽는 MBON일수록 학습된 가치의 누출이 컸다(사후 관찰). 허브 KC(냄새 참여도 상위 10%)가 αβ에 몰려 있는지, 그리고 허브 KC의 입력이 과수렴 사구체 묶음(DM2, DM4, VM2, VM3)에서 오는지 확인했다.

## 결과

| | 오른쪽 | 왼쪽 |
|---|---:|---:|
| 허브 기준 (73개 냄새 중 반응 수) | 60 이상 | 55 이상 |
| 허브 KC 수 / 반응 KC 수 | 71 / 679 | 72 / 704 |
| 허브 중 KCab 비율 / 반응 KC 중 KCab 비율 | 50.7% / 51.1% | 40.3% / 40.8% |
| Fisher p (단측) | 0.58 | 0.58 |
| 과수렴 묶음 입력 비율 중앙값 (허브 / 나머지) | 0.27 / 0.33 | 0.39 / 0.11 |
| Mann-Whitney p (단측) | 0.92 | 0.011 |
| 입력 총량 중앙값 (허브 / 나머지) | 1.56 / 0.82 | 1.70 / 0.93 |
| 대응 PN 연결 수 중앙값 (허브 / 나머지) | 5 / 3 | 4 / 3 |
| 잡음 시행 활성 비율 (허브 / 나머지) | 5.3% / 0.9% | 5.7% / 1.2% |

하위 유형별로 보면 KCab와 KCg의 허브 비율은 약 10%로 같았고, KCa'b'는 5~7%로 낮았다. 참여도 중앙값은 KCab 16~17, KCg 15, KCa'b' 7이었다.

## 판정

- **H31a: 지지되지 않음.** 허브는 αβ에 몰려 있지 않다. αβ와 γ는 허브 비율이 같다.
- **H31b: 지지되지 않음.** 허브 입력이 과수렴 묶음에서 더 많이 온다는 것은 왼쪽에서만 성립했고 오른쪽은 반대였다.

## 해석

- **허브 KC는 하위 유형이나 특정 사구체가 아니라 "입력의 양"으로 정의된다.** 허브는 대응 PN 연결이 더 많고 입력 총량이 약 2배이며, 잡음에 약 5배 더 자주 켜진다. 25~26의 기제(입력이 많은 KC가 냄새와 잡음 양쪽에 참여)와 일치한다.
- **30의 관찰(αβ를 읽는 MBON의 누출이 큼)에 대한 수정.** 허브가 αβ에 몰려서가 아니다. α'β' KC는 냄새에 훨씬 덜 반응한다(참여도 중앙값 7). 그래서 α'β' 위주의 MBON은 학습과 잡음 양쪽에서 쓰는 KC가 적어 누출이 작았다고 보는 편이 맞다. 이것도 사후 해석이다.
- 17의 과수렴 구조(과일 사구체 묶음)와 25의 허브 기제는 서로 다른 성질로 보인다. 과수렴은 "어떤 사구체끼리 같은 KC를 공유하는가"이고, 허브는 "어떤 KC가 입력을 많이 받는가"다.
