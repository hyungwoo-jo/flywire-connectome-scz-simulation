# 갈래 2: 몸 상태는 거짓 가치 신호를 행동 쪽에서 더 잘 드러나게 하는가 (48)

2026-10-10. 개인 프로젝트의 탐색 분석이다(`pipelines/48_body_state_gating.py`). 46에서 냄새 없이도 학습된 가치 신호가 행동 선택 뉴런(44의 "가치 + 몸 상태" 통합 뉴런 12개)까지 전달되는 것을 봤다. 이 뉴런들은 몸에서 올라오는 상행 신호도 받는다. 몸 상태(통증, 스트레스 같은 상행 활동)가 높을 때 거짓 신호가 행동 쪽에서 더 쉽게, 혹은 더 또렷하게 드러나는지 봤다.

## 모형

- 행동 선택 뉴런 i의 발화율: `r_i = max(0, V_i + B_i(a) - theta_i)`.
  - V_i: 출력 뉴런에서 오는 가치 입력(실제 시냅스 수와 전달물질 부호).
  - B_i(a): 상행, 내분비 뉴런에서 오는 지속적인 몸 상태 입력. 몸 상태 강도 a를 0에서 8까지 바꿨다. a = 1은 몸 상태 시냅스가 잡음 시행에서 평균적인 출력 뉴런 시냅스만큼 활동한다는 뜻이다.
  - theta_i: 학습 전, a = 1에서 잡음 시행의 5%만 넘도록 뉴런마다 정했다.
- 냄새 A를 처벌과 짝지어 학습한 뒤(대조: 같은 학습량을 무작위 KC 또는 입력 강도가 같은 KC에), 같은 잡음 시행에서 발화율 변화 패턴이 "약한 A에 대한 발화율 변화"와 닮은 비율을 셌다(코사인 0.5 초과, 크기 절반 이상, 검출기가 "냄새 있음"으로 판단한 시행).

## 해석

1. **거짓 신호가 나타나는 빈도는 몸 상태와 거의 무관하다**(학습 후 1.9~2.3%).
2. **몸 상태가 높을수록 거짓 신호의 내용이 학습한 냄새에 더 특이적이 된다.** 무작위 학습이나 허브 효과에서 오는 "A와 닮은" 신호는 몸 상태가 높을수록 줄었다. 그래서 학습 조건과의 비가 3배에서 10배(무작위 대비), 1.2배에서 2.3배(강도 맞춘 대조 대비)로 커졌다.
3. 몸 상태 a = 2 이상에서는 행동 선택 뉴런들이 늘 켜져 있는 상태가 된다(학습 전에도 모든 잡음 시행에서 발화).
4. 정리하면 이 모형에서 몸 상태가 높은 상태는 거짓 지각을 **더 자주** 만들기보다, 거짓 지각의 **내용을 최근 배운 것 쪽으로 더 또렷하게** 만든다.

## 기제와 한계

- 기제는 문턱 함수의 성질이다. 몸 상태 입력이 낮으면 뉴런 대부분이 문턱 아래에 있어서, 학습의 흔적이 몇 개 뉴런에서만 듬성듬성 드러난다. 듬성듬성한 패턴은 우연히도 "A와 닮았다"고 판정되기 쉽다(대조의 누출이 높음). 몸 상태가 높으면 모든 뉴런이 문턱 위의 선형 구간에 있어 학습의 흔적이 전체 패턴으로 드러난다. 그래서 A를 실제로 배운 경우와 아닌 경우가 잘 갈린다.
- 즉 이 결과는 "문턱이 있는 뉴런 + 지속적인 몸 상태 입력"이라는 가정에서 나온다. 실제 상행 뉴런의 활동 수준, 시간 변화, 몸 상태 신호가 흥분인지 억제인지(여기서는 예측 전달물질 부호)에 따라 달라질 수 있다.
- 단위(a = 1의 의미)는 임의로 정했다. 상대적인 경향만 해석한다.

## 관심사와의 연결

"스트레스나 통증 상태에서 사람들이 없는 것을 느낄 때, 그 내용이 최근의 걱정이나 학습과 관련된다"는 임상적 직관과 같은 방향이다. 이 모형에서는 몸 상태가 거짓 지각의 빈도보다 내용의 특이성을 바꾼다. 이것은 디지털 모형에서 나온 가설이다.
