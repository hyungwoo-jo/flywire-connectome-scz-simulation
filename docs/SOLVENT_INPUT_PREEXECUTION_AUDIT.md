# 66 실행 전 용매 입력 단위 감사

2026-10-18. 66 사전등록과 실행 계획은 보존한다. **입력 s를 24채널 모두 baseline-subtracted spikes/s로 취급한다는 전제가 확인되지 않아 현재 계획의 생리학적 해석을 보류한다.** 이번 감사에서 66의 용매 시뮬레이션 결과는 계산하지 않았다.

## 근거

고정된 DoOR.data 커밋 db323a496577c4b4a72b5c2fcd1859e07521ffb5의 door_dataset_info.csv는 Hallem.2004.EN의 SFR.substracted를 `only in datasets with inhibition`으로 설명한다. 반면 Hallem.2006.EN은 `yes`다. 따라서 서로 다른 열의 용매·냄새 값을 동일한 baseline-subtracted 단위로 가정할 수 없다.

24개 수용체의 2004 EN 용매 값은 모두 유한하지만 같은 열의 SFR은 6개만 유한했다. 원 데이터 파일의 SHA-256을 기존 Hallem 보정 manifest와 대조했다.

| 채널 | 용매 2004 EN | SFR 2004 EN | 같은 열 차이 |
|---|---:|---:|---:|
| Or47b | 72.576 | 73.076 | -0.500 |
| Or7a | 27.667 | 15.592 | 12.075 |
| Or22a | 10.000 | 6.186 | 3.814 |
| Or85b | 58.333 | 결측 | 계산 불가 |

Or47b의 큰 용매 값은 큰 증가분을 의미하지 않는다. 현 `sample_orn(delta,sfr,...)`는 delta에 2006 SFR을 더해 Poisson 입력을 만든 뒤 다시 뺀다. 2004 용매 절대값을 delta 자리에 넣으면 기준 발화가 중복될 수 있다.

일부 채널에는 음의 응답값이나 이미 차감된 SFR 0도 있으므로 모든 열에서 일괄 SFR 차감하는 수정 역시 근거가 부족하다. 6개 SFR만으로 나머지 18개를 유추하지 않는다. 2006 SFR은 다른 연구·조건이므로 2004 기준값의 단순 대체재로 사용하지 않는다.

## 실행 조건

- 각 채널/원 실험의 기준 발화·차감 처리 정의를 원 논문·보충자료 또는 저자 자료에서 확인한다.
- 용매를 실측 입력으로 쓸 경우 같은 단위의 냄새·기준값을 구성한다. 자료가 부족하면 관측된 일부 채널의 별도 탐색 모델로 범위를 제한하고 기존 66 주 분석으로 부르지 않는다.
- 단위를 해결하지 못한 채 기존 s를 쓰는 실행은 '서로 다른 측정 단위를 혼합한 인공 입력 민감도 실험' 이상의 해석을 하지 않는다.
- 수정한 입력 정의는 새로운 계획/수정 기록으로 실행 전에 고정한다. 기존 66 사전등록을 사후에 조용히 바꾸지 않는다.

재현 감사 함수는 pipelines/65x_observation_model.py의 audit_solvent_units이고 표는 qc_reports/observation_audit/solvent_unit_audit.csv다. 공개 출처: [DoOR.data](https://github.com/ropensci/DoOR.data), Hallem et al. 2004 DOI 10.1016/j.cell.2004.05.012. 단위 문제를 해결하기 전까지 original/보상 회로의 용매 누출 판정은 내리지 않는다.
