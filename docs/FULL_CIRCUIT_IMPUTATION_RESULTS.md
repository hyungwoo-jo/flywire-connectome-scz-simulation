# 부분 회로가 허브를 과장했는가 (28)

2026-10-09. [사전 등록](PREREGISTRATION_28.md)에 따라 실행했다.

## 질문

16~27은 Hallem 자료가 있는 21개 사구체의 PN만 입력을 받는 부분 회로였다. KC마다 대응 사구체에서 받는 입력 비율이 다르면, 부분 회로에서 허브가 과장될 수 있다. 25의 핵심 결과(허브 KC를 통한 학습된 가치의 누출)가 그 인공물인지 확인했다.

## 방법 요약

- 각 반구의 모든 PN->KC 연결을 썼다.
- 대응되지 않은 사구체 유형마다 가상 채널을 하나씩 만들었다. 실제 Hallem 수용체 하나의 반응을 냄새 축에서 무작위로 섞은 것이라, 크기 분포는 실제와 같고 조율은 없다. 대입은 20회 반복했다.
- 각 대입 회로에서 문턱과 검출 기준을 다시 정하고, 25와 같은 방식으로 누출을 계산했다.

## 결과

| | 오른쪽 부분 회로 | 오른쪽 전체 회로 (20회 중앙값, 범위) | 왼쪽 부분 회로 | 왼쪽 전체 회로 (20회 중앙값, 범위) |
|---|---:|---:|---:|---:|
| 냄새 특이적 누출 (학습 - 통제) | 3.42%p | **2.13%p** (1.16~4.13) | 3.70%p | **2.65%p** (1.77~4.10) |
| 학습 누출 / 통제 누출 | 3.49% / 0.06% | 2.22% / 0.09% | 3.71% / 0.01% | 2.79% / 0.15% |
| 특이 누출이 양수인 대입 | - | 20/20 | - | 20/20 |
| KC 입력 총량의 변동계수 | 0.82 | 0.65 | 0.84 | 0.68 |
| 한 KC가 반응하는 냄새 수 최대 (73개 중) | 73 | 73 | 72 | 73 |
| 입력 총량과 잡음 활성의 상관 | 0.59 | 0.45 | 0.60 | 0.49 |

부분 회로 값은 25와 정확히 같았다(재현 점검).

**판정: 견고하다(두 반구).** 전체 회로의 특이 누출은 부분 회로의 62%(오른쪽), 72%(왼쪽)이고(기준 50% 이상), 대입 20회 모두에서 양수였다(기준 16회 이상).

## 해석

- 부분 회로는 KC 입력의 불균등을 조금 키웠고(변동계수 0.82 -> 0.65), 그만큼 누출도 약 30~40% 컸다.
- 그러나 전체 회로에서도 거의 모든 냄새에 반응하는 허브 KC가 남아 있었다. 학습된 냄새의 가치는 여전히 잡음으로 새어 나왔다(잡음 "있다" 판단 중 학습 냄새의 의미를 띤 비율 2~3%, 무작위 통제는 0.1~0.2%).
- 따라서 "허브 KC가 학습된 가치를 잡음에 누출시킨다"는 25~26의 결론은 부분 회로의 인공물이 아니다.

## 한계

- 대입 채널은 실제 수용체 조율이 아니다. 실제 입력에서는 사구체들 사이의 상관 때문에 허브의 정도가 달라질 수 있다.
- 다중 사구체 PN(온도, 습도 등 냄새 외 감각 포함)에도 냄새 같은 가상 입력을 넣었다.
