# 관측된 냄새 입력의 부분 회로 실험

2026-10-08. 실제 감각 반응 자료를 근거로 한 첫 회로 실험이다. **관측된 20개 채널의 제한된 PN→KC 부분 회로**이며 전체 후각 회로 또는 실제 PN 생리의 재현은 아니다.

## 질문과 자료

임의 A/B 패턴 대신 냄새 반응 자료를 쓰면 실제 배선의 구분 능력이 대조 배선과 달라지는가? 학습에 앞서 입력 정보가 회로를 통과할 때 어떻게 달라지는지 확인했다.

[DoOR 연구](https://www.nature.com/articles/srep21841)와 [공식 자료 저장소](https://github.com/ropensci/DoOR.data)의 고정 커밋 db323a496577c4b4a72b5c2fcd1859e07521ffb5를 사용했다. DoOR는 여러 감각뉴런·수용체 반응을 정규화해 통합한 자료다. **값을 대응 PN의 상대 입력으로 직접 쓰는 것은 추가 전달 가정**이다. 물질의 분자 작용이나 PN 발화율을 직접 모사한 것은 아니다.

이전 감사에서 반응 관측이 가장 적은 채널부터 제외해 만든 20개 채널 부분집합을 사용했다. 값의 크기나 분류 결과를 보고 선택하지 않았다. 이 부분집합에서 모든 채널이 관측된 냄새 18개와 자발 활동 SFR을 확보했다. 18개 전체를 분류했으며 성능에 맞춰 냄새 쌍을 선택하지 않았다. 선택된 물질은 selected_odors.csv에 기록했다.

20개 채널은 기존 주석 기반 보수적 대응에서 PN 45개와 연결됐다. 전체 후보 PN 138개 중 이 45개의 PN→KC 연결 4,411개만 사용했다. 전체 KC 2,245개와 기존 APL 모델은 유지했다. 제외한 PN은 반응이 없다고 관측된 것이 아니다. 연결을 제외한 부분 회로를 분석한 것이다.

## 고정한 것과 바꾼 것

- KC 문턱 0.5888234575689715, PN 연결 가중치 스케일 34, APL 계수 4와 억제 강도 1을 기존 모형 그대로 유지했다. 원래 인공 입력에 맞춰 정한 문턱이므로 부분 회로와 생리학적으로 맞는다는 보장은 없다.
- 입력 전달을 absolute(통합 반응 그대로)와 positive_delta(max(반응−SFR,0))로 비교했다. 후자는 억제성 변화를 버린다. 전자는 낮은 반응값을 유지하지만 실제 발화 단위는 아니다.
- 입력 배율 1·2·4와 모의 Gaussian 잡음 표준편차 0.02·0.1을 비교했다. 원하는 성능에 맞춰 계수를 최적화하지 않았다.
- 잡음은 감각 채널마다 생성하고 [0,1]에 잘라낸 뒤 같은 채널에 대응하는 모든 PN에 동일하게 전달했다. PN마다 독립적인 정보를 새로 만든 것이 아니다. 생물학적 실측 변동도 아니다.
- 각 냄새에 모의 시행 30개를 만들어 첫 10개로 분류 중심을 정하고 나머지 20개로 평가했다. 18개 중심 중 Euclidean 거리가 가장 가까운 것을 선택했다. 동률은 임의로 첫 냄새를 고르지 않고 균등 선택 시 기대 정확도로 채점했다. 우연 수준은 1/18=5.56%다.
- 서로 다른 잡음 네 묶음으로 반복했다. 같은 잡음은 배선·입력 배율·전달 방식 비교에서 공유했다. 반복 모의 시행은 생물학적 개체나 독립 연구 자료가 아니다.

대조 배선은 관측 PN의 연결만 대상으로 동일 가중치 연결의 목적 KC를 교환했다. PN별 연결 수와 가중치, KC별 **관측 부분 회로의** 입력 연결 수와 가중치 합을 보존한다. APL 배선은 고정했다. 열 개의 제약된 대조를 만들었으며 균등 무작위 표본이라고 주장하지 않는다.

## 첫 관찰을 어떻게 수정했나

처음에는 대조 다섯 개와 잡음 한 묶음이었다. 통합 반응·낮은 잡음·배율 1에서 실제 96.67%, 대조 88.89~92.50%로 실제 배선이 앞섰다. 따라서 중간 보고에서 잠정 차이로 알리고 대조 열 개·잡음 네 묶음으로 확대했다. 새로 추가된 대조 중 일부가 실제보다 잘 구분했다. **처음과 같은 잡음 묶음에서도** 확대 대조의 최고 정확도가 실제보다 2.22%p 높았다. 네 반복 평균에서도 실제 96.53%는 대조 범위 88.40~99.03% 안에 있었다.

초기 positive_delta·큰 잡음·배율 2의 작은 우세도 확대 비교에서 유지되지 않았다. 따라서 초기 우세를 상세 배선의 특이적 기능으로 해석하지 않는다. 초기 실행 파일은 archived_initial_nulls5_repeat1/에 보존했다. 대조 수·모의 잡음에 따라 해석이 바뀔 수 있다는 직접적인 예다.

## 무엇을 생각할 수 있나

positive_delta·낮은 잡음·배율 1에서 활성 KC는 평균 0.659%, 완전 침묵 시행은 20.79%였고 정확도는 82.01%였다. 동일한 자료의 입력을 네 배로 하면 활성 KC 10.00%, 완전 침묵 0%, 정확도 100%였다. 입력 수준에는 이미 구분 정보가 있었으므로, 이 모형에서는 입력 크기와 문턱에 따른 침묵이 구분 손실의 한 요인임을 생각할 수 있다. 문턱만의 효과를 따로 분리한 실험은 아니며 APL 피드백과 포화도 함께 작용한다.

기준 활동만 넣은 무잡음 입력은 positive_delta에서 정의상 0이고 KC도 침묵했다. absolute 배율 4에서는 일부 KC(약 0.089%)가 활성화했다. 자발 활동에 대한 정상 모형 반응이며 환각이나 기억의 증거가 아니다. 무자극 여부를 판별하는 별도 분류 실험도 이번에는 하지 않았다.

관측 근거가 있는 냄새 입력에서도 **일관된 실제 배선의 분류 우수성은 확인하지 못했다.** 그러나 이로부터 실제 배선에 기능이 없다거나 실제 동물에서 무작위 배선이 더 좋다고 결론내릴 수 없다. 제한된 입력, OSN→PN 직접 전달, 임의 계수, 한 개체, 분류기의 정보 접근 범위 아래에서 얻은 결과다. 배율 2~4·낮은 잡음의 100%는 천장 효과라 세부 배선 차이를 가리기도 한다.

다음은 관측 냄새의 학습·출력 판독을 바로 확장하기보다, 특정 냄새의 무응답과 입력 전달 가정, 전체 회로 문턱을 부분 회로에 가져온 영향을 분리할 필요가 있다. KC 전체에 접근하는 분류기가 잘 구분하는 것과 특정 MBON이 해당 정보를 읽는 것은 다른 질문이다.

무응답 동률의 우연 수준, 알려진 다중 클래스 구분, 기준 활동 차감의 억제 정보 손실을 포함해 전체 테스트 25개를 통과했다. 대조 함수는 목적 KC별 연결 수·입력 가중치 합 보존을 실행 중 확인한다. 생물학적 타당성을 검증하는 테스트는 아니다.
