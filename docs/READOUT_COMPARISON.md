# 출력 크기와 학습 변화를 분리하는 판독 비교

2026-10-08. 사용자의 요청에 따라 무엇을 진행했고, 어떤 결과 때문에 어디까지 해석할 수 있는지를 차례대로 정리한다. [이전 무자극 검증](SIGNAL_PRESENCE.md)에서 드러난 입력 세기 의존성을 조사한 단계다.

## 1. 왜 이 실험을 했나

이전 모델은 A를 학습하면서 활성 KC→MBON 연결을 약화시켰다. 그래서 낮은 MBON 출력을 A로 판독했다. 하지만 낮은 출력은 A를 배웠다는 이유뿐 아니라 입력이 약하다는 이유로도 생길 수 있다. 같은 출력에 다른 원인이 섞이는 문제다.

이번 질문은 ‘출력의 절대 크기를 참조하는 대신 현재 활동이나 학습 전 출력을 함께 참조하면 이 혼동이 줄어드는가?’였다. 이것은 판독법 비교이며, 실제 초파리가 이 계산을 수행하는지 시험한 것은 아니다.

## 2. 무엇을 같게 두고 무엇을 바꿨나

PN/KC/APL 회로, 주 MBON11, A의 학습 규칙, theta, eta=20을 그대로 뒀다. 같은 입력에서 발생한 같은 KC 활동을 세 방식으로 읽었다. 방법별 문턱은 세기 1의 원래 학습 입력에서만 정하고 평가 때 고정했다.

| 방법 | 판독 점수: 클수록 A | 필요한 정보 |
|---|---|---|
| 절대 출력 raw | −학습 후 MBON 출력 | 현재 주 MBON 출력 |
| 현재 활동 정규화 | −학습 후 출력 / 현재 평균 KC 활동 | 현재 MBON + 전체 KC 평균 |
| 학습 전후 비율 | (학습 전 출력 − 학습 후 출력) / 학습 전 출력 | 현재 입력의 학습 전후 가상 출력 |

마지막 방법은 **특권적인 참조 정보**를 쓴다. 실험자가 학습 전 가중치를 보관하고 동일한 현재 입력으로 가상 출력을 계산해야 한다. 실제 뇌가 과거 가중치를 읽거나 같은 계산을 한다는 주장이 아니다. 현재 활동 정규화도 단일 MBON보다 추가 정보를 쓴다. 방법 간 정보량이 다른 비교다.

비율의 직관은 단순하다. 학습 전후 출력이 10→6이라면 감소율 40%다. 전체 활동이 균일하게 줄어 5→3이면 역시 40%다. 절대 출력 6과 3은 달라도 변화율은 같다. 이 성질은 수학적으로 기대되는 성질이다. 다만 실제 모델의 입력 세기를 바꾸면 문턱·잡음 때문에 KC들이 균일하게 줄어들지는 않으므로, 이러한 정규화가 반드시 작동하는지는 따로 시험해야 한다.

분모가 10^-12 이하이면 점수를 0으로 정했다. 그 선택 역시 모형의 가정이다. 정확한 무입력에서 비율 점수가 0이 되는 것을 생물학적 현상으로 해석하지 않는다.

## 3. 대조군과 평가

- 학습 신호 있음/없음, 평가 APL 정상/제거, 잡음 0.1/0.4, 세기 0/0.1/0.25/0.5/1을 비교했다.
- 학습은 패턴별 40회, 새 평가 잡음은 패턴별 100회다. 입력의 겹침은 약 89.3%다.
- 09와 같은 독립 잡음 기준으로 입력 존재를 확인하는 판정도 함께 기록했다.
- 실제 배선과 KC→MBON 출력 대조군 10개를 비교했다. 연결 수와 PN이 아닌 **KC의 출력 가중치 집합·합, MBON의 입력 가중치 합**을 보존하는 대조다. PN/KC/APL 연결은 그대로다.
- 거절한 실제 입력을 자동으로 B 정답으로 세지 않았다. 입력이 존재한다고 판정한 경우에만 A/B가 맞으면 정답이다. 세기 0은 잡음만 있는 조건이므로 A/B 정확도와 AUC를 부여하지 않았다.

먼저 기존 패턴·평가 잡음으로 방법을 비교했다. 방법은 이전 결과를 보고 설계했기 때문에 이것만으로는 새로운 입력에도 유지되는지 알 수 없다. 그래서 방법과 계수를 고정한 뒤, **새 패턴 8쌍과 새 평가 잡음**으로 다시 검증했다. 새 패턴도 학습 입력으로만 문턱을 적합하고 평가 입력은 사용하지 않았다. 원래 실행과 새 검증은 별도 디렉터리에 저장했다.

각 실행의 21,120행은 회로·입력·설정·판독·패턴 묶음의 조합이며 독립적인 생물학적 표본 수가 아니다. 정상 입력에서의 A/B 정확도는 같은 조건의 두 패턴 행에 중복 기록돼 있으므로 이를 두 독립 관측처럼 합치지 않는다.

## 4. 실제 결과: 새 입력에서도 무엇이 남았나

큰 잡음·정상 평가 APL·세기 1에서:

| 판독 | 기존 입력 정확도 | 새 패턴 검증 정확도 | 새 패턴 검증 AUC_A |
|---|---:|---:|---:|
| 절대 출력 | 60.25% | 64.19% | 0.697 |
| 현재 활동 정규화 | 64.31% | 71.06% | 0.786 |
| 학습 전후 비율 | 64.56% | 72.00% | 0.794 |

새 패턴 검증에서도 두 참조 정보를 쓰는 방법의 평균 정확도가 높았다. 학습 전후 비율은 8쌍 중 7쌍에서 절대 출력보다 높고 1쌍은 같았다. 따라서 기존 입력에만 맞춘 결과라는 설명만으로 이번 관찰을 설명하기는 어렵다. 다만 8쌍뿐인 같은 합성 입력 분포의 검증이며, 실제 냄새나 생물학적 개체로 일반화한 결과는 아니다.

학습 신호가 없으면 새 패턴에서 정확도는 절대 출력 49.75%, 현재 활동 정규화 52.75%, 학습 전후 비율 50.00%였다. 마지막 방법은 학습이 없으면 분자가 정확히 0이라 AUC도 정확히 0.5다. 이 비교는 변화가 학습된 가중치에 의존한다는 점검이다. 가소성을 가정했으므로 가소성의 존재를 발견한 것은 아니다.

## 5. 실제 상세 배선이 특별하다는 근거인가

기존 입력의 학습 전후 비율은 실제 회로 64.56%, 대조군별 평균 62.00~64.38%였다. 차이가 아주 작아 최초 3개 대조군을 10개로 확대했고, 새 입력에서도 확인했다.

새 입력에서는 실제 회로 72.00%가 대조군 69.00~72.88% 범위 안이었다. 현재 활동 정규화도 실제 71.06%, 대조군 69.94~72.63%였다. **새 입력에서 실제 상세 배선의 일관된 우수성을 확인하지 못했다.**

따라서 현재 생각할 수 있는 것은 ‘이 합성 모델에서는 학습한 연결의 효과를 어떤 참조와 함께 읽느냐가 성능에 영향을 준다’는 정도다. ‘실제 커넥톰의 특정 배선이 특별한 기억 기능을 만든다’는 주장으로 넘어갈 근거는 부족하다. 대조군 범위는 신뢰구간이 아니며, 10개의 제약된 무작위 회로가 모든 가능한 배선을 대표하지도 않는다. KC 세부 유형별 MBON 입력 구성은 보존하지 않는 대조라는 한계도 있다.

## 6. 어디에서 실패했나

새 입력·큰 잡음에서 10% 세기의 A/B AUC는 세 방법 모두 약 0.49~0.50이었다. **문턱을 잘 고르는 것만으로 해결되는 문제가 아니라, 이번 점수에서 입력 종류를 구분할 정보가 거의 없는 조건**이었다. 원래 KC 전체에 정보가 없다는 뜻은 아니다.

절반 세기에서 입력 존재 기준까지 적용한 결과는 다음과 같다.

| 지표 | 절대 출력 | 현재 활동 정규화 | 학습 전후 비율 |
|---|---:|---:|---:|
| A를 A로 읽음 | 81.25% | 21.13% | 24.00% |
| B를 A로 잘못 읽음 | 76.13% | 11.88% | 14.13% |
| 거절을 오답으로 센 전체 식별 정확도 | 51.19% | 53.25% | 53.56% |

비율로 읽으면 B의 A 오판이 줄지만 A 자체도 많이 놓쳤다. 전체 정확도는 소폭 개선에 그쳤다. B 오판 감소만 보여주면 개선을 과장하게 된다. 정상 세기에서도 신호 판정과 학습 판독을 합친 A/B 정답률을 함께 보고해야 한다.

잡음만 있는 새 입력에서 A 판정은 기존 절대 출력+존재 기준 약 3.88%, 두 정규화 방법+존재 기준은 이 표본에서 0%였다. 그러나 낮은 잡음의 잡음 전용 입력에서는 현재 활동 정규화도 A 오판이 남았다. 관측된 0%를 모든 잡음에서 완전한 예방으로 해석하지 않는다. 학습 전후 비율의 무입력 점수는 정의상 0이라는 점도 함께 봐야 한다.

## 7. 지금 가능한 해석과 다음 질문

모형에는 실제 연결뿐 아니라 가소성 규칙, 감각 입력, 문턱, 외부 판독이 함께 들어 있다. 실제 배선과 제약된 무작위 배선 모두에서 정규화의 성능 변화가 나왔으므로, 회로의 상세 배선보다 학습과 판독의 일반 구조가 중요한 몫을 할 가능성을 생각할 수 있다. 이것은 모든 커넥톰 세부가 불필요하다는 결론은 아니다.

다음에는 (1) 입력 강도가 다양한 학습 자료로 문턱만 보정할 때와 AUC 자체가 달라지는 경우를 구분하고, (2) KC 세부 유형의 MBON 입력 구성까지 보존한 대조로 배선 효과를 좁히고, (3) 특권적인 학습 전 참조 없이 현재 회로에서 얻을 수 있는 신호로 읽는 비교를 검토하는 것이 타당하다.

조현병·환각·실제 기억 오류를 검증한 단계는 아니다. 원리가 단순히 모형에 넣은 가정의 결과인 부분과, 그 가정 아래 실제 데이터로 비교해 새롭게 확인한 부분을 분리해 설명해야 한다.

## 재현과 기록

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
  .venv/bin/python pipelines/10_readout_comparison.py --pairs 8 --nulls 10 --trials 100
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
  .venv/bin/python pipelines/10_readout_comparison.py --pairs 8 --nulls 10 --trials 100 --validation
.venv/bin/python -m unittest discover -s tests -v
```

원자료와 08 manifest가 필요하며 SHA-256을 확인한다. 기존 비교는 qc_reports/readout_comparison/, 새 패턴 검증은 qc_reports/readout_comparison_validation/ 아래의 metrics.csv, summary.csv, manifest.json, readout_comparison.png다. 초기 대조군 3개 결과도 archived_nulls3/에 보존했다. 전체 테스트 17개가 통과했고 정상 상태 잔차는 약 4.5×10^-12 이하였다. 수치 정확성과 생물학적 타당성은 별개다.
