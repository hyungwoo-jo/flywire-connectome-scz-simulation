# 자발 활동 기준 항상성 (56)

2026-10-14. [사전 등록](PREREGISTRATION_56.md)에 따라 실행했다. 사후 점검은 `pipelines/56x_matched_noise.py`.

## 질문

55에서 냄새 반응을 맞추는 항상성은 BANC의 냄새 특이 누출을 0.8~1.0% 남겼다. 54의 결론대로 KC마다 자기 자발 입력 분포(평균 mu_i, 흔들림 sigma_i)를 기준으로 문턱을 정하면 남은 누출이 사라지는지 봤다.

```
theta_i = (1 - lambda) * theta_0 + lambda * (mu_i + z * sigma_i)
```

z는 냄새 활성 KC가 10%가 되도록 정했다.

## 사후 점검: 잡음 활동이 줄어서일 뿐인가 (판정에 쓰지 않음)

lambda 1에서는 잡음 시행에 켜지는 KC가 0.3~0.5%에서 0.004~0.025%로 크게 줄었다. 단순히 잡음 활동이 줄어서 누출이 사라졌을 수 있으므로, 원래 회로의 공통 문턱을 올려 잡음 활성을 같은 수준에 맞췄다.

| 반구 | 냄새 활성 KC | 냄새 특이 누출 | H |
|---|---:|---:|---:|
| BANC 오른쪽 | 3.0% | 1.68% | 57.6 |
| BANC 왼쪽 | 3.0% | 1.91% | 26.0 |
| FlyWire 오른쪽 | 2.9% | 1.84% | 17.7 |
| FlyWire 왼쪽 | 2.5% | 1.77% | 11.6 |
| hemibrain 오른쪽 | 1.2% | 1.76% | 36.3 |

공통 문턱을 올리면 냄새 반응이 1~3%로 줄고, 누출은 그대로이며 H는 오히려 커진다(잡음에 켜지는 소수가 더 극단적인 허브가 된다). 따라서 lambda 1의 효과는 잡음 활동의 양이 아니라 **어떤 KC가 잡음에 켜지는가**에서 온다.

## 해석

1. **54의 예측이 맞았다.** 각 KC가 자기 자발 입력 분포를 기준으로 문턱을 정하면, BANC를 포함한 다섯 반구 모두에서 냄새 특이 누출이 사라진다. 효과는 lambda에 비례하는 용량 반응이었다.
2. **잡음 활성 확률이 같아져서가 아니다.** lambda 1에서 KC별 잡음 활성 확률의 변동계수는 오히려 커졌다(원래 3.3~3.9, lambda 1에서 3.5~6.3). 입력 분포의 꼬리가 정규분포가 아니기 때문이다. 결정적인 것은 잡음에 켜지는 KC와 냄새에 잘 켜지는 KC의 겹침(H 식의 공분산)이 끊긴 것이다.
3. **대가가 있다.** 완전한 자발 기준 문턱은 기억 정확도를 떨어뜨린다(20개 냄새에서 -3~-8%p). 자발 흔들림이 작은 KC가 문턱이 낮아져 여러 냄새에 넓게 반응하면서 표상이 덜 구분되는 것으로 보인다(확인하지 않음). lambda 0.5에서는 기억 비용 없이 누출이 36~55% 줄었다.
4. **두 항상성은 서로 다른 것을 지킨다.**
   - 냄새 반응 기준 항상성(55): 기억을 높이지만 입력 불균일이 큰 회로(BANC)에서 누출을 남긴다.
   - 자발 활동 기준 항상성(56): 누출을 없애지만 기억을 깎는다.
   - 실제 KC는 냄새와 자발 활동을 구분하지 않고 자기 전체 활동을 보고 조정할 것이다. 둘을 섞은 형태가 생물학적으로 더 자연스럽고, 두 목표를 함께 만족하는 지점이 있는지는 다음 질문이다.
