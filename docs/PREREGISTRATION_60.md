# 사전 등록: 60 단계 (도파민 뉴런 배선으로 학습 위치 정하기)

2026-10-14. **누출 결과를 계산하기 전에 작성했다.** PPL101→KC 시냅스 수와 KC 아형만 먼저 뽑았다.

## 배경

지금까지 학습은 냄새에 반응한 모든 KC의 KC→MBON11 시냅스를 반응 크기만큼 약하게 만들었다(d = 1 - exp(-5k)). 실제로는 도파민 뉴런(DAN)이 들어오는 곳에서 가소성이 생긴다. MBON11 구획(γ1pedc)의 DAN은 PPL101(PPL1-γ1pedc)이다.

코딩애플 영상(「초파리에게 운전 가르치기」, 2026-09-30)은 "잘하면 도파민을 주고, 도파민이 들어오면 시냅스를 바꾸는" 방식으로 커넥톰을 학습시켰다. 여기서는 그 발상을 커넥톰 안의 실제 DAN 배선으로 바꾼다. 이렇게 학습 위치를 정해도 누출이 남는지 본다.

## 방법

**도파민 관문:** KC i가 같은 쪽 PPL101에서 받는 시냅스 수를 g_i로 둔다. 그 쪽 KC에 시냅스를 가장 많이 주는 PPL101 하나를 쓴다. 학습은 다음과 같다.

```
d_i = 1 - exp(-5 * k_i * gamma_i),  gamma_i = g_i / E_w[g]
```

E_w는 MBON11 가중치로 가중한 평균이다. 그래서 MBON11이 읽는 KC 전체의 평균 학습 세기는 원래와 같다. g_i = 0인 KC는 배우지 않는다. 같은 관문을 무작위 통제 학습에도 적용한다.

**조건:**

- 균일: 원래 규칙.
- DAN: 위의 관문.
- 아형 내 섞기: g를 같은 KC 아형(γ, αβ, α'β', 기타) 안에서 무작위로 섞은 관문. 아형별 DAN 분포는 지키고 KC 단위 배선만 지운다.

**시드:** 세 조건 모두 잡음 시행 시드 5개(59의 시드 0~4)로 반복하고, 평균을 쓴다. 섞기는 시드마다 다른 순열을 쓴다.

**대상:** 일곱 반구. PPL101→KC 시냅스가 잡힌 KC 수는 다음과 같다.

| 반구 | 관문 있는 KC | 시냅스 |
|---|---:|---:|
| hemibrain 오른쪽 | 1,304 | 3,659 |
| MaleCNS 오른쪽 | 1,330 | 3,535 |
| MaleCNS 왼쪽 | 1,272 | 2,775 |
| FlyWire 오른쪽 | 602 | 696 |
| FlyWire 왼쪽 | 887 | 1,202 |
| BANC 오른쪽 | 97 | 106 |
| BANC 왼쪽 | 53 | 55 |

BANC는 DAN→KC 시냅스가 다른 데이터셋보다 열 배 이상 적게 잡혀 있어 재구성 차이로 보인다. 그래서 **판정은 BANC를 뺀 다섯 반구로 하고**, BANC 결과는 보고만 한다.

**함께 보고:** 관문 있는 H, MBON11이 읽는 KC에서 g와 평균 자발 입력의 Spearman 상관(전체, 아형 내).

## 판정 (실행 전 고정, BANC 제외 다섯 반구)

- **P1 (누출 유지):** DAN 관문에서 냄새 특이 누출(5회 평균)이 0.5% 이상인 반구가 5개 모두이면 지지.
- **P2 (규칙에 둔감):** DAN과 균일의 누출 차이 절대값이 1.0%p 미만인 반구가 4개 이상이면 지지.
- **P3 (KC 단위 DAN 배선은 무관):** DAN과 아형 내 섞기의 누출 차이 절대값이 0.5%p 미만인 반구가 4개 이상이면 지지.

## 해석 규칙

- P1이 지지되면 누출은 학습 규칙의 세부(어디서 가소성이 생기는가)에 기대지 않는다.
- P3가 기각되면 DAN→KC 배선 안에 PN 입력과 맞물린 구조가 있다는 뜻이다. 상관 방향으로 누출을 키우는지 줄이는지 본다.

## 한계

- DAN→KC 시냅스 수를 가소성의 위치로 보는 것은 가정이다. 도파민이 구획 전체로 퍼진다면 균일 규칙이 더 맞다.
- PPL101 하나만 본다. MBON11 구획 밖의 학습은 다루지 않는다.
- 기억 과제는 다루지 않는다(관문이 MBON11 구획에만 정의된다).
