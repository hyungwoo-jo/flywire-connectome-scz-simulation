# 실제 배선 안의 보상 (32)

2026-10-09. [사전 등록](PREREGISTRATION_32.md)에 따라 실행했다.

## 질문

27, 29에서는 KC 사이의 보상을 모형에 인위로 넣었다. 실제 BANC 배선에 이미 보상이 들어 있는가? PN 연결이 많은 KC일수록 연결당 시냅스가 적다면 배선 수준의 보상이다.

## 결과

| | 오른쪽 | 왼쪽 |
|---|---:|---:|
| KC 수 / PN->KC 연결 수 | 2,069 / 10,620 | 2,088 / 10,805 |
| 기울기 b (log 연결당 시냅스 ~ log 연결 수) | **+0.22** | **+0.18** |
| 순열 영분포 평균 (연결 수는 고정, 시냅스 수 재배정) | +0.15 | +0.16 |
| 단측 p (b가 영분포보다 작은가) | 1.00 | 0.81 |
| 총입력 ~ 연결 수의 지수 | 1.22 | 1.18 |
| KC 입력 총량의 변동계수 | 0.65 | 0.68 |

(순열 영분포가 0이 아니라 양수인 것은, 연결 수가 많을수록 평균의 로그가 덜 작아지는 수학적 성질 때문이다.)

**판정: 확립되지 않음.** BANC에서는 연결이 많은 KC가 연결당 시냅스도 같거나 약간 많았다. 배선 수준의 보상은 보이지 않고, 오히려 입력이 많은 KC가 더 많아지는 방향이다.

## 사후 점검 (판정에 쓰지 않음)

**1. 시냅스 하한.** BANC 연결 목록에는 시냅스 1개짜리 연결도 있다(PN->KC 연결의 약 18%). 하한을 1, 2, 3, 5로 바꿔도 상관은 r = 0.17~0.24로 모두 양수였다(`posthoc_threshold_sensitivity.csv`).

**2. PN 주석 범위.** 06 이후 PN을 "검증된 아세틸콜린" 투사뉴런(오른쪽 138개)으로 제한했다. 확인해 보니 이들이 PN->KC 시냅스의 97%를 차지했다. 나머지 PN을 포함해도 KC 입력 총량의 순위는 거의 같았다(Spearman 0.99). 허브 구조는 PN 주석 범위의 산물이 아니다.

**3. 재구성 완성도.** KC 입력 총량과 KC 케이블 길이의 상관은 약했다(0.17, 0.04). 잘 재구성된 KC가 입력도 많다는 교란은 크지 않아 보인다.

**4. 문헌과의 불일치.** [Abdelrahman, Vasilaki, Lin 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8670477/)은 hemibrain 커넥톰에서 "KC당 PN 입력 수가 연결당 평균 시냅스 수와 반비례한다"고 보고했다. 또 입력이 많을수록 입력 시냅스가 스파이크 시작 부위에서 멀고, PN 시냅스가 많을수록 APL 시냅스도 많다고 보고했다. BANC에서는 첫 번째 관계가 반대로 나왔다. 원인은 이번 분석으로 알 수 없다. 데이터셋 차이(시냅스 검출, 교정 방식), 정의 차이(클로 수 대 PN 파트너 수)가 후보다. 참고로 BANC의 KC당 PN 파트너 수(시냅스 3개 이상)는 평균 3.6~3.8개로, 문헌에서 흔히 말하는 클로 수(약 6~7개)보다 적다.

## 25~31에 대한 함의

- 25~31의 모형은 배선 수준의 보상이 없는 BANC 배선을 그대로 썼다. 따라서 허브 KC와 학습된 가치의 누출은 **보상이 배선에 반영되지 않은 회로**의 성질이다.
- 실제 초파리에는 배선 밖의 보상(시냅스 위치, 흥분성, KC별 APL 억제)이 있다고 보고된다. 그 보상이 충분하다면 실제 누출은 모형보다 작을 것이다(26, 29: 보상이 강할수록 누출 감소).
- 그래서 이 연구의 예측은 다음과 같다. **KC 사이의 보상이 약해지면 학습된 의미가 잡음으로 새어 나오는 거짓 지각이 늘어난다.** 보상의 실제 크기는 커넥톰만으로는 정할 수 없고, KC 생리 측정이 필요하다.
