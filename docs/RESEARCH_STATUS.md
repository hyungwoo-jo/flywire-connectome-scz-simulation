# 연구 현황과 방향

2026-10-09 기준 (20 반영). 단계별 세부는 각 문서를 본다.

## 큰 질문

초파리 연결망(BANC 커넥톰) 위에서 회로가 어떤 기능을 만드는지, 그리고 그 기능이 어떻게 틀어지는지(기억 오류, 환각에 가까운 현상)를 단순 모형으로 탐구한다.

질문은 아래 사다리를 한 칸씩 오르는 방식으로 진행한다. 아래 칸이 검증되지 않으면 위 칸의 해석은 하지 않는다.

```
6. 물질(약물) 작용                     표적, 수용체 자료 필요        미착수
5. 기억 오류, 오탐 (원래 관심사)        신호 유무 판독 과제          미착수 (보정 모형 준비됨)
4. 학습 (KC->MBON 가소성)              08~12에서 시도               실제 배선 특이성 없음
3. 그 기능에 필요한 배선 구조           17~20                       현재 위치 (마무리 단계)
2. 입력 구분 기능 (보정된 모형)         16                          완료
1. 배선, 세포 종류, 데이터 ID 확인       05, 06, 13                  완료
```

## 지금 알게 된 것

1. **배선은 무작위가 아니다.** 특정 PN 유형 쌍은 같은 KC로 몰리고(과수렴), 어떤 쌍은 서로 피한다(분리). 과일, 에스테르에 반응하는 사구체 묶음이 그 예이고, 그 출력은 KCab에 치우친다. FAFB 연구(Zheng 2022)와 같은 방향이다.
2. **그 구조는 일반적인 냄새 구분에는 약간 손해다.** 무작위에 가까운 배선이 범용 구분에 가장 유리하다는 이론과 맞는다.
3. **손해의 원인은 구조 자체다.** KC 하위 유형 배분 때문이 아니고(19), 비슷하게 반응하는 수용체끼리 모여 정보가 겹치기 때문도 아니다(20). 수용체 입력을 아무렇게나 바꿔 넣어도 손해가 남는다.
4. 따라서 이 구조가 **무엇을 위한 것인지는 "구분" 바깥에서 찾아야 한다.** 남은 후보는 (a) 발생과 공간 배치의 부산물, (c) 학습이나 행동 출력에서의 이득이다. (b) 특정 냄새 계열 특화는 18의 탐색 검정과 20에서 지지되지 않았다.

## 다음 단계 (우선순위 순)

1. **학습 단계에서의 이득 (c) 검정.** 같은 보정 모형에 KC->MBON 학습을 붙인다. 실제 배선이 "학습한 냄새와 비슷한 냄새로의 일반화"나 "냄새 계열 단위 학습"에서 무작위보다 나은지 본다. 구분에서 손해인 구조가 일반화에서는 이득일 수 있다는 가설이다. 사전 등록 후 실행한다.
2. **원래 관심사로 복귀.** 보정된 모형에서 신호 유무 판독(검출, 누락, 오탐)을 만들고, APL 약화와 학습된 기대(Powers 과제의 조건화 환각 구조)가 오탐을 어떻게 바꾸는지 본다. 1의 학습 모형이 그대로 토대가 된다.
3. (a) 부산물 가설은 시냅스 좌표가 있어야 검정할 수 있어 보류한다.

## 진행 원칙

- 새 실험은 가설, 지표, 판정 규칙을 먼저 문서로 고정한 뒤 실행한다.
- 대조 배선은 100개 이상을 쓰고 백분위로 보고한다.
- 모형의 수학적 성질과 생물학적 발견을 구분해 쓴다.
- 질환, 행동, 의식에 대한 해석은 해당 칸에 도달하기 전까지 하지 않는다.
