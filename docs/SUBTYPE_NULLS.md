# KC 유형 구성까지 보존한 배선 대조

2026-10-08. ‘실제 배선만의 역할’을 더 좁혀 묻기 위해, 입력 강도뿐 아니라 KC 세부 유형 구성까지 보존하는 대조군을 추가했다.

## 왜 기존 대조로 부족했나

기존 KC→MBON 대조는 각 뉴런의 연결 수와 가중치를 보존했지만, 주 MBON이 받는 KC 유형의 구성은 바뀔 수 있었다. 실제와 대조가 달라도 상세한 연결 상대 때문인지 유형 구성 때문인지 구분하기 어려웠다.

실제 주 MBON11의 입력 2,775개 시냅스에서 KCg가 2,200개(약 79.3%), KCab가 558개였다. 이 구성을 유지하면서 상세 연결 상대를 바꿔 비교했다.

| KC 주석 유형 | 주 MBON 입력 KC 수 | 시냅스 수 |
|---|---:|---:|
| KCg | 665 | 2,200 |
| KCab | 348 | 558 |
| KCa'b' | 8 | 8 |
| KCapbp | 1 | 2 |
| KC | 5 | 7 |

이는 cell_sub_class 주석이며 빈 주석은 cell_type으로 대체했다. KC라는 넓은 주석까지 생리학적으로 상세히 확인한 것은 아니다. 위치별 접촉과 수용체, 실제 DAN 구획은 통제하지 않았다.

## 무엇을 보존했나

같은 시냅스 수의 연결끼리, presynaptic KC 유형도 같은 경우에만 연결 대상을 교환했다. 따라서 다음을 보존했다.

- KC별 출력 연결 수와 출력 가중치 집합·합.
- MBON별 입력 연결 수와 입력 가중치 합.
- 각 MBON의 KC 유형별 입력 연결 수와 입력 가중치 합.
- 따라서 유형 사이의 전체 연결 수·가중치 구성.

각 유형에서 해당 연결 수의 5배만큼 성공적인 교환을 시행했다. 교환할 수 없는 유형은 그대로 두고 기록하도록 했다. 이번 실제 자료에서는 다섯 유형 모두 교환을 수행했다. 새로운 중복 연결을 허용하지 않았다.

새 대조군 10개에서 연결 상대가 달라진 비율은 약 84.7~85.5%, 전체 가중치 중 상대가 달라진 몫은 약 75.2~76.5%였다. 기존 제약보다 더 많은 구조를 보존하므로 일부 강한 연결은 남는다. 모든 가능한 그래프의 균일한 무작위 표본이나 상세 배선 전체를 완전히 제거한 것으로 해석하지 않는다.

## 평가를 어떻게 같게 뒀나

실제 배선, 기존 입력 강도 보존 대조군 10개, 새 유형·강도 보존 대조군 10개를 같은 입력에 적용했다. 10단계 새 입력 검증에서 사용한 8쌍, 큰 잡음, 정상 세기, 정상 APL, eta=20과 같은 판독을 사용했다. 유형 대조의 정의만 달라지는지 보려는 비교이므로 새로운 입력 시드는 추가하지 않았다.

학습 신호 없음/있음과 세 판독법을 평가했다. 문턱은 원래 학습 입력에서만 정하고 평가 때 고정했다. 같은 실제 회로의 결과는 이전 10단계와 정확히 일치했다. 비교 기준이 계산 변경으로 흔들리지 않았음을 확인했다.

이번 집중 대조에는 PN 입력 존재 기준을 적용하지 않았다. 정상 세기에서의 판독 비교이며, 약한 입력·무자극까지 확장한 결과는 아니다.

세 판독법 모두 실제 배선이 새 대조군 범위 안에 있었다. 학습 전후 비율의 AUC도 실제 0.794, 새 대조군 0.796~0.817이었다. 이 조건에서는 실제 상세 배선의 특별한 우수성을 확인하지 못했다. 이것만으로 실제 배선이 생물학적으로 더 나쁘다고 결론 내리지도 않는다.

## 어디까지 생각할 수 있나

임의의 감각 패턴에 가정한 가소성을 적용하고 외부 판독을 사용하면, 실제 상세 배선을 바꿔도 유사한 기능이 나왔다. 현재 모델의 성공은 넓은 회로 구조·학습 규칙·판독에 의존하는 부분이 클 수 있다. KC 유형 구성까지 맞춘 이번 대조에서도 그 판단이 유지됐다.

이것은 연결 자료가 무의미하다는 뜻이 아니다. 실제 감각 입력의 구조나 행동 목적을 반영하지 않은 과제에서, 실제 배선의 장점이 드러나지 않을 수 있다. 그런 가능성을 생각할 수 있지만 이번 데이터만으로 그 이유를 특정한 것은 아니다.

다음에는 출력 문턱을 더 복잡하게 만드는 것만 반복하기보다, 생물학적으로 근거 있는 입력·구체적인 과제·모델 가정의 근거를 확인할 필요가 있다. 판독이 이용하는 정보와 실제 동물에서 이용 가능한 신호의 차이도 계속 명시해야 한다.

## 한계와 재현

하나의 개체, 주 MBON11 하나, 인공 입력 8쌍, 하나의 가소성 규칙, 유형 안의 제한된 배선 혼합, 일부 강한 연결 보존의 한계가 있다. 현재 실제 결과를 본 뒤 대조를 설계했으므로 탐색 분석이다. 질환·환각·실제 기억의 행동 증거로 해석하지 않는다.

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 \
  .venv/bin/python pipelines/12_subtype_nulls.py --pairs 8 --nulls 10
.venv/bin/python -m unittest discover -s tests -v
```

원자료 SHA-256을 확인한다. 결과는 qc_reports/subtype_nulls/의 metrics.csv(1,008행), graph_means.csv, main_input_composition.csv, manifest.json, subtype_nulls.png다. 유형별 입력 차수·가중치 보존과 교환 불가 유형의 명시적 보존을 검증했다. 전체 테스트 22개가 통과했고 실제 회로의 이전 결과와 정확한 일치도 확인했다. 수치 잔차는 약 4.8×10^-12 이하였다.
