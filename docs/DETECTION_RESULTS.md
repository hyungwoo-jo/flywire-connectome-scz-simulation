# 신호 검출과 오탐, APL 약화 (23)

2026-10-09. [사전 등록](PREREGISTRATION_23.md)에 따라 실행했다. 원래 관심사(억제가 약해지면 없는 냄새를 있다고 판단하는가)로 돌아온 첫 단계다. 두 반구를 처음부터 함께 썼다.

## 과제

- 출력 뉴런 하나가 KC 활동의 합을 읽고, 그 값이 기준을 넘으면 "냄새 있음"으로 판단한다.
- 기준은 정상 APL에서 잡음만 있는 시행 1,000개의 95백분위로 정하고 고정했다.
- 잡음 시행은 냄새 없이 감각뉴런 자발 활동의 Poisson 잡음만 있다. 신호 시행은 평가용 냄새 73개를 약한 농도(Hallem 변화량 x 0.1)로 준다.
- APL 강도는 1, 0.5, 0으로 바꿨다.

## 결과 (주 조건: 농도 0.1, 0.5 s 창)

| | 오른쪽 | 왼쪽 |
|---|---|---|
| 오탐률 FA (APL 1 -> 0.5 -> 0) | 7.1% -> 7.5% -> 8.0% | 5.6% -> 6.0% -> 6.5% |
| 적중률 H (APL 1 -> 0.5) | 73.6% -> 74.7% | 68.1% -> 68.5% |
| 민감도 AUC (APL 1 -> 0.5) | 0.9181 -> 0.9182 | 0.9032 -> 0.9032 |
| ΔAUC (95% 부트스트랩 구간) | +0.0001 (0.00001, 0.0002) | +0.00004 (-0.00004, 0.0001) |
| 배선 특이성 z (대조 100개 대비) | -0.52 | 0.01 |

(정상 APL의 오탐률이 5%가 아닌 것은, 기준을 별도 보정 시행에서 정했고 KC 합이 0인 시행이 많아 값이 이산적이기 때문이다.)

보조 조건도 같았다. 농도 0.05와 0.2에서 AUC는 APL 강도와 무관하게 소수점 셋째 자리까지 같았다. 잡음이 큰 0.25 s 창에서는 오탐 증가가 조금 더 컸지만(오른쪽 5.3% -> 7.5%, 왼쪽 4.0% -> 6.2%, APL 1 -> 0), AUC는 역시 그대로였다(차이 0.0006 이하).

**판정**
- H23a (조작 점검): 두 반구 모두 오탐 증가. **다만 크기가 0.4~0.9%p로 매우 작다.**
- H23b (주 가설): 두 반구 모두 |ΔAUC| < 0.02. **민감도는 그대로이고, 작은 오탐 증가는 편향 이동이다.**
- H23c: 배선 특이성 없음.

## 해석

이 모형에서 APL은 KC 전체 활동에 비례해 억제를 건다. 냄새가 없거나 약할 때는 KC가 거의 켜지지 않으므로(잡음 시행 평균 활성 0.4%) APL 피드백도 거의 0이다. 그래서 APL을 약하게 해도 문턱 근처의 판단은 거의 바뀌지 않는다. APL은 강한 냄새에서 KC가 너무 많이 켜지는 것을 막는 장치로 작동하고(16: APL 제거 시 9.4%에서 14.0%), 약한 신호의 검출에는 거의 관여하지 않는다.

이는 15의 관찰과도 이어진다. 문턱 근처의 오탐과 누락은 **KC의 흥분성(문턱)** 이 좌우했다. 따라서 "억제 약화 -> 오탐(환각 비슷한 현상)"이라는 처음의 직관은, 적어도 이 회로와 이 모형에서는 지지되지 않는다. 01~04에서 본 극적인 효과가 계산 방식의 착시였다는 05의 결론과도 맞다.

실제 생물에서는 APL이 국소적으로 작동하고(구획별), 자발 활동이나 시간 동역학이 있으므로 이 결론을 그대로 옮길 수는 없다.

## 다음 질문

오탐을 좌우하는 것이 흥분성이라면, 다음 두 가지를 묻는다(24).
1. KC 전체의 흥분성을 높이면(문턱을 낮추면) 오탐은 편향 이동인가, 민감도 저하인가?
2. 특정 냄새에 대한 "기대"를 그 냄새의 KC만 흥분성을 높이는 것으로 근사하면, 잡음 시행이 그 냄새로 잘못 읽히는 냄새 특이적 오탐이 생기는가? 이는 Powers 2017의 조건화 환각(기대가 지각을 만든다)의 회로 수준 근사다.
