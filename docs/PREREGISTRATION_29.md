# 사전 등록: 29 단계 (부분 보상 최적 가설의 독립 검정)

2026-10-09. **결과를 보기 전에 작성했다.**

## 배경

27에서 KC별 문턱 보상의 강도를 바꾸자, 사전 등록한 단조 가설은 틀렸고 결과를 본 뒤 "중간 보상이 최적(U자형)"이라는 관찰이 나왔다. 사후 관찰이므로 독립된 방식으로 검정한다.

27의 완전 보상이 나빠진 이유는 두 가지일 수 있다.
- (가) 보상이 지나치면 원래 약한 KC를 잡음에 노출시킨다(진짜 U자형).
- (나) KC별 문턱을 보정용 냄새 37개로 추정해서 생긴 추정 잡음.

이번에는 추정이 필요 없는 **입력 강도 보상**을 쓴다.

## 보상의 구현

- KC i가 대응 PN에게서 받는 입력 총량을 S_i, 입력이 있는 KC들의 평균을 S̄라 한다.
- 보상 강도 α에서 KC i의 모든 입력 가중치에 (S̄ / S_i)^α를 곱한다. 입력 0인 KC는 그대로 둔다.
- α = 0은 원래 회로, α = 1은 26의 완전 정규화와 같다(재현 점검).
- α = 0, 0.25, 0.5, 0.75, 1. 각 α에서 theta를 같은 보정 규칙(보정용 냄새, 10%)으로 다시 정하고, 검출 기준도 다시 정한다.
- 측정은 27과 같다. 학습된 가치의 누출과 무작위 통제 누출(25의 정의, 시드, MBON11), 범용 구분 d'(18의 주 조건)이다.

## 판정 (두 반구 각각, 두 반구 일치 필요)

- **U자형 (누출).** 학습 누출이 최소인 α가 0.25, 0.5, 0.75 중 하나이고, 그 최솟값이 α = 1의 누출보다 상대적으로 10% 이상 작다.
- **U자형 (구분).** d'이 최대인 α가 0.25, 0.5, 0.75 중 하나이고, 그 최댓값이 α = 1의 d'보다 0.3 이상 크다.
- 두 반구 모두 두 조건을 충족하면 "부분 보상 최적 지지". 누출 조건만 두 반구에서 충족하면 "누출에서만 부분 보상 최적". 두 반구 모두 α = 1이 누출 최소, d' 최대이면 "완전 보상이 최적(27의 U자형은 추정 잡음 때문)". 그 밖은 "불일치".

## 한계

- 입력 가중치를 바꾸는 것은 생물학적 보상의 한 근사다(실제로는 KC의 클로 수와 시냅스 강도 사이의 보상 등이 보고됨).
- 21개 사구체 부분 회로다. 28에서 부분 회로가 누출을 약 30~40% 키운다는 것을 확인했다.
