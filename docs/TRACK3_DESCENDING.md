# 갈래 3: 학습된 가치 신호는 어떤 행동 명령으로 가는가 (49)

2026-10-10. 개인 프로젝트의 탐색 분석이다(`pipelines/49_descending_paths.py`). 출력 뉴런(MBON)의 학습 변화를 하행 뉴런(DN, 뇌에서 몸으로 행동 명령을 내리는 뉴런 1,303개)까지 전달했다.

## 방법

- FlyWire 오른쪽 버섯체 보정 모형. 냄새 A를 처벌과 짝지어 학습(처벌 구역 출력 뉴런에서 A의 KC 연결 약화).
- 전달: 출력 뉴런 53개 -> 중간 뉴런(출력 뉴런 입력을 받는 중추 뉴런 8,327개) -> 하행 뉴런, 그리고 출력 뉴런 -> 하행 뉴런 직접 연결. 각 단계는 받는 쪽 뉴런의 전체 입력으로 나눈 시냅스 비율에 전달물질 부호를 곱했다. 선형 전달이다.
- 지표(실행 전 고정):
  - 하행 뉴런별 일관성: 평가용 냄새 73개 중 그 뉴런이 약한 A 신호 변화의 상위 5%에 드는 비율.
  - 하행 뉴런 수준의 누출: 냄새 없는 잡음 시행에서 하행 뉴런 변화 패턴이 약한 A 패턴과 닮은 비율(코사인 0.5 초과, 크기 절반 이상).

## 결과

### 하행 뉴런 수준의 누출

| 학습 | 누출 |
|---|---:|
| 실제 학습 | **2.1%** |
| 무작위 KC에 같은 학습량 | 0.22% |
| 입력 강도 맞춘 KC에 같은 학습량 | 0.92% |

46의 행동 선택 뉴런(2.2%)과 같은 크기다. 거짓 가치 신호가 행동 명령 단계까지 그대로 전달된다.

### 처벌 학습 신호를 일관되게 받는 하행 뉴런

일관성 50% 이상인 하행 뉴런은 66개다(오른쪽 44, 왼쪽 15, 중앙 7). 계열별로 DNp 16, DNg 12, DNpe 11, DNge 9, MDN 4, DNa 4, DNde 4, DNbe 4개다.

| 하행 뉴런 | 일관성 | 방향 |
|---|---:|---|
| MDN 4개 (좌우 모두) | 0.99~1.00 | 4개 모두 증가 |
| DNp42 | 1.00 | 증가 |
| DNa03 (좌, 우) | 1.00, 0.67 | 증가 |
| DNb05 | 1.00 | 증가 |
| DNg13 | 1.00 | 감소 |
| DNp46 | 1.00 | 감소 |

## 해석

- **MDN("문워커" 하행 뉴런)은 초파리의 뒷걸음질을 일으키는 뉴런으로 알려져 있다**(Bidaye et al. 2014, Science). 이 모형에서는 처벌을 배운 냄새가 73개 거의 모두에서 MDN 4개 전부의 입력을 높인다. 나쁜 냄새를 만나면 뒤로 물러나는 방향과 맞는다.
- 따라서 이 모형에서는 **처벌을 배운 뒤 냄새가 없는 상황에서 생긴 거짓 가치 신호가 뒷걸음질 명령 쪽으로 갈 수 있다.** 초파리판 "거짓 지각이 회피 행동으로 이어지는 경로"의 후보다.
- 다른 일관된 하행 뉴런(DNp42, DNa03, DNb05, DNg13, DNp46 등)의 기능은 이번에 확인하지 않았다. 유형 이름만 기록한다.

## 한계

- 두 단계 선형 전달이다. 중간 뉴런의 문턱, 되먹임, 시간 동역학이 없다. 하행 뉴런까지 가는 신호의 크기(mbon_reach)는 작아서, 실제로 행동을 바꿀 만큼인지는 이 모형으로 알 수 없다.
- 증가와 감소의 방향은 예측 전달물질 부호(글루탐산을 억제로)에 달려 있다.
- 처벌 학습만 봤다. 보상 학습이 어떤 하행 뉴런(예: 앞으로 걷기)으로 가는지는 다음에 볼 수 있다.
