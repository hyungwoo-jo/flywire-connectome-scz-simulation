# 누출을 간섭으로 다시 쓰기 (70, 갈래 3)

2026-10-19. 새 계산은 없다. 01~67의 결과를 환각 해석 없이 머신러닝 용어로 다시 정리한 문서다([연구 계획](RESEARCH_PROGRAM_68.md)). 각 주장 옆의 번호는 근거 단계다.

## 문제 설정

| 회로 | 머신러닝 대응 |
|---|---|
| PN 약 50개 → KC 약 2,000개 | 고정된 희소 무작위 특징 사상(sparse random features) |
| KC 문턱과 APL 억제로 약 10%만 켜짐 | 희소화 비선형성(threshold-linear + 전역 억제) |
| KC → MBON 가중치를 도파민 신호로 약화 | 한 번의 국소 학습 규칙(Hebbian-like depression)으로 학습하는 선형 판독 |
| 감각뉴런의 자발 발화 변동 | 입력 잡음 |

**간섭:** 학습하지 않은 입력(잡음, 다른 냄새)이 학습된 판독 가중치를 다시 읽어 학습한 입력과 비슷한 출력을 내는 현상이다. 01~62의 "누출"은 이 간섭을 재는 한 지표다. 같은 입력의 학습 전후 출력 변화(L)가 약한 진짜 자극 기준을 넘는 잡음 시행의 비율로 정의했다.

## 주장과 근거

**1. 단위 사이 입력 세기의 불균일성이 간섭을 만든다.**
- 학습 패턴과 잡음 활동의 겹침을 허브 인자 H(우연이면 1)로 잰다.
- 실제 배선에서 H는 5~12다(43).
- 초파리 배선 없는 합성 확장층에서도 입력 세기 변동계수 0.1~0.2만으로 H가 3~4가 되고, 0이면 약 1이다(53).
- 입력이 많은 단위는 신호와 잡음 양쪽에 참여하고, 학습은 신호에 참여한 단위의 판독을 바꾼다. 그래서 잡음이 학습된 판독을 선택적으로 읽는다.

**2. 불균일성의 원천은 배선 그래프의 고차 구조가 아니라 단위(노드)의 성질이다.**
- H − 1의 58~115%가 KC 입력 세기의 10분위만으로 설명된다.
- 어느 입력에서 받는지만 섞은 재배선에서도 H가 유지됐다(0.89~1.27배)(54).
- 사구체 쌍 과수렴(17)은 간섭에 체계적으로 기여하지 않았다.

**3. 보상(정규화)은 간섭을 줄이지만, 방식에 따라 기억 용량과 상충한다.**
- 입력 세기를 고르게 맞추면(구조적 정규화) 간섭이 0.2~0.6배로 준다(26, 34, 36).
- 같은 정규화가 기억 정확도를 떨어뜨리고 과보상을 만든다(55).
- 단위마다 자기 평균 활동을 맞추는 활동 의존 항상성은 기억을 올리고 간섭을 줄인다(55~57).
  - 자발 상태가 대부분인 조건(자발 99%)의 항상성은 다섯 반구와 처음 보는 MaleCNS에서 간섭을 ±0.3% 안으로 없애면서 기억을 지켰다(57, 58).
  - 머신러닝으로 말하면, 입력 분포 전체에 대한 단위별 활성 정규화(batch norm이나 homeostatic plasticity에 가까움)가 가중치 정규화보다 낫다는 결과다.

**4. 억제와 단위 간 연결은 간섭의 주요 변수가 아니다.**
- 전역 억제(APL)를 약화해도 오탐이 거의 늘지 않았다(23).
- KC별 억제(33)와 KC끼리의 연결(37)도 간섭을 거의 바꾸지 않았다.

**5. 간섭의 크기는 "잡음 신호 대 약한 진짜 신호"의 비율로 정해진다.**
- 약한 입력을 얕게 표상하는 회로(학습 깊이가 얕은 경우)일수록, 같은 잡음이 상대적으로 크게 읽힌다(61, 62).

## 경계 조건 (67에서 확인)

- **누출 L은 분석자용 진단값이다.** 같은 입력에 대한 학습 전 출력과 학습 후 출력을 둘 다 알아야 계산된다.
- **판독 기준을 고정하면 간섭이 보이지 않았다.** 학습 후 MBON11 출력 하나만 읽는 판독에서, 학습 정보 자체는 뚜렷이 남았다(A/B 83~89%, 통제 56~58%). 그러나 판독 기준을 고정하면, 잡음을 학습 냄새로 읽는 차이가 원래 회로에서 반대 방향, 항상성 회로에서 0 근처였다(67).
- **따라서 주장 1~5는 표상 수준의 간섭(학습된 판독 가중치와 잡음 활동의 겹침)에 대한 것이다.** 단일 스칼라 출력에서의 기능적 오인율로 바로 옮겨지지 않는다.
- 여러 출력을 함께 읽는 판독에서 간섭이 기능적 오류로 나타나는지는 열린 질문이다.

## 기존 이론과의 관계

- **희소 확장과 간섭:**
  - 희소 분산 표상이 패턴 사이 겹침을 줄여 간섭을 줄인다는 생각은 오래되었다. 대표적으로 Kanerva의 sparse distributed memory, 연결주의의 catastrophic interference 논의가 있다.
  - 확장층의 최적 연결 수에 대해서는 Babadi와 Sompolinsky(2014), Litwin-Kumar 등(2017)의 분석이 있다.
  - 이 문서가 더하는 것은 **연결 수가 아니라 단위 사이 입력 세기의 불균일성**이 간섭의 주 변수라는 점이다. 그리고 그 크기를 실제 배선 다섯 개에서 잰 값이다.
- **단위 불균일성:**
  - 인공망과 신경 모형에서 단위 불균일성이 학습을 돕는다는 보고도 있다.
  - 여기서는 불균일성이 기억 용량에는 쓸모가 있고(구조적 평탄화가 기억을 떨어뜨림, 55) 간섭에는 해롭다.
  - 활동 의존 정규화가 둘을 함께 만족시킨다(57).
- **Abdelrahman 등(2021):** 같은 항상성이 기억을 되살린다고 보고했다. 55와 57은 그 항상성이 간섭도 줄인다는 결과를 더한다.

## 남은 질문 (68 이후로 넘김)

- **불균일성은 학습이 만드는 것인가, 피하는 것인가:** 같은 확장층을 학습으로 최적화하면 입력 세기가 고르게 되는가, 허브가 생기는가(갈래 2, 69 이후).
- **해석 기법의 정답 복원:** 활동만으로 쓰는 해석 기법이 이런 단위 성질(허브, 입력 사구체)을 복원하는가(갈래 1, 68).
- **여러 출력을 읽는 판독:** 여러 MBON을 함께 읽는 판독에서 표상 간섭이 기능적 오류가 되는가.

## 한계

- 모든 결과는 발화율 모형 안의 계산이다.
- 시냅스 세기는 시냅스 수로 근사했다.
- 생리 근거(63~67)는 이 문서의 주장을 지지하지도 기각하지도 않는다.
