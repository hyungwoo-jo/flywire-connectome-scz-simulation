# 하행 뉴런의 가치 특이성: 처벌 대 보상 (50)

2026-10-11. 개인 프로젝트의 탐색 분석이다(`pipelines/50_dn_valence_specificity.py`). 지표는 실행 전에 스크립트 머리말에 고정했다. 49의 두 공백을 메운다. (1) 처벌 학습이 MDN(뒷걸음질)을 높인다는 결과가 무작위 대조를 넘는가. (2) 보상 학습은 반대 방향으로 가는가.

## 방법

- 49와 같은 전달(출력 뉴런 53개 -> 중간 뉴런 -> 하행 뉴런 1,303개, 직접 연결 포함, 부호와 입력 비율 반영). 평가용 냄새 73개.
- 하행 뉴런별 부호 효과 s: 냄새마다 하행 뉴런 변화 벡터를 크기 1로 나눈 뒤 냄새 평균.
- 처벌 학습은 PPL1 구역, 보상 학습은 PAM 구역의 출력 뉴런 연결을 약화.
- 대조: 출력 뉴런 53개의 구역 표지(처벌/보상)를 개수를 유지한 채 무작위로 섞기 1,000회.

기능이 알려진 다른 하행 뉴런은 두 학습 모두에서 효과가 0에 가까웠다. DNp09(앞으로 걷기)는 +0.002/-0.000, DNa02와 DNa01(방향 전환)은 +0.004~0.006/-0.000, DNp01(거대 섬유 탈출)은 0이었다.

처벌 효과가 가장 큰 유형은 DNp42(+0.32), DNpe021, DNp52, DNpe006, DNp71이고, 보상 효과가 가장 큰 유형은 DNp54, oviDNa_b, DNg103, DNg63, DNp29다. DNp52는 처벌에서 증가(+0.08), 보상에서 크게 감소(-0.30)한다.

## 해석

1. **49의 "처벌 -> MDN 증가"는 무작위 구역 배정에서도 비슷하게 나온다.** MDN이 하행 뉴런 중 상위에 있는 것은 맞지만, 그것은 처벌 구역이라서가 아니라 MDN이 출력 뉴런 전반에서 강한 입력을 받는 위치이기 때문일 수 있다. 처벌 특이적이라는 주장은 철회한다.
2. **보상 학습은 MDN을 대조 이상으로 낮춘다.** 보상을 배운 냄새는 뒷걸음질 명령을 줄이는 쪽이다. 다가가기와 맞는 방향이다. 이번 분석에서 대조를 넘은 MDN 결과는 이쪽이다.
3. **처벌과 보상이 하행 뉴런 전체에서 거울상으로 작동하지는 않는다**(상관 거의 0). 두 학습은 서로 다른 하행 뉴런 집합으로 간다. MDN과 DNp52는 예외적으로 두 학습에서 반대 방향이다.
4. **앞으로 걷기(DNp09), 방향 전환(DNa01/02), 탈출(DNp01) 뉴런에는 버섯체 학습 신호가 거의 닿지 않는다**(두 단계 안에서). 학습 신호는 특정 소수 하행 뉴런에 몰린다.

## 거짓 지각 가설에 대한 의미

46~49의 그림 "처벌 학습 뒤 거짓 신호 -> MDN -> 뒷걸음질"은 약해진다. MDN으로 가는 경로 자체는 있지만 처벌에 특이적이지 않다. 반대로 "보상 학습 뒤 거짓 신호 -> MDN 감소"는 특이적이다. 냄새가 없을 때 거짓 신호가 생기면, 최근 보상을 배운 경우 뒤로 물러나는 경향이 줄어드는 쪽이다.

## 한계

- 선형 두 단계 전달이다. 세 단계 이상의 경로, 문턱, 되먹임은 없다.
- 부호는 예측 전달물질(글루탐산을 억제로)에 달려 있다.
- 오른쪽 FlyWire 버섯체에서 나간 신호만 봤다.
- 효과 크기의 절대값은 모형 단위이며, 실제 MDN 발화를 바꿀 만큼인지는 모른다.
