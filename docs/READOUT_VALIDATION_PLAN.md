# 학습 후 출력만 사용하는 기능 판독: 후속 설계

2026-10-18. 실행 전 설계 초안이며 새 판독 결과는 아직 계산하지 않았다. 관측 감사와 66 입력 단위 정리가 선행 조건이다.

## 질문

분석자용 누출 지표 L(k)는 같은 입력에 대한 학습 전후 MBON 출력의 상대 감소다. 실제 후속 회로가 학습 전 출력까지 접근하지 않고도 약한 입력·무자극을 학습 자극으로 읽는가?

## 접근 가능한 정보

- 허용: 학습 후 MBON 출력, 별도 보정 시행에서 고정한 기준, 실제 후속 뉴런이 받는 것으로 명시한 추가 출력.
- 허용하지 않음: 평가 입력의 학습 전 출력, 실제 정답 냄새/입력 크기, 평가 시점의 분류 성능을 보고 정한 문턱.
- L(k)와 H는 기전 진단값으로 병기하되 기능 판독 결과와 분리한다.

## 기본 비교

학습한 냄새 A, 강도·KC 활동·가중치 변화량을 맞춘 다른 냄새 B, 학습하지 않은 냄새, 용매/약한 비특이 입력, 순수 자발 입력을 구분한다. 자극이 없는 시행에는 냄새 식별 정답을 부여하지 않는다. 먼저 신호 검출, 그다음 검출된 시행의 냄새/학습 가치 판독을 평가한다.

동일한 보정 절차를 학습 A, 비짝 학습, 학습량 일치 무작위 KC 통제, 학습 없음에 적용한다. 전체 출력 감소만으로 생긴 효과와 학습 자극에 특이적인 효과를 나눈다. 신호 누락도 전체 성능에 포함하고 검출 시행만의 정확도로 과장하지 않는다.

## 판정 전 고정할 항목

- 실제 회로에서 쓰는 출력 채널 및 비교 기준을 어느 보정 시행에서 형성하는가.
- 보정/평가 seed와 개체·냄새 분할. 현재 이미 살펴본 데이터로 하는 검증은 탐색으로 표시한다.
- 주 결과: 신호 검출 민감도·오탐, A 판독률과 B/기타 판독률의 차이, 약한 신호 누락, 학습 전후의 실제 출력 분포.
- 출력 강도 일치 통제와 KC 유형 내 순열을 포함해 효과의 특이성을 확인한다.
- 반구와 모의 반복을 독립 개체로 세지 않는다. 이 모형의 학습/판독 효과를 지각·질환의 직접 증거로 부르지 않는다.

단순 판독에서 효과가 유지되지 않으면 분석자용 L(k)의 변화를 행동적 혼동으로 확대하지 않는다. 유지되더라도 실제 동물에서 같은 판독 회로를 쓰는지 별도 근거가 필요하다.
