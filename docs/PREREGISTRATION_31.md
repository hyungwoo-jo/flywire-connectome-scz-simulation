# 사전 등록: 31 단계 (허브 KC는 어떤 KC인가)

2026-10-09. **결과를 보기 전에 작성했다.**

## 배경

30에서 αβ KC를 많이 읽는 MBON일수록 학습된 가치의 누출이 컸다(사후 관찰). 17에서는 가장 강한 과수렴 묶음(과일 냄새 사구체)의 출력이 KCab에 치우쳐 있었다. 허브 KC가 αβ 계열에 몰려 있는지, 그리고 허브 KC가 받는 입력이 과수렴 사구체에서 오는지 직접 확인한다.

## 정의

- 두 반구, 원래 부분 회로(16, 22 보정), 정상 APL, 10% theta.
- **참여도:** KC가 평가용 냄새 73개 중 반응하는 냄새의 수(무잡음 원농도).
- **허브 KC:** 참여도가 상위 10%인 KC(반응이 있는 KC 중에서). 동률은 포함한다.
- **잡음 활성:** 25의 잡음 시행 500개에서 켜지는 비율.

## 검정

**H31a (하위 유형).** 허브 KC 중 KCab의 비율이, 반응이 있는 전체 KC 중 KCab의 비율보다 크다. Fisher 정확 검정(단측, p < 0.05). 두 반구 모두 충족하면 "허브는 αβ에 몰려 있다".

**H31b (입력의 출처).** 17에서 DM1-DM4의 Z > 3.29 이웃 중 Hallem 대응 사구체 {DM2, DM4, VM2, VM3}(18의 C_B)에서 오는 입력이 KC 입력 총량에서 차지하는 비율이, 허브 KC에서 나머지 반응 KC보다 크다. Mann-Whitney 단측 p < 0.05가 두 반구 모두면 지지.

**보조 (판정 없음).**
- 하위 유형별 참여도 중앙값과 잡음 활성 비율.
- 허브 KC의 PN 입력 연결 수(클로 수에 대응)와 입력 가중치 총합을 나머지 KC와 비교.
