# 입력 존재와 기억 판독을 분리하기

2026-10-08. [학습 실험](ASSOCIATIVE_READOUT.md)의 ‘낮은 MBON 출력이면 A’ 규칙은 무자극도 A로 읽었다. 이번에는 외부의 입력 존재 기준을 추가하고, 잘못된 판정을 줄이는 대신 무엇을 놓치는지 비교했다.

## 설계

08과 같은 주 MBON11, 정상 APL 학습, eta=20, 높은 입력 겹침, 패턴 8쌍을 사용했다. 학습 입력과 가중치는 같은 시드로 재생성하고, 평가 잡음은 새로운 독립 시드로 만들었다. A/B 각각 평가 100회다. APL은 평가 시 정상/제거를 비교했다.

입력 세기는 0/0.1/0.25/0.5/1로 비교했고 같은 평가 잡음을 공유했다. 세기 0은 정확한 0 입력이 아니라 **인공 잡음만 있는 입력**이다. 그 경우 A/B라는 원래 패턴 이름은 실제 자극 종류를 뜻하지 않으며, 두 묶음을 합쳐 잡음 판정률을 계산했다. 정확한 0 입력은 별도 논리 점검으로 기록했다.

입력 존재 기준은 다음과 같다.

```text
PN 활동 합 > 독립 잡음 입력 2,000회의 95번째 백분위수
A로 판정 = 입력 존재 AND 학습 단계에서 고정한 A 판독
```

잡음 0.1/0.4 각각 하나의 기준을 정했다. 이 기준은 별도 학습 잡음에서 정했고 평가 입력으로 조정하지 않았다. 95% 기준은 연구자가 고른 값이며 실제 초파리의 감각 탐지 회로가 아니다. 정상 잡음 분포를 정확히 아는 가정도 포함된다.

## 결과와 비용

큰 잡음, 정상 평가 APL에서 잡음만 있는 입력을 A로 읽는 비율은 **80.38%→2.63%**였다. 정확한 0 입력은 기존 판독에서 A, 입력 존재 기준을 추가하면 A가 아니었다.

잡음만 있는 입력의 약 5.19%가 존재 기준을 넘었다. 이는 95번째 백분위수로 기준을 정했으니 기대되는 꼬리 비율이며 새로운 생물학적 발견이 아니다. 그중 기존 A 판독도 만족한 몫이 2.63%다.

| 입력 세기 | 실제 A의 신호 존재 판정 | 실제 A를 A로 읽음: 기존 | 실제 A를 A로 읽음: 존재 기준 추가 |
|---|---:|---:|---:|
| 0.1 | 13.50% | 81.25% | 8.13% |
| 0.25 | 47.63% | 79.88% | 33.75% |
| 0.5 | 96.75% | 75.63% | 72.63% |
| 1.0 | 100% | 56.13% | 56.13% |

잡음 오판을 줄였지만 약한 실제 입력의 상당 부분도 놓쳤다. 학습 단계는 세기 1의 입력만 사용했고, 판독 문턱을 평가 때 바꾸지 않았다. 이것이 세기 변화에 따른 결과에 영향을 준다.

기존 판독에서 입력이 약할수록 A 판정률이 높아지는 문제도 보였다. 예를 들어 큰 잡음·세기 0.5의 B도 기존 71.88%, 기준 추가 후 69.13%가 A로 판정됐다. 작은 잡음에서는 세기 0.25/0.5의 A와 B가 모두 A로 판정됐지만, 세기 1에서는 A 약 95.5%, B 약 5.25%였다. **입력 존재 기준만으로 입력 종류 판독의 세기 의존성을 해결하지 못한다.**

이것은 다음 세 질문을 구분해야 한다는 사례다.

1. 지금 입력이 있는가?
2. 있다면 A인가 B인가?
3. 이 판독에 학습으로 변한 연결이 어떤 기여를 했는가?

첫 질문에 기준을 추가해 나아졌다고 두 번째·세 번째 질문까지 해결됐다고 해석하지 않는다. 잡음에 대한 A 판정은 이 모형의 결정 오류이지 환각이나 생물학적 기억 오류의 증거가 아니다.

## 다음 검증

입력 세기 변화가 출력의 절대 크기를 움직이는 효과와 입력 종류를 구분하는 효과를 분리할 필요가 있다. 강도가 다양한 입력으로 판독 기준을 학습하거나, 학습 전후 반응의 상대 변화를 비교하는 분석을 검토할 수 있다. 후자는 실험자가 계산하는 반사실적 비교이며 실제 뇌가 학습 전 가중치를 별도로 읽는다는 주장이 아니다.

학습 단계의 무작위 배선 범위 안에 실제 회로 성능이 있었던 결과도 유지된다. 더 복잡한 판독 규칙을 추가하는 것만으로 실제 커넥톰의 특수성을 입증하지 못한다. 세기·잡음·판독 가정을 바꿔도 남는 실제 배선의 효과가 있는지를 별도로 물어야 한다.
