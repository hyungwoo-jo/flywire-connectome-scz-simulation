# 06~15 단계 종합

2026-10-09. 새 실험이 아닌 기존 결과의 정리다. 다음 단계(16~18)의 출발점으로 쓴다.

## 확립된 것 (이 모형 범위 안에서)

1. **실제 PN->KC, KC->MBON 상세 배선은 제약 대조 배선과 구분되지 않았다.** 인공 A/B 입력(06, 07), 학습 판독(08~11), KC 유형 보존 대조(12), DoOR 관측 냄새 18개(14)까지 모든 조건에서 실제 배선은 대조 범위 안에 있었다. 대조 수는 5~10개였다.
2. **구분 성능을 가장 크게 바꾼 것은 입력 크기와 KC 문턱의 비율이었다.** 관측 냄새에서 작은 입력은 KC 전체 침묵(평가 시행의 약 21%)을 만들었고, 낮은 잡음 조건 오류의 약 87%가 침묵 시행에서 나왔다(15).
3. **APL은 활성 KC 수와 반응 크기를 줄이지만, 이 모형의 분류 정확도에는 일관된 영향을 주지 않았다**(06, 07, 15).

## 기각되거나 철회된 것

- 01~04의 E/I, 환각, 기억 해석은 정규화 문제와 데이터 ID 문제로 보류했다(05).
- 14 초기의 "실제 배선 우세"는 대조를 5개에서 10개로, 잡음 반복을 1회에서 4회로 늘리자 사라졌다.

## 모형의 성질일 뿐인 것 (새로운 발견이 아님)

- 같은 0 출력은 구분할 수 없다. 문턱을 낮추면 잡음에도 반응한다. 출력이 포화하지 않는 범위에서 입력 배율과 문턱은 서로 교환 가능하다(15).
- 완전 침묵 상태에서는 APL 구동도 0이므로 APL이 침묵 여부를 바꿀 수 없다(15).

## 남은 구조적 문제

1. **보정 불일치.** 문턱은 인공 입력에서 활성 KC 10%에 맞춘 값이다. 관측 냄새에서는 활성 KC가 0.66%였다. 문헌상 KC 반응은 냄새당 대략 5~10%다. 실제 입력에서 정상 회로를 알려진 특징에 맞추고 고정하는 단계(RESEARCH_DIRECTION_EXPLAINED.md 5장의 3번)를 실제 냄새 입력으로는 수행하지 않았다.
2. **입력 변환 부재.** DoOR 통합값(0~1)을 PN 입력으로 직접 넣었다. 감각뉴런->PN 사이의 알려진 비선형 정규화(Olsen 2010)를 쓰지 않았다.
3. **질문의 기대값.** PN->KC 연결이 무작위에 가깝다는 보고(Caron 2013)와, 무작위 확장이 일반적인 구분에 거의 최적이라는 이론(Litwin-Kumar 2017)을 고려하면 "실제 배선 = 대조"는 기대되는 결과다. Zheng 2022(FAFB)는 PN->KC 샘플링이 완전 무작위가 아니라 주로 음식 냄새에 반응하는 PN 유형들이 같은 KC로 과수렴하는 구조를 보고했다. 그 모형에서도 관측 배선은 일반적인 구분에서 무작위보다 나빴고, 신호가 이 과수렴 PN 유형들로만 흐를 때 회복됐다.
4. **통계.** 대조 10개의 최소~최대 범위만 보고했다. 천장(100%) 조건이 많았다.
