# 학습만으로 생기는 가치 신호의 누출 (25)

2026-10-09. [사전 등록](PREREGISTRATION_25.md)(실행 전 수정 1 포함)에 따라 실행했다.

## 질문

24에서 냄새에 반응하는 KC는 잡음에도 잘 켜지는 것처럼 보였다. 그렇다면 기대 같은 별도 기제 없이 **학습만 해도**, 냄새가 없을 때 학습한 냄새의 가치 신호가 출력에 나타나는가?

## 방법 요약

- 두 반구 보정 모형, 검출기(KC 합)와 기준은 23과 같다.
- 출력은 각 반구의 실제 MBON11이다(오른쪽 KC 입력 1,027개, 왼쪽 668개).
- 냄새 A를 학습하면 A에 반응한 KC의 MBON11 연결이 약해진다.
- **가치 신호 L:** 어떤 시행에서 학습 전보다 MBON11 출력이 상대적으로 얼마나 줄었는가.
- **누출:** 잡음 시행에서 검출기가 "있다"고 판단하고, 동시에 L이 약한 A 시행 L 중앙값의 절반을 넘는 경우.
- **통제:** A의 학습량 분포를 같은 수의 무작위 KC에 재배치해 학습했다.

## 결과

|---|---:|---:|
| 잡음 시행 중 "있다" 판단 (학습과 무관) | 5.2% | 5.4% |
| 그중 A의 가치 신호를 띤 비율 (A 학습) | **3.5%** | **3.7%** |
| 같은 비율 (무작위 KC 학습 통제) | 0.06% | 0.01% |

| KC 입력 총량과 잡음 활성 확률의 상관 (P25) | rho 0.59 | rho 0.60 |

**판정**
- H25 지지(두 반구). 학습만으로 가치 신호가 잡음에 누출되며, 무작위 학습보다 훨씬 크다.
- P25 지지(두 반구). 입력을 많이 받는 KC일수록 잡음에도 잘 켜진다.
- 배선 특이성 없음.

## 해석

1. **잡음으로 생긴 "있다" 판단의 약 3분의 2가 학습한 냄새의 가치를 띤다.** 냄새가 없을 때 회로가 가끔 내는 거짓 신호는 무작위한 내용이 아니라, 최근 배운 냄새의 의미를 실어 나른다.
2. **기제는 "허브 KC"다.** PN 입력을 많이 받는 KC는 (a) 거의 모든 냄새 표상에 참여하고, (b) 잡음에도 잘 켜진다. 그래서 어떤 냄새를 배우든 그 학습은 허브 KC의 출력 연결을 바꾸고, 잡음이 허브 KC를 켜면 그 변화가 출력에 그대로 드러난다. 무작위 KC에 같은 양의 학습을 주면 이 일이 거의 일어나지 않는다.
3. **배선 특이성이 없는 이유도 같은 기제로 설명된다.** 대조 배선은 KC별 입력 총량을 보존하므로 허브 KC도 그대로 남는다. 즉 효과는 BANC 배선의 세부가 아니라 "KC마다 입력량이 다르다"는 일반적 성질에서 나온다.
4. **환각 연구와의 연결.** Powers 2017의 조건화 환각은 학습된 연합이 신호 없는 상황에서 지각을 만든다는 현상이다. 이 모형에서는 별도의 기대 기제 없이도, 학습과 허브 KC만으로 "신호 없는 상황에서 학습된 의미가 나타나는" 일이 생긴다. 다만 이것은 출력 뉴런 하나의 계산 결과이고 초파리의 지각이나 행동이 아니다.

## 한계

- 21개 사구체 부분 회로라서 KC 입력량의 불균등이 전체 회로보다 클 수 있다. 전체 사구체 입력이 있으면 허브 효과의 크기는 달라질 수 있다.
- 학습 규칙과 MBON 하나의 판독은 단순화했다.
- 기준(약한 A 신호의 절반)은 하나의 선택이다.
