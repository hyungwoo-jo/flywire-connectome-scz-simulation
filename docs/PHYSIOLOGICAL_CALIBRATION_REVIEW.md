# 입력 단위와 KC 활동-형광 보정의 근거 점검

2026-10-18. 공개 원자료와 1차 문헌을 추가 확인했다. 결과에 맞춰 임의의 생리 계수를 선택하지 않았다.

## 1. 2004 용매 입력

공식 [DoOR Hallem.2004.EN 설명](https://neuro.uni-konstanz.de/DoOR/content/dataset.php?dataset=Hallem.2004.EN)은 자발 발화 차감이 일괄적이지 않음을 명시한다. 공개 표의 같은 열에서 Or47b 용매 72.576과 SFR 73.076이 함께 존재한다. 따라서 용매 열을 24채널 모두 양의 증가분으로 넣는 가정은 성립하지 않는다. 이 점은 로컬 자료와 공식 웹 설명 양쪽에서 확인했다.

현재 확보한 24채널 용매 표에서 같은 연구 SFR은 6개만 유한하다. 공기/기준 대조를 추가로 찾아봤지만 현재 표 안에서 누락된 18채널 기준값을 복원할 수 있는 완전한 대조 행은 확보하지 못했다. [원 연구](https://pubmed.ncbi.nlm.nih.gov/15210116/)의 24채널 원기록 또는 처리 정의 확인이 필요하다. 이는 자료를 모두 찾아도 없다는 주장이 아니라 현재 확보 범위의 제한이다.

같은 채널에서 냄새−용매 차이를 취하면 공통 오프셋이 상쇄되는 수학적 성질이 있다. 그러나 처리 오프셋이 모든 행에 같다는 근거가 필요하고, 그 차이만으로 용매−공기의 실제 반응이나 절대 Poisson 변동을 복원할 수 없다. 따라서 이 방법을 66의 용매 생리 검증으로 바꾸지 않았다.

## 2. 형광 보정에는 두 연결이 필요하다

현재 KC 모형 k는 0~1의 상대 활동이며 실제 spikes/s로 보정된 값이 아니다. 필요한 것은 (1) k→발화율/스파이크, (2) 해당 세포·구획에서 스파이크→형광의 두 연결이다. GCaMP6f의 시간 상수 하나를 문헌에서 가져오는 것만으로 두 연결이 정해지지 않는다.

[동시 전기·칼슘 기록 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC8060029/)는 스파이크-형광 변환을 직접 추정하는 자료의 예다. 다만 이 연구는 생쥐 피질 뉴런이므로 그 계수를 성체 초파리 KC 세포체에 바로 대입하지 않는다. 이번 검색 범위에서는 현재 영상 조건에 대응하는 성체 KC 동시 기록 기반 절대 변환표를 확보하지 못했다.

## 3. KC 자체에서도 구획과 조작 조건이 중요하다

[Greenin-Whitehead et al. 2025](https://doi.org/10.1113/JP288790)는 NaChBac 조작에서 전기적 흥분성과 GCaMP6f 반응을 함께 조사했다. 조작 기간에 따라 정상 스파이크 감소가 비슷해도 수상돌기/축삭의 칼슘 반응 회복은 달랐고 세포체 반응과도 달랐다. 이는 특정 조작 실험의 결과이며 정상 KC의 모든 칼슘 신호가 스파이크와 무관하다는 뜻이 아니다. 현재 감사에서는 세포·구획·조건이 다른 변환 계수를 무비판적으로 옮기지 않아야 한다는 근거로 사용했다.

저자 공개 PDF는 data/physiology_review/에 두고 SOURCE.json에 DOI·URL·SHA-256을 기록했다. 원문은 Git 제외 대상이다.

## 4. 현재 분석 경로

- 용매 생리 입력은 단위가 정리되기 전까지 보류한다. 기존 66 사전등록은 보존한다.
- 잠재 모형을 영상으로 직접 기각하는 주장도 절대 변환이 정리되기 전까지 보류한다. 실제 기저 영상의 주입·회수 실험은 검출력 점검으로 유지한다.
- 독립적으로 검증할 수 있는 정보 접근 문제는 기존 2006 입력을 사용하는 추상 회로 안에서 진행한다. 학습 후 MBON 출력만 쓰는 판독과 같은 입력의 학습 전 출력을 아는 지표를 비교한다. 이 분석은 형광·행동·지각의 생리 검증을 대신하지 않는다.
