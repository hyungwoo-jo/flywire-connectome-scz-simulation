## 배경

## 16. 입력 변환과 보정 (결과 판단 없음, 고정 단계)

**입력.** Hallem and Carlson 2006 (DoOR.data 커밋 db323a49의 per-receptor CSV, 열 `Hallem.2006.EN`). 수용체 24개 × 냄새 110개로 결측이 없다. 값은 자발 활동 대비 변화량(spikes/s)이다.

**수용체 -> PN 대응.** DoOR `door_mappings.csv` 의 사구체를 쓴다. Or33b는 DM3와 DM5에 공동 발현되므로 사구체 대응에서는 제외한다(DM3 <- Or47a, DM5 <- Or85a). 대신 정규화 합에는 포함한다. BANC PN 중 사구체 접두사가 일치하고 `multiple_glomeruli` 나 `annotation_prefix_conflict` 가 아닌 PN만 쓴다(13단계 감사표 기준). DC1과 VA1d는 주석 충돌로 빠진다. 나머지 PN의 입력은 0이 아니라 "회로에서 제외"로 처리한다(14단계와 동일한 부분 회로).

**감각뉴런 -> PN 변환.** Olsen, Bhandawat and Wilson 2010의 식을 계수 조정 없이 그대로 쓴다.
`PN = Rmax * ORN^1.5 / (ORN^1.5 + sigma^1.5 + (m * sum(ORN_1..24) / 190)^1.5)`
Rmax=165, sigma=12, m=10.63. ORN은 Hallem 변화량을 0에서 자른 값이다(Olsen의 적합도 기준선을 뺀 반응이다). KC 입력은 `W_PN->KC @ (PN / Rmax)` 이다.

**시행 잡음.** 500 ms 창의 Poisson 계수 잡음을 쓴다. 감각뉴런 발화율 r(자발 활동 포함)에 대해 시행 측정값은 `count/0.5 - SFR`, count ~ Poisson(0.5*r)이다. 그 다음 0에서 자르고 변환한다. 민감도 확인으로 창을 0.25 s(잡음 약 1.4배)로 줄인 조건도 둔다. 임의의 Gaussian 크기를 정하지 않는다.

**냄새 분할.** 냄새 110개를 고정 시드(16000)로 보정용 37개와 평가용 73개로 나눈다. 보정용 냄새는 17, 18단계의 평가에 쓰지 않는다.

**보정.** 실제 배선, 정상 APL(계수 4), 무잡음 보정용 냄새에서 활성 KC 평균이 **10%** 가 되도록 문턱 theta만 이분법으로 정한다. 민감도 조건은 5%다. 정한 뒤에는 고정한다.

**보정 점검 (통과 기준, 통과 여부만 보고).**
- (a) APL 제거 시 평균 활성 KC 비율이 정상보다 커야 한다(Lin 2014의 정성적 결과).
- (b) 평가용 냄새의 무잡음 평균 활성 KC가 3~20% 범위다.
- (c) 평가용 냄새 중 KC 전체 침묵 냄새의 비율을 보고한다(기준 없음).

(a)나 (b)를 통과하지 못하면 17단계는 진행하고, 18단계는 실행하되 해석을 "보정 실패 조건"으로 제한한다.

## 17. 배선 구조: 과수렴 PN 유형 공동체 (그래프만, 냄새 자료 사용 안 함)

**질문.** BANC 우측 PN->KC에서 특정 PN 유형들이 같은 KC로 우연보다 자주 수렴하는가 (Zheng 2022의 FAFB 결과가 재현되는가)?

**방법.** PN 유형 = cell_type의 사구체 접두사(PN 138개 전체, 다중 사구체 유형은 그 자체를 하나의 유형으로 둔다). 쌍 (i, j)에 대해 i와 j 모두에게서 입력을 받는 KC 수를 센다. 대조는 기존 `strength_preserving_null` (PN별 연결 수, KC별 입력 연결 수와 가중치 합 보존) **1,000개**, 시드 170001~171000. 쌍별 Z = (관측 - 대조 평균) / 대조 SD.

**공동체 정의.** Z > 3.29 (양측 p < 0.001 근사)인 쌍을 간선으로 하는 유형 그래프에서, 유형 3개 이상의 가장 큰 연결 성분을 "핵심 공동체"로 정한다. 이 규칙 외에 손으로 고르지 않는다.

**보조 기술(판정 없음).** 공동체 PN의 출력이 KC 하위 유형(KCg, KCab, KCa'b')에 어떻게 분포하는지 보고한다(Zheng: ab, a'b'에 치우침). 공동체 사구체가 Hallem 자료에서 어떤 냄새 계열에 반응하는지 기술한다. "음식 냄새"라는 분류는 이번에 독립적으로 검증하지 않았으므로 기술에만 쓴다.

**판정.** 핵심 공동체가 존재하면(유형 3개 이상) "재현", 없으면 "재현 안 됨". 재현되지 않으면 18단계는 실행하지 않는다.

## 18. 기능: 공동체로 흐르는 냄새에서 실제 배선이 유리한가

**가설 H1.** 실제 배선은 평가용 냄새 전체의 구분에서 대조보다 낫지 않다(z_all <= 0 예상, 06~15와 Zheng).
**가설 H2 (주 가설).** 입력이 핵심 공동체 PN에 많이 실린 냄새끼리의 구분에서, 실제 배선의 대조 대비 상대 위치가 그렇지 않은 냄새보다 높다.

**냄새 분류 (입력만 사용).** 평가용 냄새 중 무잡음 PN 변환값의 최대가 10 Hz 미만인 냄새는 제외한다(입력이 거의 없는 냄새). 남은 냄새마다 공동체 비중 c = 공동체 대응 PN의 변환값 합 / 대응 PN 전체 변환값 합. c의 중앙값으로 HIGH와 LOW로 나눈다. 핵심 공동체에 대응되는 Hallem 사구체가 2개 미만이면 H2는 검정력이 없다고 보고 실행하지 않는다.

**측정.** 냄새당 시행 30개(학습 10, 평가 20). 그룹(HIGH, LOW, 전체) 안에서:
- 주 지표: 평균 쌍별 d'. 학습 시행 중심의 차 방향으로 평가 시행을 투영하고 `|mu1 - mu2| / sqrt((v1 + v2) / 2)` 를 계산한다. 분산이 0인 쌍은 d' 상한 10으로 자른다.
- 보조 지표: 최근접 중심 다중 분류 정확도(동률은 균등 기대값).

**대조.** 14단계와 같이 대응 PN의 연결만 교환하는 `strength_preserving_null` **100개**, 시드 180001~180100. 대조마다 같은 잡음 시행을 공유한다.

**통계.** 그룹 g에 대해 z_g = (실제 - 대조 평균) / 대조 SD. 주 통계량 D = z_HIGH - z_LOW. 영분포는 대조 각각을 가상의 관측으로 두고 나머지 99개 대비로 D를 계산해 얻는다. 단측 p = (1 + #{D_k >= D}) / 101.

**판정 규칙.**
- H2 지지: 주 잡음 조건(0.5 s 창), 보정 10%에서 D > 0 이고 p < 0.05.
- 강한 지지: 위에 더해 민감도 조건(0.25 s 창, 보정 5%) 4개 조합 중 3개 이상에서 D > 0.
- 그 밖에는 "지지되지 않음"으로 보고한다. 주 조건 외의 조합에서 p < 0.05가 나와도 주 결과로 바꾸지 않는다.
- H1은 z_all을 보고하고 -1.96 < z_all < 1.96이면 "대조와 구분 안 됨"으로 쓴다.

## 추가 기록 1 (2026-10-09, 17 실행 후, 18 실행 전)

**16 결과.** 보정 점검 (a), (b) 모두 통과했다. 10% 보정 기준으로 평가용 냄새 활성 KC는 9.37%, APL 제거 시 13.95%였다. 냄새 전체가 침묵한 경우는 없었다.

**17 결과와 사전 규칙의 실패.** Z > 3.29 쌍은 59개로, 대조 각각을 가상 관측으로 둔 경우의 평균 5.6개(95백분위 10개)보다 많았다(p = 0.001). 그러나 사전 규칙인 "가장 큰 연결 성분"은 유형 58개 중 44개를 하나로 이어 버렸다. 촘촘한 공동체가 아니라 드문 간선이 사슬처럼 연결된 것이다. 이 규칙은 공동체의 정의로 부적절했으므로 **사전 등록 기준의 "재현" 판정은 내리지 않는다.** 사전 등록된 H2는 이 정의로는 실행할 수 없다.

**18에서 바꾸는 점 (탐색 분석으로 명시).** 결과를 보기 전에 다음을 정한다.
- H1은 공동체 정의와 무관하므로 사전 등록대로 실행한다.
- H2는 다음 두 정의로 **탐색적으로** 실행한다. 통계 절차(D, 가상 관측 영분포, 판정 기준)는 사전 등록과 같다. 정의가 사후에 정해졌으므로 결과를 확증으로 쓰지 않는다.
  - C_A: 17의 탐색 군집 절차(Z 행 프로필의 average linkage, 6개 군집, 군집 내 평균 Z 최대)가 고른 {DM6, VC4, VM5d}. 군집 내 평균 Z 4.24, 대조 기준 p = 0.001. 세 사구체 모두 Hallem 대응이 있다.
  - C_B: 가장 강한 쌍 DM1-DM4의 Z > 3.29 이웃 중 Hallem 대응 사구체: {DM2, DM4, VM2, VM3}. DM1(Or42b)은 Hallem 2006에 없다.
